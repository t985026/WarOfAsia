# 韓國紅方｜第四卷：中俄朝協同、盟國分化與國際制度牽制

## 一、文件定位

本卷分析中國、北韓與俄羅斯如何在不一定形成正式聯合作戰指揮的情況下，透過互補行動分散美韓日、歐洲及臺灣資源。

## 二、三方互補角色

### 中國

- 臺海主要行動者。
- 對韓經濟、外交、資訊與區域軍事壓力。
- 在聯合國與全球南方推動主權及反干涉敘事。

### 北韓

- 朝鮮半島第二戰場。
- 核飛彈、網路、金融與心理壓力。
- 牽制韓國、日本及駐韓美軍。

### 俄羅斯

- 外交支持與安理會阻礙。
- 能源、金融、技術及制裁緩衝。
- 在歐洲、北極或其他地區增加美歐壓力。
- 支持反西方及多極化敘事。

## 三、協同不等於統一指揮

三方可能存在：

- 共同反對美國同盟體系。
- 互相利用對方危機。
- 交換能源、物資、技術及外交支持。
- 在時間上互相呼應。

但也存在矛盾：

- 中國不希望北韓全面失控。
- 俄羅斯可能追求自身利益，不完全服從中國。
- 北韓可能藉機提高要價。
- 對韓全面戰爭可能破壞中國臺海目標。

## 四、盟國分化目標

| 關係 | 紅方希望造成的分化 |
|---|---|
| 美韓 | 韓國限制基地與區域任務 |
| 日韓 | 中斷情報、飛彈預警與後勤 |
| 韓臺 | 韓國避免通信、產業及人道支援 |
| 韓澳歐 | 韓國不加入制裁與供應鏈替代 |
| 美國與歐洲 | 歐洲不願承擔對中經濟成本 |
| 東協與G7 | 全球南方維持中立或反制裁 |

## 五、聯合國與國際敘事

中國與俄羅斯可利用安理會否決與程序，使：

- 強制性決議難以通過。
- 國際社會轉向停火、人道與對話。
- 臺海與半島行動被描述為內政或安全回應。
- 韓國被要求避免「擴大衝突」。

北韓則可能宣稱其活動是對美韓演習及美國區域部署的防衛回應。

## 六、全球南方與東協

紅方可能強調：

- 西方雙重標準。
- 制裁傷害全球經濟。
- 臺海問題應由中國自行解決。
- 韓國應保持和平與中立。
- 亞洲不應成為美國同盟戰場。

## 七、俄羅斯第二方向壓力

俄羅斯不需直接參與朝鮮半島，只要：

- 在歐洲增加軍事與政治壓力。
- 影響能源與糧食市場。
- 協助中朝取得受限資源。
- 使美國與歐洲無法集中注意力。

即可提高紅方整體空間。

## 八、紅方成功條件

- 美韓日無法形成共同情勢判斷。
- 歐洲只發表聲明，不採實質措施。
- 東協及印度公開反對制裁或軍事支援。
- 聯合國討論長期停留在程序與停火。
- 北韓維持高威脅而沒有遭到一致反制。
- 韓國企業成功阻止政府加入制裁。

## 九、紅方失敗條件

- 美韓日定期公開共同威脅評估。
- G7為韓國企業提供金融、原料與市場替代。
- 東協及全球南方關切民用設施與航行安全。
- 北韓行動被視為配合中國而引發更多制裁。
- 俄中朝合作促使韓國、日本與歐洲安全合作深化。

## 十、藍方觀察重點

- 三方聲明是否使用相同歸責與法律語言。
- 北韓軍事行動是否與中國對韓外交要求同步。
- 俄羅斯是否提供新的能源、技術或金融緩衝。
- 安理會與國際組織是否被程序性拖延。
- 全球南方資訊環境是否出現集中敘事。
- 中國經濟措施與北韓軍事壓力是否互相配合。

## 十一、本卷結論

中俄朝不必建立完整聯合司令部，也能透過：

> 中國主戰略、北韓牽制、俄羅斯分散與國際制度阻礙，形成對韓國與盟國的複合壓力。

### 紅方分析六軸

1. **政治目的**：是否要迫使韓國中立、退出同盟或限制基地支援。  
2. **工具組合**：政治、經濟、外交、情報、網路、軍事與犯罪代理是否同步。  
3. **第二戰場**：北韓是否能牽制美韓日兵力與決策。  
4. **可否認性**：是否利用商業、媒體、社團、網路犯罪或灰色地帶降低歸責。  
5. **成本控制**：紅方是否避免直接攻擊韓國，以防觸發美韓共同防衛。  
6. **失敗條件**：哪些藍方反應會使紅方分化、脅迫與牽制失效。
