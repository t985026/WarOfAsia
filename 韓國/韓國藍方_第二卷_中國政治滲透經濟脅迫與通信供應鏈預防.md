# 韓國藍方｜第二卷：中國政治滲透、經濟脅迫與通信供應鏈預防

## 一、目的

建立在法治下防止外國政府利用秘密委託、企業控制、資料集中、經濟依賴及通信供應鏈影響韓國決策的制度。

## 二、證據標準

不能以親中、反美、反日或不同外交立場直接推定滲透。高風險指標包括：

- 隱瞞外國政府或黨國委託。
- 不透明金流與最終受益人。
- 取得軍政或關鍵產業敏感資料。
- 危機期間接受待命或同步任務。
- 控制媒體、資料、電信或高權限系統。
- 有證據顯示與外國官方行動協同。

## 三、政治資金與秘密委託

- 政治獻金與第三方資金揭露。
- 政黨、媒體、智庫與學術資助透明。
- 最終受益人及實際控制人登記。
- 外國政府委託登記。
- 違法金流凍結與司法程序。
- 保護記者、學者、僑民與合法團體。

## 四、地方政府與交流

需確認：

- 是否涉及敏感基礎設施。
- 是否要求政府或個人資料。
- 是否存在未揭露資助。
- 是否以投資或觀光交換政治聲明。
- 是否形成危機期間的影響網絡。

## 五、媒體與資訊

### 風險

- 股權與廣告資金不透明。
- 內容農場與境外協同帳號。
- 假民調、深偽與剪輯影片。
- 分化美韓同盟與日韓合作。

### 防禦

- 媒體最終受益人揭露。
- 政治廣告與境外資助標示。
- 平台協同行為透明報告。
- 政府單一事件事實頁。
- 民間查核與學術研究。
- 不以反假訊息壓制合法批評。

## 六、VPN與eSIM

### 高風險組合

- 最終控制人不透明。
- 資料中心、SM-DP+或流量出口位於高風險法域。
- 同一集團控制VPN、eSIM、廣告與身分平台。
- 異常低價鎖定軍公教、媒體、學生或科技人員。
- App要求過多權限或安裝根憑證。
- 沒有獨立安全稽核。

### 政策

- 軍政設備禁止未核准公共VPN與旅遊eSIM。
- 建立供應商白名單。
- 要求控制權變更通報。
- 審查流量出口與上游電信商。
- MDM限制側載、根憑證及設定檔。
- 建立危機時停用供應商能力。

## 七、雲端、資料中心與電信

- 儲存地與備份地透明。
- 政府資料不得集中於單一供應商。
- 遠端維護最小權限。
- 高風險供應鏈隔離。
- 軟體更新需簽章及驗證。
- 建立離線與跨雲復原。
- 多家電信與衛星備援。

## 八、半導體、電池與關鍵礦物

- 最終來源清冊。
- 重要原料最低庫存。
- 單一來源依賴門檻。
- 與美、日、澳、歐建立替代合作。
- 企業遭報復時融資與市場支援。
- 物流、保險與海運應變。

## 九、經濟脅迫情境

| 工具 | 風險 | 預防 |
|---|---|---|
| 海關與檢疫 | 出口延遲 | 市場多元化 |
| 觀光與文化 | 服務業受創 | 國內及第三國支援 |
| 關鍵原料 | 生產停擺 | 庫存與替代 |
| 在中韓企 | 資產及人員風險 | 撤離與保險 |
| 金融與支付 | 流動性壓力 | 盟國金融支援 |
| 輿論抵制 | 品牌與政治壓力 | 透明溝通 |

## 十、反間諜與高權限管理

- 任用前查核。
- 高權限持續查核。
- 最小權限與職務分離。
- 異常下載及登入監控。
- 離職即時撤權。
- 退休後敏感接觸通報。
- 債務、脅迫與家屬支援。
- 主動通報減責及保護。

## 十一、司法與權利護欄

- 秘密委託需具體定義。
- 司法審查與比例原則。
- 犯罪所得依法沒收。
- 保護證人與通報者。
- 不以政治立場、國籍或族裔推定犯罪。

## 十二、政府與企業分工

### 政府

- 制定風險標準。
- 提供情報與預警。
- 建立企業緊急支援。
- 協調盟國替代市場。

### 企業

- 揭露控制權與資料流。
- 執行供應鏈稽核。
- 建立替代供應商。
- 通報外國政府異常要求。
- 保護員工與客戶資料。

## 十三、KPI

| 領域 | 指標 |
|---|---|
| 政治資金 | 最終受益人揭露率 |
| VPN/eSIM | 核准供應商覆蓋率 |
| 雲端 | 跨供應商復原時間 |
| 關鍵礦物 | 單一來源依賴比例 |
| 企業 | 庫存與替代市場 |
| 反間諜 | 線索至權限隔離時間 |
| 媒體 | 境外資金透明度 |
| 法治 | 司法覆核品質 |

## 十四、結論

目標不是切斷所有對中交流，而是：

> 任何外國政府都不能透過隱藏控制權、資料集中、經濟依賴或秘密委託，在危機時快速改變韓國決策。

## 評估方法

| 等級 | 定義 | 使用方式 |
|---|---|---|
| A | 官方法律、制度、公開軍事活動與確認案件 | 基準事實 |
| B | 官方威脅評估、可信研究與多來源支持 | 主要判斷 |
| C | 依公開能力建立的條件式推演 | 明確標示情境 |
| D | 未交叉驗證傳聞 | 不納入核心結論 |

判斷同時觀察：朝鮮半島軍事風險、臺海外溢、政治與經濟脅迫、政府持續能力、美韓同盟及日韓協同。
