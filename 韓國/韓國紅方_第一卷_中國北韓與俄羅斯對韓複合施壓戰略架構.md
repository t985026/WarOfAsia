# 韓國紅方｜第一卷：中國、北韓與俄羅斯對韓複合施壓戰略架構

## 一、執行摘要

韓國紅方不應被簡化成「北韓直接進攻韓國」。在2027臺海戰爭外溢情境中，更可能形成三層架構：

1. **中國主導政治與戰略塑形**：迫使韓國限制美軍支援、維持中立、延遲與日本及臺灣協同。  
2. **北韓提供軍事與心理牽制**：以核飛彈、邊境、海上、網路及宣傳迫使韓國保留主要兵力。  
3. **俄羅斯提供間接緩衝**：在外交、能源、制裁規避、資訊敘事及其他戰區增加壓力。  

紅方的理想成果不是占領韓國，而是：

> 韓國仍存在，但政治決策受限、駐韓美軍無法支援臺海、日韓合作失靈、企業害怕中國報復，社會將臺海支援視為對韓國本土安全的直接威脅。

## 二、紅方戰略目標

### 2.1 最低目標

- 韓國不直接參與臺海軍事行動。
- 駐韓美軍不大量調往臺海。
- 韓國不開放基地或後勤設施支援對中作戰。
- 韓國不加入最嚴厲金融與科技制裁。

### 2.2 中度目標

- 韓國政府與反對黨因臺海政策嚴重分裂。
- 日韓情報及飛彈預警合作受阻。
- 韓國企業反對政府配合美國。
- 中國經濟脅迫使韓國採取模糊或中立立場。

### 2.3 最大目標

- 美韓同盟可信度下降。
- 韓國要求限制駐韓美軍區域任務。
- 韓國與日本安全合作中止。
- 北韓利用危機取得軍事或政治讓步。
- 韓國在區域安全架構中被迫戰略中立化。

## 三、紅方九層架構

| 層級 | 主體 | 主要作用 |
|---|---|---|
| 1 | 中國政治領導 | 決定對韓施壓程度與臺海目標 |
| 2 | 中國外交及統戰網絡 | 塑造中立、反美、反日與和平敘事 |
| 3 | 中國經貿及市場工具 | 關鍵原料、海關、企業與消費壓力 |
| 4 | 中國情報與網路體系 | 蒐集決策、供應鏈、同盟與社會資料 |
| 5 | 中國軍事與灰色地帶 | 對韓國周邊施壓但避免過早觸發戰爭 |
| 6 | 北韓核飛彈與常規軍 | 製造第二戰場及高度不確定性 |
| 7 | 北韓網路、金融與宣傳 | 擾亂金融、政府與社會信任 |
| 8 | 俄羅斯外交與制裁緩衝 | 支持中朝敘事、分散美歐注意力 |
| 9 | 商業、社團與犯罪代理 | 提供可否認的資訊、金流與秩序干擾 |

## 四、紅方作戰邏輯

```text
放大韓國對北韓威脅的焦慮
        ↓
宣稱臺海支援會削弱半島防衛
        ↓
以經濟成本迫使企業與地方反對政府
        ↓
以假消息及政治爭議分裂美韓、日韓
        ↓
北韓提高飛彈、邊境與網路壓力
        ↓
迫使韓國保留兵力並限制基地支援
        ↓
中國在臺海取得更大決策與時間空間
```

## 五、紅方優先避免的結果

紅方會盡量避免：

- 直接攻擊韓國領土而觸發美韓共同防衛。
- 使韓國政黨形成罕見的反中共識。
- 過度經濟報復而促使韓國供應鏈永久脫中。
- 北韓失控造成全面半島戰爭。
- 攻擊韓國商船、公民或基地，讓日本與澳洲更容易加入。
- 可驗證的秘密資金與指揮證據被公開。

## 六、紅方時間軸

### 平時

- 累積政治、媒體、學術、企業與地方關係。
- 建立對韓供應鏈依賴與資料掌握。
- 蒐集基地、同盟、政府及企業決策資訊。
- 放大歷史、駐軍、經濟與世代矛盾。

### 臺海危機前30日

- 提醒韓國支援美軍的經濟與安全成本。
- 增加北韓軍事與宣傳活動。
- 影響企業、媒體及地方政府要求中立。
- 對韓網路與金融系統進行更多偵察。

### 開戰後72小時

- 中國警告韓國不得開放基地。
- 北韓提高核飛彈與邊境警戒。
- 散布假美軍撤離、假動員及假政府協議。
- 對韓國企業、金融與通信施加可控壓力。

### 第4至30日

- 依韓國支援程度調整經濟脅迫。
- 鼓勵韓國國內要求停火與限制同盟支援。
- 北韓維持「接近戰爭但未全面開戰」狀態。
- 利用俄羅斯及全球南方推動反制裁敘事。

## 七、紅方成熟度模型

| 等級 | 狀態 |
|---|---|
| 0 | 一般外交與商業接觸 |
| 1 | 敘事與利益關係累積 |
| 2 | 金流、媒體、企業與地方影響網絡 |
| 3 | 對韓供應鏈、資料與政治弱點系統化掌握 |
| 4 | 臺海危機期間跨領域協同施壓 |
| 5 | 北韓軍事牽制與中國經濟資訊工具同步 |
| 6 | 韓國同盟、政府與社會出現實質決策失能 |

## 八、紅方成功指標

- 韓國公開限制駐韓美軍區域使用。
- 韓國拒絕與日本交換重要情報。
- 韓國只發表中立或停火聲明，不加入實質措施。
- 韓國企業與地方政府公開反對中央政策。
- 韓國社會將中國經濟報復視為政府支援臺海的責任。
- 北韓未全面開戰但成功牽制韓美大部分注意力。

## 九、紅方失敗指標

- 韓國形成跨黨派最低國安共識。
- 駐韓美軍調動已有替代與增援，半島嚇阻未下降。
- 日韓美即時共享飛彈及網路情報。
- 韓國企業獲得盟國市場、金融與原料支援。
- 中國秘密資金、資料控制與協同行動被依法公開。
- 北韓挑釁反而促使韓國、日、美安全合作深化。

## 十、本卷結論

紅方最有效的策略不是全面攻韓，而是：

> 以北韓製造不能忽視的軍事風險，以中國提供不能忽視的經濟代價，再利用韓國內部政治分歧，使韓國自行限制對美、日、臺的支援。

### 紅方分析六軸

1. **政治目的**：是否要迫使韓國中立、退出同盟或限制基地支援。  
2. **工具組合**：政治、經濟、外交、情報、網路、軍事與犯罪代理是否同步。  
3. **第二戰場**：北韓是否能牽制美韓日兵力與決策。  
4. **可否認性**：是否利用商業、媒體、社團、網路犯罪或灰色地帶降低歸責。  
5. **成本控制**：紅方是否避免直接攻擊韓國，以防觸發美韓共同防衛。  
6. **失敗條件**：哪些藍方反應會使紅方分化、脅迫與牽制失效。
