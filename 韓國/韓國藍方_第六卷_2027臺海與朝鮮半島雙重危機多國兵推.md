# 韓國藍方｜第六卷：2027臺海與朝鮮半島雙重危機多國兵推

## 一、兵推角色

| 角色 | 主要目標 |
|---|---|
| 韓國藍方 | 保衛半島、維持政府與同盟 |
| 北韓紅方一 | 牽制韓美、提高政治利益 |
| 中國紅方二 | 阻止韓國支援美臺、分化同盟 |
| 美國盟方 | 嚇阻北韓並支援臺海 |
| 日本盟方 | 保護本土、基地與區域交通 |
| 臺灣合作方 | 維持政府並取得支援 |
| 俄羅斯支援方 | 支持中朝、分散美歐 |
| 澳洲/歐洲 | 情報、制裁、後勤與人道 |
| 國際市場 | 航運、金融、能源與供應鏈反應 |

## 二、初始條件

- 中國對臺發動武裝行動。
- 臺灣通信與基礎設施嚴重受損。
- 北韓提高飛彈及軍事戒備。
- 中國要求韓國限制美軍基地支援。
- 韓國社群出現假美軍撤離與假動員。
- 中國對韓企業及供應鏈施壓。
- 美國要求後方支援，但仍需防範北韓。

## 三、戰前30日

### 中國

- 增加對韓政治與媒體壓力。
- 暗示經濟報復。
- 要求韓國保持中立。

### 北韓

- 強化軍事宣傳。
- 進行飛彈與網路準備。
- 觀察韓美調動。

### 韓國

- 監測同步性。
- 清查經濟與資安風險。
- 與美日秘密磋商。
- 避免過早造成市場恐慌。

## 四、戰前72小時

- 北韓部隊及飛彈活動增加。
- 中國宣布臺海大規模軍演。
- 韓國金融與航運市場波動。
- 駐韓美軍提高戒備。
- 韓國保護政府、通信與能源。

## 五、開戰後0至6小時

### 中國

- 攻擊臺灣並警告韓國不得支援。
- 對韓社群散布假消息。
- 對企業與網路施壓。

### 北韓

- 提高警戒與宣傳。
- 暫不發動大規模攻擊。

### 韓國

- 啟動國家危機管理。
- 美韓確認半島戰力。
- 保護基地、政府及金融。
- 暫不宣布直接參與臺海。

### 裁決

韓國維持半島嚇阻，但政治與市場壓力快速增加。

## 六、6至24小時

### 北韓保持克制

韓國可：

- 提供美軍情報與後勤。
- 支援臺灣資安、通信與醫療。
- 參與制裁。

### 北韓有限挑釁

韓國：

- 提高半島兵力。
- 限制臺海直接支援。
- 與日本加強飛彈預警。

### 北韓重大攻擊

韓國：

- 半島防衛絕對優先。
- 美韓共同防衛。
- 臺海支援以外交、後勤與情報為主。

## 七、24至72小時

### 中國未攻擊韓國

- 韓國進行有限後方支援。
- 對中制裁仍有國內爭議。
- 中國加大經濟與資訊壓力。

### 中國攻擊韓國船艦或基地

- 韓國直接介入風險大幅上升。
- 美韓共同防衛啟動可能增加。
- 日本與澳洲支援擴大。

### 北韓與中國同步行動

- 韓國保留主要兵力。
- 美國同時處理兩個戰場。
- 日韓情報合作成為關鍵。

## 八、第4至14日三條路線

| 路線 | 可能性 | 結果 |
|---|---:|---|

| 中國攻擊韓國資產 | 10–25% | 韓國對中政策急劇轉向 |

## 九、第15至30日

| 結果 | 可能性 |
|---|---:|
| 韓國政府與軍隊有效運作 | 85–95% |
| 北韓未發動全面戰爭 | 80–95% |
| 韓國持續後方支援 | 55–75% |
| 韓國直接參與臺海作戰 | 5–15% |
| 中國對韓重大經濟脅迫 | 60–85% |
| 韓中關係長期對抗 | 50–75% |
| 日韓安全合作加深 | 55–75% |

## 十、90日情境

### A：長期臺海戰爭、半島未開戰

- 韓國成為美軍後方與產業支援節點。
- 中國經濟報復加深。
- 日韓合作增加但國內爭議持續。

### B：北韓長期挑釁

- 韓國維持高警戒。
- 經濟與社會成本上升。
- 美國兵力配置更困難。

### C：半島軍事衝突

- 臺海與半島形成真正雙戰場。
- 美國、日本與澳洲資源被分散。
- 全球市場衝擊擴大。

## 十一、一年情境

### 韓國維持自主與同盟

- 美韓同盟制度化。
- 對中依賴降低。
- 國防、資安與民防支出增加。

### 韓國遭經濟與政治分化

- 對中政策反覆。
- 美韓日協同受阻。
- 企業與社會承擔長期成本。

### 北韓趁機改變現狀

通常需同時出現：

- 美韓預警與指揮失效。
- 駐韓美軍過度調離。
- 韓國內部政治癱瘓。
- 中俄提供重大支援。

## 十二、主要決策分岔

1. 北韓是否動武。  
2. 中國是否攻擊韓國。  
3. 駐韓美軍是否調動。  
4. 韓國是否提供基地支援。  
5. 日本與韓國是否合作。  
6. 中國經濟報復程度。  
7. 韓國內部政治是否形成最低共識。  
8. 俄羅斯是否加強支援中朝。  

## 十三、韓國藍方勝利條件

- 北韓未改變半島現狀。
- 政府與美韓指揮持續。
- 經濟脅迫未迫使韓國退出同盟。
- 國內未因假消息與政治分裂失能。
- 韓國能提供有限但持續區域支援。
- 直接戰爭未因誤判擴大。

## 十四、結論

最可能的韓國角色不是第一線臺海參戰國，而是：

> 朝鮮半島防衛核心、駐韓美軍後方節點、區域情報與資安夥伴，以及半導體、造船、醫療與供應鏈支援國。
