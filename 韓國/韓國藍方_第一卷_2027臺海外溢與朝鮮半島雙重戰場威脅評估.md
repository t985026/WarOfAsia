# 韓國藍方｜第一卷：2027臺海外溢與朝鮮半島雙重戰場威脅評估

## 一、執行摘要

韓國面對2027臺海戰爭時，不能只問「是否援助臺灣」，而必須同步處理：

- 北韓核武、飛彈、邊境、海上與網路挑釁。
- 駐韓美軍是否調動，以及半島防衛是否被削弱。
- 中國對韓政治、經濟、媒體與社會分化。
- 日本與韓國是否維持情報及飛彈預警合作。
- 韓國產業、能源、金融與供應鏈是否遭報復。
- 臺海與朝鮮半島是否形成雙重危機。

韓國藍方的勝利條件是：

> 北韓無法利用臺海戰爭改變半島現狀，中國無法以政治與經濟脅迫迫使韓國退出美韓同盟，韓國政府、軍隊、社會與產業能持續運作。

## 二、國家安全基準

### 2.1 首要威脅

1. 北韓核武與彈道飛彈。  
2. 首都圈近距離軍事壓力。  
3. 北韓網路、金融與情報行動。  
4. 中國經濟脅迫及政治影響。  
5. 臺海戰爭造成美軍調動與供應鏈衝擊。  
6. 俄中朝合作擴大韓國決策壓力。  

### 2.2 韓國優勢

- 美韓同盟與駐韓美軍。
- 半導體、造船、電池、通信與工業能力。
- 完整政府與地方行政體系。
- 民防、乙支演習及災害管理制度。
- 與美、日、澳、歐洲的合作網絡。

### 2.3 主要脆弱面

- 首都圈人口與功能高度集中。
- 對外能源及原料依賴。
- 與中國的貿易及供應鏈關聯。
- 對美、中、日與北韓政策高度政治化。
- 高度依賴電力、雲端、金融與通信。

## 三、五種雙重戰場情境

| 情境 | 北韓狀態 | 中國狀態 | 韓國主要任務 |
|---|---|---|---|
| A | 克制 | 對臺作戰 | 後方支援與經濟安全 |
| B | 提高戒備 | 對臺作戰 | 保留兵力、強化預警 |
| C | 有限挑釁 | 對臺作戰 | 雙重危機管理 |
| D | 重大攻擊 | 對臺作戰 | 半島防衛優先 |
| E | 北韓配合、中國對韓施壓 | 區域聯動 | 美韓同盟與政府持續運作 |

## 四、基準可能性

| 情境 | 臺海開戰後30日內可能性 |
|---|---:|
| 北韓提高軍事戒備與宣傳 | 70–90% |
| 北韓飛彈試射或有限挑釁 | 45–70% |
| 北韓大型網路與金融攻擊 | 45–70% |
| 北韓全面戰爭 | 5–15% |
| 中國對韓經濟施壓 | 60–85% |
| 中國對韓資訊與政治分化 | 80–95% |
| 韓國提供美軍後方支援 | 50–75% |
| 韓國直接派兵臺海 | 5–15% |
| 中國直接攻擊韓國資產 | 10–25% |

## 五、北韓第二戰場目的

- 迫使韓國保留主要兵力。
- 阻止駐韓美軍向其他地區調動。
- 分散日本與美國飛彈預警資源。
- 以網路及金融攻擊增加社會成本。
- 透過假動員與假戰爭訊息製造恐慌。
- 爭取政治、經濟或軍事交換利益。

## 六、中國對韓主要壓力

### 政治

- 放大「臺海與韓國無關」。
- 製造反美與反日爭議。
- 宣稱支援美軍會使韓國成為戰場。
- 放大政府與反對黨外交分歧。

### 經濟

- 海關與行政限制。
- 關鍵原料與零組件供應。
- 觀光、留學、文化與消費市場。
- 在中韓企資產及人員壓力。

### 資訊

- 假美軍撤離。
- 假政府同意提供臺海基地。
- 假北韓即將開戰。
- 假銀行倒閉與能源不足。
- 假日本重新軍事化。

## 七、駐韓美軍調動底線

- 預警及情報能力不得失效。
- 防空、飛彈與延伸嚇阻溝通不中斷。
- 關鍵基地與後勤仍可防衛半島。
- 北韓升高警戒時，調動須立即重估。
- 任何調動都需替代與增援方案。

## 八、日韓合作

可合作：

- 飛彈預警與海空情報。
- 撤僑與人道支援。
- 北韓網路威脅。
- 海纜、航運與供應鏈。
- 對中國與北韓制裁。

限制：

- 歷史問題與國內政治。
- 日本軍事角色爭議。
- 中國與北韓的分化宣傳。

## 九、風險上修條件

- 北韓與中國同步軍演或政治聲明。
- 北韓部隊、飛彈與核指揮異常。
- 中國要求韓國限制美軍基地使用。
- 韓國關鍵產業遭突然制裁。
- 韓國社會因臺海支援嚴重分裂。
- 中國攻擊韓國船艦、航空器、基地或公民。

## 十、風險下修條件

- 美韓公開確認半島防衛底線。
- 北韓未出現實質動員。
- 美日韓維持情報及危機溝通。
- 企業取得替代供應與市場。
- 政府透明說明基地及支援政策。
- 國內政黨形成最低國安共識。

## 十一、0至30日決策

### 戰前30日至72小時

- 監測中朝同步性。
- 清查基地、經濟與資安風險。
- 驗證政府與地方命令。

### 0至24小時

- 判斷臺海是否正式武裝衝突。
- 提高北韓警戒。
- 確保美韓聯合指揮。
- 預備經濟與網路反制。

### 24至72小時

- 決定基地及後勤支援程度。
- 與日本協調情報與預警。
- 啟動撤僑及外國居民支援。

### 第4至30日

- 處理供應鏈與經濟脅迫。
- 維持民防、醫療與政府運作。
- 防止政治分裂。
- 準備長期區域對峙。

## 十二、結論

韓國最危險的不是單純臺海戰爭，而是：

> 臺海衝突、北韓挑釁、中國經濟脅迫、日韓政治摩擦與韓國內部假訊息同時發生。
