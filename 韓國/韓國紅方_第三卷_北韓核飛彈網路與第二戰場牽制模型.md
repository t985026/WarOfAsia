# 韓國紅方｜第三卷：北韓核飛彈、網路與第二戰場牽制模型

## 一、核心判斷

在臺海戰爭期間，北韓最具戰略價值的角色不一定是發動全面戰爭，而是維持一個：

> 韓國與美國不能忽視、不能確定是否會升級、也不能輕易抽調兵力的高風險狀態。

## 二、北韓目標

- 迫使韓國保留主要軍力。
- 阻止駐韓美軍向臺海調動。
- 分散日本預警與飛彈防禦。
- 取得制裁、援助、政治或軍事談判利益。
- 配合中國削弱美韓日同盟。
- 測試韓國政府與社會韌性。

## 三、第二戰場工具

| 工具 | 目的 | 升級風險 |
|---|---|---:|
| 宣傳與假消息 | 製造恐慌及政治分裂 | 低 |
| 網路與金融攻擊 | 擾亂政府、銀行與企業 | 中 |
| 飛彈試射 | 迫使美韓日提高警戒 | 中 |
| 海上或邊境事件 | 消耗反應並測試紅線 | 中高 |
| 大規模軍演與動員 | 阻止兵力調離 | 高 |
| 有限武裝攻擊 | 迫使半島防衛優先 | 極高 |
| 核武威脅或使用 | 改變整個區域戰爭 | 極高 |

## 四、北韓升級階梯

### 第一級：資訊與網路

- 假美軍撤離。
- 假韓國動員。
- 金融及加密資產攻擊。
- 政府與媒體帳號冒用。

### 第二級：軍事展示

- 飛彈試射。
- 空中、海上及邊境活動。
- 核與戰略力量宣傳。
- 部隊休假取消或演訓增加。

### 第三級：有限挑釁

- 製造局部事件。
- 迫使韓國分散軍力。
- 同時提出談判或政治條件。

### 第四級：重大攻擊

- 使朝鮮半島防衛完全取代臺海支援。
- 但同時承擔美韓直接反擊及政權風險。

## 五、北韓為何可能避免全面戰爭

- 美國延伸嚇阻及美韓聯合防衛。
- 全面戰爭可能威脅政權生存。
- 中國未必希望失控的半島戰爭。
- 北韓可透過有限挑釁取得牽制效果。
- 全面戰爭會破壞經濟、政權控制及中國臺海計畫。

## 六、中朝協同的不同程度

| 等級 | 狀態 |
|---|---|
| 0 | 各自行動，沒有可驗證協同 |
| 1 | 相近敘事與時機，但可能是機會主義 |
| 2 | 外交、宣傳與軍事活動節奏一致 |
| 3 | 中國壓力與北韓挑釁明顯互補 |
| 4 | 出現情報、物資或任務協調證據 |
| 5 | 形成可驗證的聯合危機計畫 |

不得因活動同時發生就自動判定有直接指揮關係。

## 七、網路與金融方向

北韓可把重點放在：

- 銀行、加密資產及支付。
- 政府與軍方帳號。
- 媒體及警報系統。
- 供應鏈與遠端維護。
- 國防承包商及研究機構。

公開文件只列風險類別，不提供入侵方法與目標細節。

## 八、紅方成功條件

- 韓國過度反應，造成金融或交通自我停擺。
- 假警報及假命令破壞政府信任。
- 韓國停止與日本共享預警。
- 駐韓美軍調動受到政治阻力。
- 中國利用北韓威脅迫使韓國中立。
- 美韓對北韓意圖判斷不一致。

## 九、紅方失敗條件

- 美韓預先確認半島戰力底線。
- 日韓美即時共享飛彈預警。
- 韓國政府命令具多重驗證。
- 網路與金融系統可降級不停擺。
- 北韓挑釁被精準、比例且一致回應。
- 中國被迫公開承擔支持北韓升級的政治成本。

## 十、藍方預警指標

- 北韓飛彈、核、邊境與網路活動同步。
- 軍事活動超出演訓需求。
- 對美軍調動及韓國基地論述突然增加。
- 北韓提出與中國相似的臺海敘事。
- 俄羅斯與北韓物資、技術或外交互動增加。
- 韓國金融、通信與警報系統同時遭到異常。

## 十一、本卷結論

北韓第二戰場的最佳紅方效果是：

> 不必真正全面開戰，只要讓韓國與美國無法確定會不會開戰，就能限制兵力、後勤與政治決策。

## 評估與證據分級

| 等級 | 定義 | 文件用法 |
|---|---|---|
| A級 | 官方法律、制度、公開軍事活動、制裁措施與確認案件 | 基準事實 |
| B級 | 官方威脅評估、可信研究、多來源一致判斷 | 主要推論依據 |
| C級 | 依公開能力與行為建立的條件式情境 | 必須標示「推演」 |
| D級 | 未交叉驗證傳聞、單一匿名指控 | 不納入核心結論 |

### 紅方分析六軸

1. **政治目的**：是否要迫使韓國中立、退出同盟或限制基地支援。  
2. **工具組合**：政治、經濟、外交、情報、網路、軍事與犯罪代理是否同步。  
3. **第二戰場**：北韓是否能牽制美韓日兵力與決策。  
4. **可否認性**：是否利用商業、媒體、社團、網路犯罪或灰色地帶降低歸責。  
5. **成本控制**：紅方是否避免直接攻擊韓國，以防觸發美韓共同防衛。  
6. **失敗條件**：哪些藍方反應會使紅方分化、脅迫與牽制失效。
