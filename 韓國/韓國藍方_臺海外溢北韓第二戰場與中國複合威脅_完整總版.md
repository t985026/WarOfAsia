# 韓國藍方｜第一卷：2027臺海外溢與朝鮮半島雙重戰場威脅評估

## 一、執行摘要

韓國面對2027臺海戰爭時，不能只問「是否援助臺灣」，而必須同步處理：

- 北韓核武、飛彈、邊境、海上與網路挑釁。
- 駐韓美軍是否調動，以及半島防衛是否被削弱。
- 中國對韓政治、經濟、媒體與社會分化。
- 日本與韓國是否維持情報及飛彈預警合作。
- 韓國產業、能源、金融與供應鏈是否遭報復。
- 臺海與朝鮮半島是否形成雙重危機。

韓國藍方的勝利條件是：

> 北韓無法利用臺海戰爭改變半島現狀，中國無法以政治與經濟脅迫迫使韓國退出美韓同盟，韓國政府、軍隊、社會與產業能持續運作。

## 二、國家安全基準

### 2.1 首要威脅

1. 北韓核武與彈道飛彈。  
2. 首都圈近距離軍事壓力。  
3. 北韓網路、金融與情報行動。  
4. 中國經濟脅迫及政治影響。  
5. 臺海戰爭造成美軍調動與供應鏈衝擊。  
6. 俄中朝合作擴大韓國決策壓力。  

### 2.2 韓國優勢

- 美韓同盟與駐韓美軍。
- 半導體、造船、電池、通信與工業能力。
- 完整政府與地方行政體系。
- 民防、乙支演習及災害管理制度。
- 與美、日、澳、歐洲的合作網絡。

### 2.3 主要脆弱面

- 首都圈人口與功能高度集中。
- 對外能源及原料依賴。
- 與中國的貿易及供應鏈關聯。
- 對美、中、日與北韓政策高度政治化。
- 高度依賴電力、雲端、金融與通信。

## 三、五種雙重戰場情境

| 情境 | 北韓狀態 | 中國狀態 | 韓國主要任務 |
|---|---|---|---|
| A | 克制 | 對臺作戰 | 後方支援與經濟安全 |
| B | 提高戒備 | 對臺作戰 | 保留兵力、強化預警 |
| C | 有限挑釁 | 對臺作戰 | 雙重危機管理 |
| D | 重大攻擊 | 對臺作戰 | 半島防衛優先 |
| E | 北韓配合、中國對韓施壓 | 區域聯動 | 美韓同盟與政府持續運作 |

## 四、基準可能性

| 情境 | 臺海開戰後30日內可能性 |
|---|---:|
| 北韓提高軍事戒備與宣傳 | 70–90% |
| 北韓飛彈試射或有限挑釁 | 45–70% |
| 北韓大型網路與金融攻擊 | 45–70% |
| 北韓全面戰爭 | 5–15% |
| 中國對韓經濟施壓 | 60–85% |
| 中國對韓資訊與政治分化 | 80–95% |
| 韓國提供美軍後方支援 | 50–75% |
| 韓國直接派兵臺海 | 5–15% |
| 中國直接攻擊韓國資產 | 10–25% |

## 五、北韓第二戰場目的

- 迫使韓國保留主要兵力。
- 阻止駐韓美軍向其他地區調動。
- 分散日本與美國飛彈預警資源。
- 以網路及金融攻擊增加社會成本。
- 透過假動員與假戰爭訊息製造恐慌。
- 爭取政治、經濟或軍事交換利益。

## 六、中國對韓主要壓力

### 政治

- 放大「臺海與韓國無關」。
- 製造反美與反日爭議。
- 宣稱支援美軍會使韓國成為戰場。
- 放大政府與反對黨外交分歧。

### 經濟

- 海關與行政限制。
- 關鍵原料與零組件供應。
- 觀光、留學、文化與消費市場。
- 在中韓企資產及人員壓力。

### 資訊

- 假美軍撤離。
- 假政府同意提供臺海基地。
- 假北韓即將開戰。
- 假銀行倒閉與能源不足。
- 假日本重新軍事化。

## 七、駐韓美軍調動底線

- 預警及情報能力不得失效。
- 防空、飛彈與延伸嚇阻溝通不中斷。
- 關鍵基地與後勤仍可防衛半島。
- 北韓升高警戒時，調動須立即重估。
- 任何調動都需替代與增援方案。

## 八、日韓合作

可合作：

- 飛彈預警與海空情報。
- 撤僑與人道支援。
- 北韓網路威脅。
- 海纜、航運與供應鏈。
- 對中國與北韓制裁。

限制：

- 歷史問題與國內政治。
- 日本軍事角色爭議。
- 中國與北韓的分化宣傳。

## 九、風險上修條件

- 北韓與中國同步軍演或政治聲明。
- 北韓部隊、飛彈與核指揮異常。
- 中國要求韓國限制美軍基地使用。
- 韓國關鍵產業遭突然制裁。
- 韓國社會因臺海支援嚴重分裂。
- 中國攻擊韓國船艦、航空器、基地或公民。

## 十、風險下修條件

- 美韓公開確認半島防衛底線。
- 北韓未出現實質動員。
- 美日韓維持情報及危機溝通。
- 企業取得替代供應與市場。
- 政府透明說明基地及支援政策。
- 國內政黨形成最低國安共識。

## 十一、0至30日決策

### 戰前30日至72小時

- 監測中朝同步性。
- 清查基地、經濟與資安風險。
- 驗證政府與地方命令。

### 0至24小時

- 判斷臺海是否正式武裝衝突。
- 提高北韓警戒。
- 確保美韓聯合指揮。
- 預備經濟與網路反制。

### 24至72小時

- 決定基地及後勤支援程度。
- 與日本協調情報與預警。
- 啟動撤僑及外國居民支援。

### 第4至30日

- 處理供應鏈與經濟脅迫。
- 維持民防、醫療與政府運作。
- 防止政治分裂。
- 準備長期區域對峙。

## 十二、結論

韓國最危險的不是單純臺海戰爭，而是：

> 臺海衝突、北韓挑釁、中國經濟脅迫、日韓政治摩擦與韓國內部假訊息同時發生。

# 韓國藍方｜第二卷：中國政治滲透、經濟脅迫與通信供應鏈預防

## 一、目的

建立在法治下防止外國政府利用秘密委託、企業控制、資料集中、經濟依賴及通信供應鏈影響韓國決策的制度。

## 二、證據標準

不能以親中、反美、反日或不同外交立場直接推定滲透。高風險指標包括：

- 隱瞞外國政府或黨國委託。
- 不透明金流與最終受益人。
- 取得軍政或關鍵產業敏感資料。
- 危機期間接受待命或同步任務。
- 控制媒體、資料、電信或高權限系統。
- 有證據顯示與外國官方行動協同。

## 三、政治資金與秘密委託

- 政治獻金與第三方資金揭露。
- 政黨、媒體、智庫與學術資助透明。
- 最終受益人及實際控制人登記。
- 外國政府委託登記。
- 違法金流凍結與司法程序。
- 保護記者、學者、僑民與合法團體。

## 四、地方政府與交流

需確認：

- 是否涉及敏感基礎設施。
- 是否要求政府或個人資料。
- 是否存在未揭露資助。
- 是否以投資或觀光交換政治聲明。
- 是否形成危機期間的影響網絡。

## 五、媒體與資訊

### 風險

- 股權與廣告資金不透明。
- 內容農場與境外協同帳號。
- 假民調、深偽與剪輯影片。
- 分化美韓同盟與日韓合作。

### 防禦

- 媒體最終受益人揭露。
- 政治廣告與境外資助標示。
- 平台協同行為透明報告。
- 政府單一事件事實頁。
- 民間查核與學術研究。
- 不以反假訊息壓制合法批評。

## 六、VPN與eSIM

### 高風險組合

- 最終控制人不透明。
- 資料中心、SM-DP+或流量出口位於高風險法域。
- 同一集團控制VPN、eSIM、廣告與身分平台。
- 異常低價鎖定軍公教、媒體、學生或科技人員。
- App要求過多權限或安裝根憑證。
- 沒有獨立安全稽核。

### 政策

- 軍政設備禁止未核准公共VPN與旅遊eSIM。
- 建立供應商白名單。
- 要求控制權變更通報。
- 審查流量出口與上游電信商。
- MDM限制側載、根憑證及設定檔。
- 建立危機時停用供應商能力。

## 七、雲端、資料中心與電信

- 儲存地與備份地透明。
- 政府資料不得集中於單一供應商。
- 遠端維護最小權限。
- 高風險供應鏈隔離。
- 軟體更新需簽章及驗證。
- 建立離線與跨雲復原。
- 多家電信與衛星備援。

## 八、半導體、電池與關鍵礦物

- 最終來源清冊。
- 重要原料最低庫存。
- 單一來源依賴門檻。
- 與美、日、澳、歐建立替代合作。
- 企業遭報復時融資與市場支援。
- 物流、保險與海運應變。

## 九、經濟脅迫情境

| 工具 | 風險 | 預防 |
|---|---|---|
| 海關與檢疫 | 出口延遲 | 市場多元化 |
| 觀光與文化 | 服務業受創 | 國內及第三國支援 |
| 關鍵原料 | 生產停擺 | 庫存與替代 |
| 在中韓企 | 資產及人員風險 | 撤離與保險 |
| 金融與支付 | 流動性壓力 | 盟國金融支援 |
| 輿論抵制 | 品牌與政治壓力 | 透明溝通 |

## 十、反間諜與高權限管理

- 任用前查核。
- 高權限持續查核。
- 最小權限與職務分離。
- 異常下載及登入監控。
- 離職即時撤權。
- 退休後敏感接觸通報。
- 債務、脅迫與家屬支援。
- 主動通報減責及保護。

## 十一、司法與權利護欄

- 秘密委託需具體定義。
- 司法審查與比例原則。
- 犯罪所得依法沒收。
- 保護證人與通報者。
- 不以政治立場、國籍或族裔推定犯罪。

## 十二、政府與企業分工

### 政府

- 制定風險標準。
- 提供情報與預警。
- 建立企業緊急支援。
- 協調盟國替代市場。

### 企業

- 揭露控制權與資料流。
- 執行供應鏈稽核。
- 建立替代供應商。
- 通報外國政府異常要求。
- 保護員工與客戶資料。

## 十三、KPI

| 領域 | 指標 |
|---|---|
| 政治資金 | 最終受益人揭露率 |
| VPN/eSIM | 核准供應商覆蓋率 |
| 雲端 | 跨供應商復原時間 |
| 關鍵礦物 | 單一來源依賴比例 |
| 企業 | 庫存與替代市場 |
| 反間諜 | 線索至權限隔離時間 |
| 媒體 | 境外資金透明度 |
| 法治 | 司法覆核品質 |

## 十四、結論

目標不是切斷所有對中交流，而是：

> 任何外國政府都不能透過隱藏控制權、資料集中、經濟依賴或秘密委託，在危機時快速改變韓國決策。

# 韓國藍方｜第三卷：臺海戰爭外溢與北韓第二戰場國家危機應變

## 一、危機分級

| 等級 | 狀態 | 主要行動 |
|---|---|---|
| 1 | 臺海軍演、北韓宣傳 | 強化監控 |
| 2 | 臺海武裝衝突、北韓戒備 | 美韓聯合警戒 |
| 3 | 北韓有限挑釁、網攻、經濟脅迫 | 跨部會應變 |
| 4 | 北韓重大攻擊或中國攻擊韓國資產 | 國家防衛 |
| 5 | 半島全面戰爭 | 全國動員 |

# 韓國藍方｜第四卷：美韓同盟、日韓協同與印太區域支援架構

# 韓國藍方｜第六卷：2027臺海與朝鮮半島雙重危機多國兵推

## 一、兵推角色

| 角色 | 主要目標 |
|---|---|
| 韓國藍方 | 保衛半島、維持政府與同盟 |
| 北韓紅方一 | 牽制韓美、提高政治利益 |
| 中國紅方二 | 阻止韓國支援美臺、分化同盟 |
| 美國盟方 | 嚇阻北韓並支援臺海 |
| 日本盟方 | 保護本土、基地與區域交通 |
| 臺灣合作方 | 維持政府並取得支援 |
| 俄羅斯支援方 | 支持中朝、分散美歐 |
| 澳洲/歐洲 | 情報、制裁、後勤與人道 |
| 國際市場 | 航運、金融、能源與供應鏈反應 |

## 二、初始條件

- 中國對臺發動武裝行動。
- 臺灣通信與基礎設施嚴重受損。
- 北韓提高飛彈及軍事戒備。
- 中國要求韓國限制美軍基地支援。
- 韓國社群出現假美軍撤離與假動員。
- 中國對韓企業及供應鏈施壓。
- 美國要求後方支援，但仍需防範北韓。

## 三、戰前30日

### 中國

- 增加對韓政治與媒體壓力。
- 暗示經濟報復。
- 要求韓國保持中立。

### 北韓

- 強化軍事宣傳。
- 進行飛彈與網路準備。
- 觀察韓美調動。

### 韓國

- 監測同步性。
- 清查經濟與資安風險。
- 與美日秘密磋商。
- 避免過早造成市場恐慌。

## 四、戰前72小時

- 北韓部隊及飛彈活動增加。
- 中國宣布臺海大規模軍演。
- 韓國金融與航運市場波動。
- 駐韓美軍提高戒備。
- 韓國保護政府、通信與能源。

## 五、開戰後0至6小時

### 中國

- 攻擊臺灣並警告韓國不得支援。
- 對韓社群散布假消息。
- 對企業與網路施壓。

### 北韓

- 提高警戒與宣傳。
- 暫不發動大規模攻擊。

### 韓國

- 啟動國家危機管理。
- 美韓確認半島戰力。
- 保護基地、政府及金融。
- 暫不宣布直接參與臺海。

### 裁決

韓國維持半島嚇阻，但政治與市場壓力快速增加。

## 六、6至24小時

### 北韓保持克制

韓國可：

- 提供美軍情報與後勤。
- 支援臺灣資安、通信與醫療。
- 參與制裁。

### 北韓有限挑釁

韓國：

- 提高半島兵力。
- 限制臺海直接支援。
- 與日本加強飛彈預警。

### 北韓重大攻擊

韓國：

- 半島防衛絕對優先。
- 美韓共同防衛。
- 臺海支援以外交、後勤與情報為主。

## 七、24至72小時

### 中國未攻擊韓國

- 韓國進行有限後方支援。
- 對中制裁仍有國內爭議。
- 中國加大經濟與資訊壓力。

### 中國攻擊韓國船艦或基地

- 韓國直接介入風險大幅上升。
- 美韓共同防衛啟動可能增加。
- 日本與澳洲支援擴大。

### 北韓與中國同步行動

- 韓國保留主要兵力。
- 美國同時處理兩個戰場。
- 日韓情報合作成為關鍵。

## 十、90日情境

### A：長期臺海戰爭、半島未開戰

- 韓國成為美軍後方與產業支援節點。
- 中國經濟報復加深。
- 日韓合作增加但國內爭議持續。

### B：北韓長期挑釁

- 韓國維持高警戒。
- 經濟與社會成本上升。
- 美國兵力配置更困難。

### C：半島軍事衝突

- 臺海與半島形成真正雙戰場。
- 美國、日本與澳洲資源被分散。
- 全球市場衝擊擴大。

## 十一、一年情境

### 韓國維持自主與同盟

- 美韓同盟制度化。
- 對中依賴降低。
- 國防、資安與民防支出增加。

### 韓國遭經濟與政治分化

- 對中政策反覆。
- 美韓日協同受阻。
- 企業與社會承擔長期成本。

### 北韓趁機改變現狀

通常需同時出現：

- 美韓預警與指揮失效。
- 駐韓美軍過度調離。
- 韓國內部政治癱瘓。
- 中俄提供重大支援。

## 十二、主要決策分岔

1. 北韓是否動武。  
2. 中國是否攻擊韓國。  
3. 駐韓美軍是否調動。  
4. 韓國是否提供基地支援。  
5. 日本與韓國是否合作。  
6. 中國經濟報復程度。  
7. 韓國內部政治是否形成最低共識。  
8. 俄羅斯是否加強支援中朝。  

## 十三、韓國藍方勝利條件

- 北韓未改變半島現狀。
- 政府與美韓指揮持續。
- 經濟脅迫未迫使韓國退出同盟。
- 國內未因假消息與政治分裂失能。
- 韓國能提供有限但持續區域支援。
- 直接戰爭未因誤判擴大。

## 十四、結論

最可能的韓國角色不是第一線臺海參戰國，而是：

> 朝鮮半島防衛核心、駐韓美軍後方節點、區域情報與資安夥伴，以及半導體、造船、醫療與供應鏈支援國。
