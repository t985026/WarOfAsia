# 韓國紅方｜第一卷：中國、北韓與俄羅斯對韓複合施壓戰略架構

## 一、執行摘要

韓國紅方不應被簡化成「北韓直接進攻韓國」。在2027臺海戰爭外溢情境中，更可能形成三層架構：

1. **中國主導政治與戰略塑形**：迫使韓國限制美軍支援、維持中立、延遲與日本及臺灣協同。  
2. **北韓提供軍事與心理牽制**：以核飛彈、邊境、海上、網路及宣傳迫使韓國保留主要兵力。  
3. **俄羅斯提供間接緩衝**：在外交、能源、制裁規避、資訊敘事及其他戰區增加壓力。  

紅方的理想成果不是占領韓國，而是：

> 韓國仍存在，但政治決策受限、駐韓美軍無法支援臺海、日韓合作失靈、企業害怕中國報復，社會將臺海支援視為對韓國本土安全的直接威脅。

## 二、紅方戰略目標

### 2.1 最低目標

- 韓國不直接參與臺海軍事行動。
- 駐韓美軍不大量調往臺海。
- 韓國不開放基地或後勤設施支援對中作戰。
- 韓國不加入最嚴厲金融與科技制裁。

### 2.2 中度目標

- 韓國政府與反對黨因臺海政策嚴重分裂。
- 日韓情報及飛彈預警合作受阻。
- 韓國企業反對政府配合美國。
- 中國經濟脅迫使韓國採取模糊或中立立場。

### 2.3 最大目標

- 美韓同盟可信度下降。
- 韓國要求限制駐韓美軍區域任務。
- 韓國與日本安全合作中止。
- 北韓利用危機取得軍事或政治讓步。
- 韓國在區域安全架構中被迫戰略中立化。

## 三、紅方九層架構

| 層級 | 主體 | 主要作用 |
|---|---|---|
| 1 | 中國政治領導 | 決定對韓施壓程度與臺海目標 |
| 2 | 中國外交及統戰網絡 | 塑造中立、反美、反日與和平敘事 |
| 3 | 中國經貿及市場工具 | 關鍵原料、海關、企業與消費壓力 |
| 4 | 中國情報與網路體系 | 蒐集決策、供應鏈、同盟與社會資料 |
| 5 | 中國軍事與灰色地帶 | 對韓國周邊施壓但避免過早觸發戰爭 |
| 6 | 北韓核飛彈與常規軍 | 製造第二戰場及高度不確定性 |
| 7 | 北韓網路、金融與宣傳 | 擾亂金融、政府與社會信任 |
| 8 | 俄羅斯外交與制裁緩衝 | 支持中朝敘事、分散美歐注意力 |
| 9 | 商業、社團與犯罪代理 | 提供可否認的資訊、金流與秩序干擾 |

## 四、紅方作戰邏輯

```text
放大韓國對北韓威脅的焦慮
        ↓
宣稱臺海支援會削弱半島防衛
        ↓
以經濟成本迫使企業與地方反對政府
        ↓
以假消息及政治爭議分裂美韓、日韓
        ↓
北韓提高飛彈、邊境與網路壓力
        ↓
迫使韓國保留兵力並限制基地支援
        ↓
中國在臺海取得更大決策與時間空間
```

## 五、紅方優先避免的結果

紅方會盡量避免：

- 直接攻擊韓國領土而觸發美韓共同防衛。
- 使韓國政黨形成罕見的反中共識。
- 過度經濟報復而促使韓國供應鏈永久脫中。
- 北韓失控造成全面半島戰爭。
- 攻擊韓國商船、公民或基地，讓日本與澳洲更容易加入。
- 可驗證的秘密資金與指揮證據被公開。

## 六、紅方時間軸

### 平時

- 累積政治、媒體、學術、企業與地方關係。
- 建立對韓供應鏈依賴與資料掌握。
- 蒐集基地、同盟、政府及企業決策資訊。
- 放大歷史、駐軍、經濟與世代矛盾。

### 臺海危機前30日

- 提醒韓國支援美軍的經濟與安全成本。
- 增加北韓軍事與宣傳活動。
- 影響企業、媒體及地方政府要求中立。
- 對韓網路與金融系統進行更多偵察。

### 開戰後72小時

- 中國警告韓國不得開放基地。
- 北韓提高核飛彈與邊境警戒。
- 散布假美軍撤離、假動員及假政府協議。
- 對韓國企業、金融與通信施加可控壓力。

### 第4至30日

- 依韓國支援程度調整經濟脅迫。
- 鼓勵韓國國內要求停火與限制同盟支援。
- 北韓維持「接近戰爭但未全面開戰」狀態。
- 利用俄羅斯及全球南方推動反制裁敘事。

## 八、紅方成功指標

- 韓國公開限制駐韓美軍區域使用。
- 韓國拒絕與日本交換重要情報。
- 韓國只發表中立或停火聲明，不加入實質措施。
- 韓國企業與地方政府公開反對中央政策。
- 韓國社會將中國經濟報復視為政府支援臺海的責任。
- 北韓未全面開戰但成功牽制韓美大部分注意力。

## 九、紅方失敗指標

- 韓國形成跨黨派最低國安共識。
- 駐韓美軍調動已有替代與增援，半島嚇阻未下降。
- 日韓美即時共享飛彈及網路情報。
- 韓國企業獲得盟國市場、金融與原料支援。
- 中國秘密資金、資料控制與協同行動被依法公開。
- 北韓挑釁反而促使韓國、日、美安全合作深化。

## 十、本卷結論

紅方最有效的策略不是全面攻韓，而是：

> 以北韓製造不能忽視的軍事風險，以中國提供不能忽視的經濟代價，再利用韓國內部政治分歧，使韓國自行限制對美、日、臺的支援。

# 韓國紅方｜第二卷：中國對韓政治影響、經濟脅迫與同盟分化

## 一、文件定位

本卷模擬中國如何在不直接攻擊韓國的情況下，利用政治、經濟、媒體、地方交流、企業利益及通信供應鏈，降低韓國支援美國、臺灣與日本的意願。

## 二、主要敘事

### 2.1 對美韓同盟

- 美國會抽走駐韓美軍保護臺灣。
- 美國把韓國當成對中前線。
- 韓國承擔成本，美國獲得戰略利益。
- 美國不會在北韓與中國同時施壓時保護韓國。

### 2.2 對日韓合作

- 日本藉危機重新軍事化。
- 韓國若與日本合作等於放棄歷史立場。
- 日本只保護本土，不會真正保護韓國。
- 情報共享會使韓國軍事資料落入日本手中。

### 2.3 對臺海議題

- 臺海與韓國無關。
- 韓國支援臺灣將使北韓有藉口升級。
- 臺灣政府挑釁造成危機。
- 中國行動只是內政與有限執法。

## 三、政治影響接觸面

| 接觸面 | 可利用議題 | 藍方應觀察證據 |
|---|---|---|
| 政黨與政治人物 | 同盟、反戰、經濟成本 | 秘密委託、金流、協同 |
| 地方政府 | 觀光、投資、友城 | 未揭露條件、資料要求 |
| 媒體與平台 | 戰爭恐懼、反日反美 | 股權、廣告、協同帳號 |
| 學術與智庫 | 中立化、制裁成本 | 資助來源、委託範圍 |
| 企業與商會 | 市場、原料、在中資產 | 政府壓力、統一遊說 |
| 僑團與社團 | 文化、和平、反歧視 | 是否有隱藏官方任務 |

## 四、經濟脅迫工具

### 4.1 低可見度工具

- 海關、檢疫與行政延遲。
- 企業審查及市場准入。
- 觀光、文化與留學限制。
- 消費抵制與網路輿論。
- 關鍵原料交付延遲。

### 4.2 中度工具

- 限制特定韓國企業。
- 暫停供應關鍵礦物或零組件。
- 加強對在中韓企稅務、資安與勞動審查。
- 減少金融、物流與跨境資料合作。

### 4.3 高度工具

- 大規模出口或市場限制。
- 對韓國金融與科技企業制裁。
- 對特定產業實施聯合國際壓力。
- 以能源、物流及海運造成長期成本。

## 五、供應鏈與通信平台

### 5.1 可能利用的資料

- eSIM及行動位置。
- VPN來源IP、出口與連線時間。
- 雲端帳號與企業通信。
- 廣告、支付與裝置識別。
- 供應商遠端維護權限。
- 在中韓國企業及員工資料。

### 5.2 紅方理想狀態

同一控制體系可關聯：

```text
真實身分與付款
＋
裝置與位置
＋
企業與政府帳號
＋
VPN及跨境流量
＋
媒體與廣告偏好
＋

```

文件不假定所有中國資本企業都執行情報任務；只有控制權、資料流、法律要求與具體協同行為形成證據鏈時，才提高評級。

## 六、對企業的心理作用

中國不一定要真正制裁所有企業，只要讓企業相信：

- 政府支援臺海會失去中國市場。
- 加入美方科技限制會遭報復。
- 日韓合作會破壞中國客戶關係。
- 政府沒有能力補償企業損失。

企業就可能主動遊說政府降低支援。

## 七、危機期間的分化順序

1. 提醒韓國北韓威脅。  
2. 警告基地支援將使韓國成為戰場。  
3. 透過企業與媒體放大經濟損失。  
4. 放大日韓歷史與軍事爭議。  
5. 推動「停火、中立、限制美軍」的政治方案。  
6. 對拒絕配合的部門或企業實施選擇性報復。  

## 八、紅方成功條件

- 韓國政府未能向企業提供補償與替代市場。
- 外國資金與媒體控制權不透明。
- 日韓政治互信快速下降。
- 韓國民眾相信駐韓美軍會被全部抽走。
- 臺海戰況資訊不透明，紅方可壟斷部分敘事。
- 韓國主要政黨把國安議題完全轉化為內部鬥爭。

## 九、紅方反效果

- 經濟報復可能使韓國永久降低對中依賴。
- 資訊操作被揭露後可能提高反中共識。
- 過度反日宣傳可能促使年輕世代更支持實務安全合作。
- 攻擊VPN、eSIM或雲端信任可能導致韓國全面採用美日歐標準。
- 企業若得到G7金融與市場支援，經濟脅迫效果下降。

## 十、藍方預警

- 多個媒體、企業與政治團體突然使用相同論述。
- 與中國市場高度相關企業同步要求限制基地。
- 未揭露資金的廣告、民調與活動增加。
- 旅遊、海關、原料與網路壓力在同一時間出現。
- 中國外交警告與北韓軍事活動同步。
- VPN、eSIM、雲端或資料業者控制權突然變更。

## 十一、本卷結論

紅方政治經濟戰的重點不是讓所有韓國人支持中國，而是：

# 韓國紅方｜第三卷：北韓核飛彈、網路與第二戰場牽制模型

## 一、核心判斷

在臺海戰爭期間，北韓最具戰略價值的角色不一定是發動全面戰爭，而是維持一個：

## 二、北韓目標

- 迫使韓國保留主要軍力。
- 阻止駐韓美軍向臺海調動。
- 分散日本預警與飛彈防禦。
- 取得制裁、援助、政治或軍事談判利益。
- 配合中國削弱美韓日同盟。
- 測試韓國政府與社會韌性。

## 三、第二戰場工具

| 工具 | 目的 | 升級風險 |
|---|---|---:|
| 宣傳與假消息 | 製造恐慌及政治分裂 | 低 |
| 網路與金融攻擊 | 擾亂政府、銀行與企業 | 中 |
| 飛彈試射 | 迫使美韓日提高警戒 | 中 |
| 海上或邊境事件 | 消耗反應並測試紅線 | 中高 |

| 有限武裝攻擊 | 迫使半島防衛優先 | 極高 |
| 核武威脅或使用 | 改變整個區域戰爭 | 極高 |

## 四、北韓升級階梯

### 第一級：資訊與網路

- 假美軍撤離。
- 假韓國動員。
- 金融及加密資產攻擊。
- 政府與媒體帳號冒用。

### 第二級：軍事展示

- 飛彈試射。
- 空中、海上及邊境活動。
- 核與戰略力量宣傳。
- 部隊休假取消或演訓增加。

### 第三級：有限挑釁

- 製造局部事件。
- 迫使韓國分散軍力。
- 同時提出談判或政治條件。

### 第四級：重大攻擊

- 使朝鮮半島防衛完全取代臺海支援。
- 但同時承擔美韓直接反擊及政權風險。

## 五、北韓為何可能避免全面戰爭

- 美國延伸嚇阻及美韓聯合防衛。
- 全面戰爭可能威脅政權生存。
- 中國未必希望失控的半島戰爭。
- 北韓可透過有限挑釁取得牽制效果。
- 全面戰爭會破壞經濟、政權控制及中國臺海計畫。

# 韓國紅方｜第四卷：中俄朝協同、盟國分化與國際制度牽制

## 一、文件定位

本卷分析中國、北韓與俄羅斯如何在不一定形成正式聯合作戰指揮的情況下，透過互補行動分散美韓日、歐洲及臺灣資源。

## 二、三方互補角色

### 中國

- 臺海主要行動者。
- 對韓經濟、外交、資訊與區域軍事壓力。
- 在聯合國與全球南方推動主權及反干涉敘事。

### 北韓

- 朝鮮半島第二戰場。
- 核飛彈、網路、金融與心理壓力。
- 牽制韓國、日本及駐韓美軍。

### 俄羅斯

- 外交支持與安理會阻礙。
- 能源、金融、技術及制裁緩衝。
- 在歐洲、北極或其他地區增加美歐壓力。
- 支持反西方及多極化敘事。

## 三、協同不等於統一指揮

三方可能存在：

- 共同反對美國同盟體系。
- 互相利用對方危機。
- 交換能源、物資、技術及外交支持。
- 在時間上互相呼應。

但也存在矛盾：

- 中國不希望北韓全面失控。
- 俄羅斯可能追求自身利益，不完全服從中國。
- 北韓可能藉機提高要價。
- 對韓全面戰爭可能破壞中國臺海目標。

## 四、盟國分化目標

| 關係 | 紅方希望造成的分化 |
|---|---|
| 美韓 | 韓國限制基地與區域任務 |
| 日韓 | 中斷情報、飛彈預警與後勤 |
| 韓臺 | 韓國避免通信、產業及人道支援 |
| 韓澳歐 | 韓國不加入制裁與供應鏈替代 |
| 美國與歐洲 | 歐洲不願承擔對中經濟成本 |
| 東協與G7 | 全球南方維持中立或反制裁 |

## 五、聯合國與國際敘事

中國與俄羅斯可利用安理會否決與程序，使：

- 強制性決議難以通過。
- 國際社會轉向停火、人道與對話。
- 臺海與半島行動被描述為內政或安全回應。
- 韓國被要求避免「擴大衝突」。

北韓則可能宣稱其活動是對美韓演習及美國區域部署的防衛回應。

## 六、全球南方與東協

紅方可能強調：

- 西方雙重標準。
- 制裁傷害全球經濟。
- 臺海問題應由中國自行解決。
- 韓國應保持和平與中立。
- 亞洲不應成為美國同盟戰場。

## 七、俄羅斯第二方向壓力

俄羅斯不需直接參與朝鮮半島，只要：

- 在歐洲增加軍事與政治壓力。
- 影響能源與糧食市場。
- 協助中朝取得受限資源。
- 使美國與歐洲無法集中注意力。

即可提高紅方整體空間。

## 八、紅方成功條件

- 美韓日無法形成共同情勢判斷。
- 歐洲只發表聲明，不採實質措施。
- 東協及印度公開反對制裁或軍事支援。
- 聯合國討論長期停留在程序與停火。
- 北韓維持高威脅而沒有遭到一致反制。
- 韓國企業成功阻止政府加入制裁。

## 九、紅方失敗條件

- 美韓日定期公開共同威脅評估。
- G7為韓國企業提供金融、原料與市場替代。
- 東協及全球南方關切民用設施與航行安全。
- 北韓行動被視為配合中國而引發更多制裁。
- 俄中朝合作促使韓國、日本與歐洲安全合作深化。

## 十、藍方觀察重點

- 三方聲明是否使用相同歸責與法律語言。
- 北韓軍事行動是否與中國對韓外交要求同步。
- 俄羅斯是否提供新的能源、技術或金融緩衝。
- 安理會與國際組織是否被程序性拖延。
- 全球南方資訊環境是否出現集中敘事。
- 中國經濟措施與北韓軍事壓力是否互相配合。

## 十一、本卷結論

中俄朝不必建立完整聯合司令部，也能透過：

> 中國主戰略、北韓牽制、俄羅斯分散與國際制度阻礙，形成對韓國與盟國的複合壓力。

# 韓國紅方｜第五卷：2027臺海與朝鮮半島雙重危機紅方兵推

## 一、初始條件

- 中國對臺灣發動明確武裝行動。
- 臺灣通信與基礎設施嚴重受損。
- 韓國與美國提高區域警戒。
- 北韓尚未發動重大攻擊，但核飛彈及網路活動升高。
- 中國希望韓國限制基地、後勤、情報及制裁支援。
- 俄羅斯支持中國外交敘事並觀察其他戰區機會。

## 二、紅方勝利條件

### 中國

- 韓國不提供重大基地及後勤支援。
- 韓國不加入全面金融與科技制裁。
- 日韓安全合作受阻。
- 韓國企業與社會要求中立。

### 北韓

- 韓國及駐韓美軍保留主要兵力。
- 取得更多政治、軍事或經濟談判空間。
- 不承受全面戰爭與政權生存風險。

### 俄羅斯

- 美國與歐洲資源被分散。
- 中國與北韓增加對俄依賴。
- 制裁體系出現漏洞與疲勞。

## 三、戰前30日

### 中國

- 透過外交、企業與媒體警告韓國保持中立。
- 加強對韓供應鏈與市場風險訊號。
- 蒐集基地、同盟及企業決策變化。

### 北韓

- 提高飛彈、網路與宣傳準備。
- 測試美韓預警及輿論。
- 避免過早觸發全面防衛。

### 俄羅斯

- 支持反制裁與反干涉敘事。
- 增加其他戰區壓力。

## 四、戰前72小時

- 中國宣布大規模臺海軍演及禁限航區。
- 北韓提高部隊與飛彈活動。
- 韓國企業及金融市場開始擔憂。
- 社群出現假美軍撤離、假基地協議及假動員。
- 中國警告韓國不得加入「圍堵」。

## 五、開戰後0至6小時

### 紅方行動

- 中國對臺開戰，但避免直接攻擊韓國。
- 北韓提高核飛彈警戒。
- 對韓國金融、媒體與通信施加有限壓力。
- 宣稱韓國若支援美軍將承擔後果。

### 預期韓國反應

- 提高半島警戒。
- 暫不宣布直接參與臺海。
- 與美日進行緊急協調。
- 保護金融、能源、政府及基地。

### 裁決

紅方成功延遲韓國公開決策，但未使美韓同盟失效。

## 六、6至24小時

### 紅方選項A：保持可控壓力

- 北韓試射或展示，但不攻擊。
- 中國選擇性施壓企業及媒體。
- 優點：降低觸發韓國反擊。
- 缺點：韓國仍可提供後方支援。

### 紅方選項B：北韓有限挑釁

- 提高韓國軍事優先順序。
- 優點：牽制效果大。
- 缺點：可能強化美韓日合作。

### 紅方選項C：直接攻擊韓國資產

- 優點：可能中斷特定支援。
- 缺點：極可能觸發美韓共同防衛，屬高風險失敗路線。

中央情境選擇A，並保留B作為威脅。

## 七、24至72小時

紅方施壓重點：

- 要求韓國限制基地使用。
- 擴大經濟與市場警告。
- 放大「駐韓美軍將被抽空」。
- 北韓維持接近危機的軍事活動。
- 俄羅斯支持停火與反制裁論述。

### 72小時裁決

| 紅方目標 | 結果 |
|---|---|
| 阻止韓國直接參戰 | 部分成功 |
| 阻止情報與資安支援 | 失敗 |
| 阻止美軍後勤使用 | 未決 |
| 分裂日韓合作 | 部分成功 |
| 迫使韓國退出制裁 | 未決 |
| 維持北韓牽制 | 成功 |

## 八、第4至14日三條路線

| 路線 | 中央可能性 | 紅方效果 |
|---|---:|---|
| 可控牽制與經濟壓力 | 50% | 韓國有限支援但不直接參戰 |
| 北韓重大有限挑釁 | 30% | 韓國重心轉回半島，但同盟更緊密 |
| 紅方失控擴大 | 20% | 中國或北韓攻擊韓國，引發區域戰爭 |

## 九、第15至30日

### 紅方理想結果

- 韓國維持高警戒及低度區域支援。
- 企業推動降低對中制裁。
- 日韓合作只維持技術層級。
- 北韓未全面開戰但成功牽制。
- 美國需要在臺海與半島分配資源。

### 紅方最壞結果

- 韓國跨黨派支持美韓日合作。
- 中國經濟報復促使企業脫中。
- 北韓挑釁遭到一致且有效嚇阻。
- 駐韓美軍調動獲得替代增援。
- 韓國加入G7式金融與科技限制。

## 十、30日結果區間

| 結果 | 條件式可能性 |
|---|---:|
| 韓國未直接投入臺海作戰 | 80–95% |
| 韓國持續提供後方支援 | 55–75% |
| 北韓成功牽制主要韓美兵力 | 45–65% |
| 中國重大經濟脅迫 | 60–85% |
| 日韓合作仍維持 | 55–75% |
| 紅方迫使韓國完全中立 | 15–30% |
| 中國或北韓攻擊韓國造成區域戰爭 | 10–25% |

## 十一、90日與一年

### 90日

- 若戰爭持續，韓國成為美軍後方、產業及資安節點。
- 中國經濟報復加深。
- 北韓可能提高要價。
- 韓國社會出現經濟與安全疲勞。

### 一年

紅方若未能快速成功，可能造成：

- 韓國降低對中國市場與供應鏈依賴。
- 美韓同盟及日韓安全合作制度化。
- 韓國國防、民防與資安支出上升。
- 中國對韓影響力長期下降。

## 十二、本卷結論

紅方在韓國方向的合理策略是可控牽制，不是全面攻擊。其最大風險在於：

> 施壓越強，越可能把原本政治分裂的韓國推向更一致、更長期的美韓日安全合作。

3. **第二戰場**：北韓是否能牽制美韓日兵力與決策。  
4. **可否認性**：是否利用商業、媒體、社團、網路犯罪或灰色地帶降低歸責。

6. **失敗條件**：哪些藍方反應會使紅方分化、脅迫與牽制失效。

# 韓國紅方｜第六卷：紅方限制、失敗條件與藍方預警儀表板

## 一、目的

本卷不強化紅方攻擊能力，而是分析其限制、矛盾、誤判與可供韓國藍方利用的失敗條件。

## 二、中國的限制

- 不希望直接觸發美韓共同防衛。
- 韓國是重要產業、貿易與區域經濟體。
- 過度制裁可能加速韓國脫中。
- 對韓施壓可能強化日韓合作。
- 中國無法完全控制北韓升級。
- 臺海戰爭已占用大量政治、軍事與經濟資源。

## 三、北韓的限制

- 全面戰爭可能威脅政權生存。
- 核飛彈與有限挑釁難以精準控制誤判。
- 中國未必支持失控半島戰爭。
- 韓國與美國具強大聯合防衛能力。
- 持續高警戒也會消耗北韓資源。
- 俄羅斯及中國援助不代表無條件支持。

## 四、俄羅斯的限制

- 自身經濟、軍事與其他戰區負擔。
- 與中國、北韓利益並非完全一致。
- 無法直接替代中國與北韓所有科技、金融及市場需求。
- 直接介入東北亞戰爭的風險極高。

## 五、紅方內部矛盾

| 矛盾 | 說明 |
|---|---|
| 中國要可控、北韓要提高要價 | 北韓可能超出中國希望的程度 |
| 經濟脅迫與長期影響力 | 短期制裁可能摧毀長期關係 |
| 反日敘事與北韓威脅 | 北韓越強硬，韓國越需要日本預警 |
| 避免攻韓與阻止基地 | 不攻擊基地就難完全中斷支援 |
| 模糊歸責與公開嚇阻 | 威脅太模糊可能無法改變韓國政策 |
| 危機持續與民怨 | 長期衝突也會增加中朝國內成本 |

## 六、紅方常見誤判

1. 高估韓國企業阻止政府決策的能力。  
2. 低估北韓挑釁對日韓合作的促進作用。  
3. 認為韓國歷史爭議一定能中斷所有安全合作。  
4. 低估美國為半島提供替代兵力與延伸嚇阻。  
5. 高估網路與假消息可立即使政府失能。  
6. 低估經濟報復造成韓國供應鏈永久轉移。  
7. 認為不直接攻擊韓國就能完全阻止韓國支援。  
8. 低估公開證據對韓國民意的整合作用。  

## 七、藍方預警領域

| 領域 | 主要指標 |
|---|---|
| 中國政治 | 對韓中立與基地限制要求 |
| 中國經濟 | 海關、原料、企業及市場同步壓力 |
| 中國資訊 | 相同敘事跨媒體、企業與社團同步 |
| 北韓軍事 | 飛彈、邊境、核、部隊及演訓活動 |
| 北韓網路 | 金融、政府、警報與媒體異常 |
| 俄羅斯 | 能源、技術、金融與外交支援 |
| 同盟分化 | 美韓、日韓與韓臺互信下降 |
| 供應鏈 | VPN、eSIM、雲端與電信控制權變化 |

## 八、綠黃橙紅分級

### 綠色

- 一般外交、宣傳及軍事活動。
- 沒有跨領域同步。

### 黃色

- 中國經濟警告與北韓軍事展示同時升高。
- 媒體及企業出現集中論述。

### 橙色

- 北韓部隊及網路活動顯著。
- 中國要求限制基地並採取實際經濟措施。
- 日韓或美韓政治協調受阻。

### 紅色

- 北韓接近實際武裝攻擊。
- 中國攻擊或準備攻擊韓國資產。
- 中俄朝出現可驗證任務協同。
- 韓國政府命令、金融、通信與基地同時遭複合衝擊。

## 九、指標評分

| 分數 | 意義 |
|---:|---|
| 0 | 未出現 |
| 1 | 單一弱訊號 |
| 2 | 多來源支持但規模有限 |
| 3 | 官方或高可信證據，影響顯著 |
| 4 | 與其他領域同步並出現危機啟用 |

不得只使用總分；三個以上領域同步才應大幅上修。

## 十、藍方可利用的紅方失敗點

- 提前公布半島戰力底線及替代增援。
- 為企業提供金融、原料與市場保險。
- 將日韓合作限定在可公開、實務及防禦領域。
- 建立高階命令、金融與警報系統多重驗證。
- 公開可驗證的秘密金流、網路及經濟脅迫證據。
- 對北韓採取一致、比例且可降級的回應。
- 維持韓中危機通信，降低誤判。
- 讓合法反對意見參與國安共識，避免紅方利用壓制敘事。

## 十二、最終判斷

紅方最危險的不是某一項武器或某一則假消息，而是：

> 中國的經濟與政治壓力、北韓的軍事與網路牽制、俄羅斯的外交與制裁緩衝，在韓國內部政治分裂時跨領域同步。

紅方最脆弱的地方則是：

> 過度施壓可能消除韓國內部分歧，促使美韓日及G7建立更長期、更制度化的合作。
