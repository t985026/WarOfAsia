## 0. 本卷摘要

最壞情境下，紅方不必把臺灣所有設施摧毀。更有效率的方式可能是讓多個系統同時「部分失效」：有電卻送不到優先用戶、有網路卻無法確認真假、有物資卻無法配送、有政府卻無法證明命令真實。這種功能性失能依賴長期蒐情、數位預置、供應鏈、內部人員、假消息與修復阻礙的組合。

## 1. 十三層系統性失能架構

| 層級 | 功能 |
|---|---|
| 1. 戰略需求 | 決定希望臺灣哪些功能降級 |
| 2. 情報建模 | 繪製人員、設備、資料與相依性 |
| 3. 資金掩護 | 支付中介、公司、設備與內容成本 |
| 4. 人員存取 | 取得組織導航、權限與危機回報 |
| 5. 數位存取 | 帳號、供應鏈、雲端與遠端維護入口 |
| 6. 產業存取 | 供應商、承包商、物流與維修鏈 |
| 7. 認知準備 | 建立可在事故時啟用的敘事 |

## 2. 網路預置：平時進入，危機啟用

國安局公開資料已將對關鍵基礎設施「設伏」列為風險。最危險的網攻可能不是立即破壞，而是長期理解：

- 管理帳號、設備版本與網路拓樸。
- 備援切換、派工、修復與供應商流程。
- 哪些監控資料最能影響操作決策。
- 哪些系統使用相同身分、雲端或遠端維護工具。
- 危機時如何讓假警報與真實損害混在一起。

### 2.1 主要效果類型

- 竊密與情勢蒐集。
- 持續存取與權限維持。
- 資料污染、顯示錯誤與操作不信任。
- 服務阻斷與大量流量壓力。
- 供應鏈與軟體更新風險。
- 事件處理通信被竊取，讓紅方即時了解修復狀況。

## 3. 數位身分與信任基礎

系統仍在線，不代表可信。紅方可能關注：

- 政府、軍事與企業高權限帳號。
- 電子簽章、憑證、DNS、網域與時間同步。
- 金融、醫療、戶政與行動身分驗證。
- 官方網站、社群、警報與媒體發布管道。
- 憑證遭竊後的撤銷與重建速度。

最黑暗的效果是：真正命令與假命令同時存在，任何澄清都被質疑。

## 4. 電信、雲端與資料中心

完整風險不只海纜，也包括：

- 行動基地台、固定網路與核心交換系統。
- 國內骨幹、DNS與必要服務。
- 公有雲、私有雲、境外雲與資料中心。
- 備份與主系統是否共用帳號、電力、電信或供應商。
- 基地台、資料中心及維修團隊的備用電力與燃料。
- 離線作業與可信乾淨映像。

紅方可能追求「不一致的降級」：不同地區、機關與民眾看到不同服務狀態，進一步放大誤解。

## 5. 能源完整鏈條

不能只看發電廠。能源鏈包括：

> 進口—卸載—儲存—燃料運輸—發電—輸電—配電—控制—維修。

可能被關注的功能資料：

- 儲備與補充節奏。
- 港口、接收、運輸與電網相依性。
- 優先用電規則與人工操作能力。
- 特殊設備、零件與外國原廠依賴。
- 搶修隊、工程車、燃料與通信需求。

最壞情境不是全臺一次停電，而是輪流異常、備援快速耗損、維修人員疲勞，並由假消息宣稱全面崩潰。

## 6. 水資源與環境安全

紅方可利用真實故障或謠言放大：

- 取水、淨水、加壓、管線與電力相依性。
- 水質監測資料是否可信。
- 備用水源、運水與地方配給能力。
- 工業事故、污染與民眾恐慌。
- 假水質警報造成大規模搶購與人口移動。

本文件不提供污染或破壞方法。藍方重點是多源驗證、人工操作、公開數據與快速檢驗。

## 7. 港口、機場、交通與物流

物資存在但無法送達，也會形成短缺。

### 7.1 系統相依

- 港務、報關、貨櫃、倉儲與裝卸資訊。
- 機場、航管、貨運與安全查核。
- 公路、鐵路、橋梁、隧道與地方配送。
- 冷鏈、藥品、燃料及危險品運輸。
- 郵政、超商、民間物流與大型配送中心。

### 7.2 恐慌循環

1. 排程、報關或配送出現異常。
2. 社群宣稱港口遭封鎖或物資將耗盡。
3. 民眾搶購、道路壅塞、客服與訂單流量暴增。
4. 真正配送被延誤，形成自我實現的短缺。
5. 紅方把混亂描述成政府失去控制。

## 8. 金融、支付與市場信心

紅方不必擊垮所有銀行，只需讓民眾相信：

- ATM即將無法提款。
- 行動支付與清算即將停止。
- 銀行、保險或證券機構即將倒閉。
- 政府將凍結存款、外匯或資本流動。
- 新臺幣、股市或國債將失去控制。

### 8.1 複合效果

- 真實網路延遲使假消息更可信。
- 大量查詢、提款與客服流量造成系統變慢。
- 正常的風控或限額被解讀成金融崩潰。
- 商家拒絕電子支付，民眾轉向現金與物資。
- 企業要求政府以政治讓步換取市場穩定。

## 9. 醫療、公共衛生與社福

最黑暗情境會利用民眾最敏感的資訊：

- 某醫院停止收治或病歷系統失效。
- 血液、氧氣、透析、藥物或急救資源不足。
- 長照、身心障礙、老人與兒童服務中斷。
- 化學、生物、放射或大型工安事件真假難辨。
- 假死亡、失蹤與高層傷亡名單造成恐慌。

紅方未必需要直接造成傷害；大量假報案、假警報與人口移動即可使醫療警消超載。

## 10. 糧食、民生物資與配售

應關注：

- 進口、國內生產、倉儲、加工、冷鏈與零售相依性。
- 配售與弱勢配送的資料與身分驗證。
- 大型倉庫、配送中心與資訊系統集中風險。
- 假短缺、假污染與假徵用公告。
- 地方與中央庫存數據不一致造成信任危機。

## 11. 科學園區、工業區與關鍵製造

紅方可能同時追求技術取得與危機中斷：

- 半導體、AI、通信、資安、精密機械、能源與軍民兩用技術。
- 特殊氣體、化學品、設備、軟體、電力與用水依賴。
- 危險物質與安全停機程序。
- 核心工程師、維護商、外國原廠與物流能力。
- 生產恢復時間、庫存與替代料件。

公開資料應避免把所有依賴集中呈現成可用的弱點清單。

## 12. 修復、搶修與復原產業鏈

這是最容易被忽略的目標面向。紅方若無法造成首次重大損害，也可能試圖降低修復速度：

- 竊取派工與備料資訊。
- 假冒主管、供應商或工程人員發出錯誤指示。
- 對維修人員、家屬或承包商施壓。
- 造成交通、燃料、住宿與安全問題。
- 讓多個小事件同時發生，使稀缺專業人力無法分配。
- 透過假消息引導民眾阻擋、圍觀或質疑修復工作。

藍方應把維修人員、工具、零件、工程車、原廠支援與安全護送視為國家戰略資產。

## 13. 內應的放大作用

內應不一定執行重大破壞。較低風險但高價值的任務可能包括：

- 回報真實損害與備援狀態。
- 確認哪些假消息最容易被相信。
- 延誤通報、派工與資源排序。
- 將資源引向錯誤地點或錯誤問題。
- 洩漏會議、修復、警戒與公共說明內容。
- 提供帳號、組織導航與供應商關係。

因此，藍方需結合人員保護、權限控管、異常行為、金流與危機通報，而非只防止「偷走文件」。

## 14. 假旗事件與事故武器化

紅方可能希望敵對行動被解讀成：

- 海事、工安或設備事故。
- 一般犯罪、黑道糾紛或員工報復。
- 激進政治團體或第三國所為。
- 政府自己隱瞞、失職或製造的事件。

### 14.1 主要效果

- 政府不敢快速歸責，擔心升高衝突。
- 政黨、媒體與社群互相指控。
- 真正的技術鑑識與修復被政治爭論拖慢。
- 大量假線索污染反情報與司法資源。

任何事故均不能在缺乏鑑識、金流與指揮證據時直接認定為國家行動。

## 15. 代理暴力與治安超載

C級最壞情境應演練：

- 大量假爆炸、火災、攻擊或失蹤通報。
- 對維修、醫療、媒體、金融與物流人員的恐嚇。
- 零星象徵性暴力造成全國性恐慌。
- 冒充不同政治陣營製造街頭衝突。
- 警察、消防、醫療與媒體無法分辨哪些事件真實。

目前不足以宣稱臺灣已存在統一指揮的此類網絡，必須列為演練情境而非既定事實。

## 16. 關鍵功能類別的完整盤點

公開紅隊文件應涵蓋但不列弱點：

| 類別 | 應納入的功能 |
|---|---|
| 國家指揮 | 合法領導、代理、命令、異地辦公、國際確認 |
| 軍事 | 指揮、感測、通信、戰力保存、後勤、維修、醫療 |
| 情報治安 | 國安、反情報、警政、海巡、消防、司法與監所 |
| 數位 | 海纜、衛星、電信、雲端、DNS、憑證、資料與備份 |
| 能源環境 | 燃料、電力、供水、危險物、工業安全與修復 |
| 交通物流 | 港口、機場、公鐵路、倉儲、冷鏈與地方配送 |
| 民生 | 金融、醫療、糧食、社福、避難、死亡失蹤管理 |
| 產業 | 科學園區、半導體、關鍵製造、供應鏈與人才 |
| 社會資訊 | 媒體、公共廣播、警報、社群與地方組織 |
| 國際連結 | 外交通信、友盟情資、物資接收、海關與國際支援 |

## 17. 系統相依性崩潰鏈

```text
海纜／電信／雲端降級
          ↓
金融、港務、物流與政府資訊延遲
          ↓
假公告與物資謠言取得可信外觀
          ↓
搶購、擠兌、道路壅塞與客服超載
          ↓
醫療、警消、維修與配送資源被分散
          ↓
真實故障修復變慢，局部短缺擴大
          ↓
中央、地方、企業與民眾互不信任
          ↓
政治讓步與自行協商壓力升高
```

## 18. 本卷自我審查：前版常漏項

- 數位身分、憑證、DNS與時間同步。
- 維修、原廠、特殊零件與工程人員安全。
- 醫療、社福、監所、殯葬與失蹤人口管理。
- 危險化學品、工業安全與安全停機。
- 假報案、假派工、假死亡名單與反情報污染。
- 外援物資到達後的查驗、分配與地方配送。
- 敵方不必摧毀設施，只要讓操作人員不再信任數據。
