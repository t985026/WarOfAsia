# 臺灣藍方｜第三卷：中共複合侵略之主動反制與國際協同架構

> **文件定位**
>
> 本系列以臺灣藍方的國家持續運作、全社會防衛、反情報、關鍵基礎設施韌性與盟國協同為核心，對應前案的40項中共複合威脅預警。
>
> 本文件只提供防禦性政策、治理、稽核、應變與演練框架；不提供攻擊目標、設施弱點、滲透招募、破壞程序、規避執法或軍事行動細節。
>
> 公開版只列「功能、依賴、替代、權責與評量」。具體人名、位置、帳號、容量、頻率、備援站點及缺口，應存放於受限附件並依權限管理。

## 一、主動反制的定義

本卷所稱主動反制，是依法、可歸責、比例適當且以防禦為目的的：

- 情報揭露與反間諜執法
- 經濟反脅迫與供應鏈限制
- 防禦性網路封鎖與可信復原
- 外國影響及政治資金透明
- 灰色地帶拒止與海上執法
- 國際共同歸責、制裁與盟國支援

不包括未經授權駭侵、報復性破壞、暗殺、秘密招募、針對平民攻擊或對中國境內進行非法行動。

## 二、共同歸責梯度

| 階段 | 證據狀態 | 處置 |
|---|---|---|
| 初步異常 | 單一訊號或技術異常 | 內部追蹤，不急於公開歸責 |
| 多來源關聯 | 技術、金流、船舶、行為出現關聯 | 與盟國交換情資 |
| 高可信證據 | 多機關及第三方可驗證 | 政府公開說明、司法處理 |
| 國家行動確認 | 指揮、基礎設施及行動節奏可歸責 | 多國共同歸責與比例反制 |

錯誤歸責會破壞政府可信度，也可能提供北京「臺灣先升級」的敘事，因此必須保留不確定性。

## 三、反情報網絡拆解

```text
最終委託與控制者
→ 金流與公司
→ 帳號、設備與通信
→ 系統、資料及門禁權限
→ 執行人員
→ 危機待命任務
```

### 3.1 主要行動

- 凍結及沒收不法金流。
- 撤銷高風險帳號、憑證及遠端權限。
- 保護受脅迫、可合作及主動通報人員。
- 查封代理公司及保存數位證據。
- 追蹤換殼公司、第三國金流與帳號重建。
- 不因政治立場、族群或合法交流推定代理關係。

## 四、VPN、eSIM及通信平台反制

若有證據顯示業者隱瞞控制權、非法處理資料、協助國家情報、惡意導流或危機停用，可依法：

- 禁止政府採購與敏感產業使用。
- 限制或要求隔離控制權、資料與基礎設施。
- 要求刪除資料、接受稽核及通知使用者。
- 罰款、暫停服務或撤銷營運資格。
- 與盟國共享惡意路由、憑證、應用程式及基礎設施指標。

不能只因低價或中國背景直接禁止；必須依控制、資料、權限、法域與行為證據。

## 五、經濟反脅迫

### 5.1 對內支援

- 受害產業快速融資、保證、補助及保險。
- 政府採購吸收必要產品。
- 出口市場轉向與盟國共同採購。
- 避免企業因單獨承受中國報復而遊說政府改變核心政策。

### 5.2 對外反制

- 投資審查、政府採購限制及技術安全措施。
- WTO、國際仲裁及多邊法律程序。
- 與盟國採取合法、比例、可逆的共同措施。
- 對涉及秘密委託或資料濫用的公司實施精準限制，而非無差別脫鉤。

## 六、防禦性網路反制

- 威脅獵捕、惡意網域與基礎設施封鎖。
- 憑證撤銷、密鑰重發、DNS與時間同步保護。
- 零信任、裝置驗證、軟體白名單及遠端維護隔離。
- 與盟國分享惡意程式、戰術及修補指引。
- 從乾淨環境進行可信復原，保留證據並由第三方覆核。

## 七、認知戰反制

不採「以假對假」，而採：

- 快速公開原始證據與時間線。
- 單一事件事實頁及統一事件編號。
- 支持獨立媒體、民間查核及研究。
- 深偽、境外政府媒體與政治廣告透明標示。
- 地方、多語言、無障礙及低網路版本發布。
- 保存更正紀錄，承認政府自身錯誤。

## 八、灰色地帶與海上反制

- 海巡、海軍、警政、司法及外交建立共同規則。
- 全程記錄船舶、軍機、公務船及海纜事件。
- 提供航運保險、風險資訊、安全航線及盟國監視。
- 對準封鎖維持商業交通與國際合法性。
- 比例應對，避免過早軍事化，但不接受中國單方面改變法律及海空現狀。

## 九、盟國協同

### 美國

- 情報、衛星、資安、軍售、後勤、制裁與危機通信。

### 日本

- 西南諸島、基地、海空監視、港口機場、海纜及民事保護。

### 韓國

- 防止北韓形成第二戰場、情報、後方支援、供應鏈與經濟反脅迫。

### 菲律賓

- 巴士海峽、北部基地、海空監視、撤僑、人道與後勤走廊。

### 澳洲

- 情報、海纜、衛星、資安、航運、後勤與共同制裁。

## 十、分階段反制

### 平時

- 建立證據鏈、透明制度、供應鏈審查及盟國協議。

### 脅迫開始

- 共同歸責、企業支援、國際法律及市場替代。

### 混合威脅啟用

- 撤銷高風險權限、拆解內應網絡、啟動通信與金融備援。

### 準封鎖

- 維持航運、保險、港口、能源與國際公共訊息。

### 有限或全面侵略

- 國家持續運作、戰力保存、盟國支援、證據保存及危機降級。

### 復原

- 清除預置、重發憑證、追究責任、補償損失及重建長期嚇阻。

## 十一、嚇阻訊號

臺灣與盟國應讓北京相信：

- 單點攻擊不能使政府失能。
- 海纜中斷不會造成完全隔離。
- 內應與通信供應鏈會被持續查核及拆解。
- 經濟脅迫成本會由盟國共同承擔。
- 準封鎖會遭共同歸責且無法低成本維持。
- 全面侵略無法快速轉化為政治投降。

## 十二、反制KPI

| 領域 | KPI |
|---|---|
| 歸責 | 從事件到多來源高可信判斷時間 |
| 反情報 | 從底層人員回溯控制者及金流的完成率 |
| 通信 | 高風險供應商撤銷及替代時間 |
| 經濟 | 受脅迫企業取得融資與替代市場時間 |
| 網路 | 惡意基礎設施封鎖及可信復原時間 |
| 認知 | 假敘事澄清、觸及及信任恢復率 |
| 海上 | 灰區事件證據完整率及航運維持率 |
| 盟國 | 共同聲明、情報及支援啟動時間 |

## 證據與決策分級

| 等級 | 定義 | 決策用途 |
|---|---|---|
| A級 | 法律、官方制度、已確認案件或可驗證事件 | 可直接作為制度設計依據 |
| B級 | 官方威脅評估、可信研究或多來源一致 | 可作主要風險判斷 |
| C級 | 依公開能力與歷史模式建立的條件式推演 | 必須明確標示假設 |
| D級 | 傳聞、單一匿名訊息或無法交叉驗證 | 不作重大決策唯一依據 |

重大升級不得由單一事件觸發，至少須同時檢查：政治控制、軍事動員、非軍事準備及危機塑形四個領域。

## 40項預警對應原則

前案40項預警在本系列分成六組：

1. **中國內部政治軍事**：黨軍衝突、清洗完成、戰爭宣傳、出境與資本控制。
2. **軍事與聯勤動員**：部隊不撤回、民船與交通徵用、醫療大量傷患準備、後備與技術人員動員。
3. **間諜與內部網絡**：人員收買、黑道地下金融、軍政承包商、高權限帳號、危機待命任務。
4. **數位與通信**：海纜、網攻、政府個資、VPN、eSIM、跨境雲端與流量關聯。
5. **政治與認知塑形**：臺灣社群分化、假命令、假投降、假金融消息、韓國與日本政治分化。
6. **區域與國際條件**：美日韓菲澳協同、北韓與俄羅斯牽制、國際歸責與撤僑訊號。

所有措施都要回答三個問題：是否降低發生機率、是否降低衝擊、是否加速可信復原。
