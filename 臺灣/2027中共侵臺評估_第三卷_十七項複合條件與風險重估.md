# 2027中共侵臺評估｜第三卷：十七項複合條件與風險重估

## 一、使用方式

本卷完整納入使用者提出的17項條件，逐項區分：

- 是否已有公開證據
- 對侵臺意圖、能力、準備或機會的影響
- 對灰色地帶、準封鎖、有限打擊與全面登陸的不同權重
- 可能的誤判與反效果
- 應觀察的升級條件

## 二、十七項條件完整評估


1. **2026年10月1日後黨政與軍方衝突**  
   短期降低全面登陸能力，但增加軍演、對外示強與誤判；若清洗完成且指揮集中，中期風險反升。

2. **中國間諜活動持續**  
   常態蒐集本身不是開戰指標；若任務轉向代理順位、戰時通信、動員、修復、待命或破壞，警示性大幅提高。

3. **控制中國人民出境**  
   個別公務員與敏感產業管制可能是常態；若擴大到技術人員、軍人家屬、外企員工及一般居民，且與資本及物流管制同步，屬高級預警。

4. **對外網路加強監控**  
   一般審查不足以證明作戰準備；若國際VPN、跨境企業通信、境外雲端、國營電信與沿海流量同步進入特殊管制，警示性提高。

5. **持續滲透韓國政治**  
   目的可能是阻止韓國提供美軍後方支援、放大反美反日爭議並迫使韓國專注北韓。需以金流、委託與協同行為判斷，不能以政治立場推定。

6. **搗亂日本軍政**  
   沖繩基地爭議、地方反對港口機場使用、假美軍事件、經濟報復與日美指揮權爭論，可延遲日本決策；但過度施壓也可能反向強化日美同盟。

7. **分化臺灣社群對立**  
   可能放大「美國會放棄臺灣」「備戰等於引戰」「政府已投降」「特定族群是內應」等敘事，目標是破壞信任與動員。

8. **持續收買臺灣人員**  
   高風險接觸面包括現退役軍人、公務員、承包商、電信能源港口交通、科技軍工及地方政治人員。由一般資料轉向危機程序和高權限，風險顯著上升。

9. **搗亂政府機關體制**  
   假公文、假命令、資料外洩、大量假檢舉、司法行政塞車、中央地方衝突及官員深偽，目標是延長每一道決策的確認時間。

10. **間諜滲透與軍事破壞**  
    若出現取得戰時門禁、高權限、修復節點、應變時間，或與網攻同步的待命任務，應視為接近危機啟用的高級警報。公開版不記載具體方法。

11. **滲透人員或間諜處罰偏輕**  
    這是臺灣自身脆弱性乘數。除刑度外，應改善證據能力、秘密委託規範、犯罪所得沒收、持續查核與主動通報減責。

12. **引入毒品、黑道並持續擾亂秩序**  
    官方案件支持黑道與地下金融曾成為滲透媒介；但「中國政府直接以毒品作為侵臺工具」缺乏足夠公開證據，須列為C至D級假設。危機時犯罪代理可透過假報案、暴力、恐嚇及交通秩序擾亂增加警消負擔。

13. **持續破壞海底電纜**  
    2025年臺灣發生多起權宜輪違規破壞通訊海纜事件，促使行政院推動海纜七法。單一事件不必然是敵對行動；多點、連續、船舶行為異常、維修受阻並與網攻軍演同步時，準封鎖風險上升。

14. **引用更多軍政設施進行模擬攻堅**  
    實體模型、專業藍軍、兵棋、數位模擬及城鎮戰訓練代表能力準備，但不等於已下政治命令。若模型更新與跨軍種、後勤、民用運輸及長期控制訓練結合，警示性更高。

15. **電資戰持續竊取民政、廉政資訊**  
    可能用於掌握代理順位、人事弱點、反間諜案件、假文件及官員互信破壞。公開資料可支持中共持續針對關鍵基礎設施進行網駭與設伏，但特定廉政資料是否遭大規模竊取仍需個案證據。

16. **持續試探並縮減臺灣實際海空活動空間**  
    共機、共艦、公務船及海警常態活動可消耗應變、改變中線現狀、蒐集反應並為封鎖建立存在。其對準封鎖及突然轉實戰的風險影響高。

17. **上述行動持續累積並跨領域同步**  
    單一事件可能是背景噪音；政治控制、民用動員、間諜啟用、多點海纜、網攻、盟國分化與大型軍演同時出現時，才構成系統性危機準備。

## 四、加入條件後的重估

| 情境 | 基準區間 | 多數條件成立後 | 說明 |
|---|---:|---:|---|
| 認知、網路、間諜與政治戰 | 80–95% | 90–98% | 幾乎必然持續 |
| 大型軍演與包圍演練 | 70–90% | 85–95% | 可作施壓與預演 |
| 短期準封鎖或海關式隔離 | 25–40% | 45–65% | 若海纜、海警、航運與網攻同步 |
| 有限打擊或外離島危機 | 10–25% | 20–35% | 取決於政治與盟國反應 |
| 全面兩棲入侵 | 10–20% | 20–35% | 仍非最可能第一步 |
| 高度危機但最終未開戰 | 40–60% | 50–70% | 脅迫可能取得部分政治效果 |

## 五、黨軍衝突的修正

若黨軍衝突在2027仍未解決：

- 全面入侵可下修至約15–25%
- 但軍演、誤判、網路、認知及有限危機維持高位

若出現以下組合：

- 清洗結束
- 指揮集中
- 重要部隊人事穩定
- 大規模軍民動員
- 沿海交通與醫療戰備
- 出境、資本與網路同步管制
- 部隊及後勤演習後不撤回

則全面侵臺可上調至約30–45%。

## 六、因果鏈

```text
內部政治控制收緊
        ↓
軍隊人事與指揮重新集中
        ↓
對外網路、人口與資本管制
        ↓
民用交通、醫療、能源、港口進入戰備
        ↓
臺灣內部網絡與盟國分化同步啟用
        ↓
大型軍演、海警隔離、海纜與網路異常
        ↓
準封鎖或有限軍事危機
        ↓
視國際反應決定擴大或降級
```

## 七、不可直接成立的推論

下列推論應避免：

- 有間諜案件 = 已決定2027入侵
- 有海纜事故 = 一定由中國政府下令
- 韓國存在親中人士 = 韓國政治被控制
- 日本有反基地運動 = 中國代理
- 黑道與毒品案件 = 中國國家行動
- 建立模型區 = 已下令攻打該設施
- 中國加強網路監控 = 已進入戰時
- 軍方清洗 = 必然以戰爭轉移危機

## 八、判斷重點

最重要的不是事件總數，而是：

1. 是否跨政治、軍事、經濟、網路與社會領域同步。  
2. 是否從蒐集、施壓轉為待命、動員與實際啟用。  
3. 是否出現不可逆準備，例如廣泛徵用、醫療戰備與部隊不撤回。  
4. 是否建立對制裁、能源、金融與人口流動的國內控制。  
5. 是否同時削弱美日韓菲澳協同。

## 評估方法與證據分級

### 證據分級

| 等級 | 定義 | 文件處理方式 |
|---|---|---|
| A級 | 法律、官方制度、官方公開案件、可驗證軍事活動 | 可作為基準事實 |
| B級 | 官方威脅評估、可信研究或多個獨立來源支持 | 可作為主要判斷依據 |
| C級 | 根據已知能力與行為建立的條件式推演 | 必須清楚標示「假設」 |
| D級 | 缺乏可靠來源、僅有傳聞或無法交叉驗證 | 不納入主要結論 |

### 機率區間的意義

| 區間 | 用語 | 意義 |
|---:|---|---|
| 0–10% | 極低 | 需要多項重大條件改變 |
| 10–25% | 低至中 | 不能排除，但不是主要路徑 |
| 25–40% | 中等 | 具有可行性，須納入實際準備 |
| 40–65% | 中高 | 多項條件若成立，風險顯著 |
| 65–85% | 高 | 應視為主要規劃情境 |
| 85–100% | 極高 | 幾乎確定會持續或發生某種形式 |

### 評估軸線

1. **意圖**：北京政治領導是否認為行動有利且可控。  
2. **能力**：解放軍及黨國體系是否具備執行與持續能力。  
3. **準備**：動員、後勤、醫療、金融、網路與社會控制是否同步。  
4. **機會**：美國、日本、韓國、菲律賓、澳洲及臺灣是否出現可利用的政治或軍事窗口。  
5. **成本**：制裁、戰損、政權風險、經濟衝擊及國際反應。  
6. **替代方案**：封鎖、隔離、灰色地帶、有限打擊是否比全面登陸更符合成本效益。
