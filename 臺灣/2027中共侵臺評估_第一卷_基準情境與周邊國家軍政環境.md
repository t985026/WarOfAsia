# 2027中共侵臺評估｜第一卷：基準情境與周邊國家軍政環境

## 一、執行摘要

2027更適合被理解為「能力節點」而不是「開戰截止日」。美國國防部2025年報告表示，中國要求解放軍在2027年底前具備對臺作戰並取得勝利的能力；這代表北京希望增加可用選項，不等於已完成不可逆的開戰決策。

截至2026年8月4日，最可能持續的行動仍是：

- 認知作戰
- 網路攻擊與長期設伏
- 間諜與人員吸收
- 經濟、外交與法律脅迫
- 海警、軍艦、軍機及公務船常態施壓
- 大型環臺軍演與封鎖演練
- 對美日韓菲澳同盟體系的分化

全面兩棲登陸具有最高軍事與政治風險，因此未必是第一選項。更合理的升級鏈為：

```text
常態灰色地帶
→ 高強度軍演及海警包圍
→ 短期海關式檢查／隔離
→ 選擇性準封鎖
→ 有限打擊或外離島危機
→ 視臺灣與盟國反應決定是否擴大
```

## 二、基準情境機率

| 情境 | 2027年底前基準區間 | 主要理由 |
|---|---:|---|
| 認知戰、網攻、間諜、政治與經濟脅迫持續 | 80–95% | 已是常態競爭工具 |
| 大型環臺軍演、海警包圍、封鎖演練 | 70–90% | 可施壓、蒐集反應且低於全面戰爭 |
| 短期海上檢查、隔離或準封鎖 | 25–40% | 可測試盟國與商業反應 |
| 有限精準打擊、外離島或局部危機 | 10–25% | 升級風險高但可作強制手段 |
| 全面兩棲入侵臺灣本島 | 10–20% | 後勤、聯合指揮、城市戰與外國介入風險極高 |
| 高度危機但最終沒有開戰 | 40–60% | 軍演與脅迫可作政治工具，不必轉成戰爭 |

這些區間互相重疊，因為同一年可能先出現軍演、隔離與危機降級，而非只有單一結果。

## 三、美國軍政環境

### 3.1 戰略角色

美國是最重要的外部嚇阻者，具備：

- 全球情報、衛星與偵察能力
- 印太海空軍及核嚇阻
- 日本、韓國、菲律賓、澳洲等同盟與基地網絡
- 對中國金融、科技、航運及供應鏈施壓能力
- 對臺軍售、訓練、後勤與通信支援能力

### 3.2 美國可能採取的行動

| 行動 | 可能性 |
|---|---|
| 情報預警、衛星監視與公開歸責 | 高 |
| 軍售、彈藥、通信、資安與後勤支援 | 高 |
| 聯合制裁及國際聯盟 | 高 |
| 海空軍直接介入 | 中至高，取決於中國行動型態 |
| 對模糊海警或海關隔離立即開戰 | 不確定 |
| 對美軍基地或艦機遭攻擊後擴大介入 | 顯著上升 |

### 3.3 美國的不確定因素

- 國內政治與國會支持
- 全球其他戰區
- 彈藥與工業產能
- 中國是否先攻擊美軍
- 臺灣是否被國際社會認為改變現狀
- 日本與菲律賓是否提供充分基地及後勤
- 核升級風險

## 四、日本軍政環境

日本是臺海危機最直接受影響的盟國節點之一，因為：

- 西南諸島鄰近臺灣
- 駐日美軍基地具有重大作用
- 日本海空交通線與臺海安全相連
- 中國軍事活動可能直接影響日本領空、領海與專屬經濟區
- 日本需同時處理居民避難與基地運用

### 4.1 可能角色

- 保衛日本領土與西南諸島：高
- 提供美軍基地、情報、後勤：高
- 非戰鬥性支援臺灣與區域航運：中至高
- 直接參與臺灣本島作戰：中，取決於日本是否遭攻擊及法律認定
- 與美國共同實施制裁及海上安全支援：高

### 4.2 中國可能對日本採取的分化

- 沖繩基地爭議
- 地方政府與中央政府立場差異
- 假美軍事故、污染或犯罪消息
- 經濟報復與觀光限制
- 強化「日本被美國拖入戰爭」敘事
- 在東海與西南諸島增加壓力

## 五、韓國軍政環境

韓國的首要軍事威脅仍是北韓。臺海危機期間，韓國很可能優先：

- 防止北韓乘機挑釁
- 保留部隊於朝鮮半島
- 保護美軍後方基地與韓國領土
- 支持情報、外交、制裁及部分後勤

### 5.1 可能角色

| 行動 | 可能性 |
|---|---|
| 外交與制裁支持 | 中至高 |
| 情報及美軍後方支援 | 中 |
| 直接出兵臺海 | 低至中 |
| 因北韓升高威脅而限制支援 | 高可能性 |

### 5.2 中國的分化重點

- 放大反美與反日敘事
- 影響政黨、媒體、商界及地方交流
- 強化「臺海與韓國無關」
- 配合北韓製造第二戰場壓力
- 削弱美日韓情報共享

## 六、菲律賓軍政環境

菲律賓北部與巴丹群島靠近巴士海峽，對臺灣南方航道與區域後勤重要。

### 6.1 可能角色

- 美軍基地輪調與後勤：中至高
- 海上監視及南海牽制：高
- 人道救援與撤僑：高
- 直接參戰：中低至中
- 受國內政治與對中經濟關係影響：高

### 6.2 風險

- 菲國內部對美軍使用基地的爭議
- 中國在南海同步升高壓力
- 地方政治與中央不同調
- 北部島嶼居民安全與疏散
- 港口機場遭網路及資訊壓力

## 七、澳洲軍政環境

澳洲可能提供：

- 情報與資安
- 外交與制裁
- 北部基地及後勤
- 海上監視與盟國協同
- 海纜與衛星通信支援

直接作戰介入取決於美國行動、澳洲國內決策及中國是否攻擊盟軍。

## 八、北韓與俄羅斯

### 8.1 北韓

最可能的作用不是直接進入臺海，而是：

- 飛彈試射
- 邊境挑釁
- 網路攻擊
- 迫使韓國與美軍保留兵力
- 增加日本飛彈防禦負擔

### 8.2 俄羅斯

可能提供：

- 外交支持
- 能源與經濟緩衝
- 情報或技術交流
- 在其他戰區增加美歐壓力
- 與中國進行海空展示

直接參與臺海戰事的可能性低於間接牽制。

## 九、區域聯動判斷

| 區域條件 | 對中國風險計算的影響 |
|---|---|
| 美日基地及聯合指揮順暢 | 降低中國開戰意願 |
| 韓國被北韓牢牢牽制 | 增加中國機會 |
| 菲律賓限制美軍使用北部基地 | 增加中國機會 |
| 澳洲明確加入後勤與制裁 | 提高中國成本 |
| 日本國內基地爭議失控 | 增加準封鎖或有限行動可能 |
| 盟國公開分歧 | 可能誘發北京測試 |
| 盟國建立共同反脅迫與航運保障 | 降低隔離成功率 |

## 十、基準情境的主要上修條件

- 解放軍高層清洗結束且指揮穩定
- 沿海軍民後勤、交通、醫療同步戰備
- 部隊演習後不撤回
- 出境、資本、網路及外企活動同步受限
- 間諜任務由蒐集轉為待命與啟用
- 多點海纜、政府、金融及電力系統同步異常
- 美日韓菲澳出現明顯政治分裂
- 北京宣傳從勝利敘事轉向犧牲與長期戰爭

## 十一、主要下修條件

- 黨軍權力衝突持續
- 聯合作戰與裝備品質問題惡化
- 中國經濟與地方財政承受重大壓力
- 美國與盟國嚇阻部署透明且可信
- 臺灣社會韌性與後備改革顯著提升
- 中國無法建立制裁、能源與金融緩衝
- 俄羅斯或北韓無法提供牽制
- 危機溝通與政治談判仍有效

## 十二、本卷結論

2027的主問題不是「會不會在某一天突然登陸」，而是：

> 北京是否在2026至2027年間，同時完成政治控制、軍事指揮、民間動員、經濟防制裁、盟國分化與臺灣內部破壞的組合準備。

只看軍演會高估或低估風險；必須把軍政、經濟、社會、情報、網路與區域外交放入同一框架。

## 評估方法與證據分級

### 證據分級

| 等級 | 定義 | 文件處理方式 |
|---|---|---|
| A級 | 法律、官方制度、官方公開案件、可驗證軍事活動 | 可作為基準事實 |
| B級 | 官方威脅評估、可信研究或多個獨立來源支持 | 可作為主要判斷依據 |
| C級 | 根據已知能力與行為建立的條件式推演 | 必須清楚標示「假設」 |
| D級 | 缺乏可靠來源、僅有傳聞或無法交叉驗證 | 不納入主要結論 |

### 機率區間的意義

| 區間 | 用語 | 意義 |
|---:|---|---|
| 0–10% | 極低 | 需要多項重大條件改變 |
| 10–25% | 低至中 | 不能排除，但不是主要路徑 |
| 25–40% | 中等 | 具有可行性，須納入實際準備 |
| 40–65% | 中高 | 多項條件若成立，風險顯著 |
| 65–85% | 高 | 應視為主要規劃情境 |
| 85–100% | 極高 | 幾乎確定會持續或發生某種形式 |

### 評估軸線

1. **意圖**：北京政治領導是否認為行動有利且可控。  
2. **能力**：解放軍及黨國體系是否具備執行與持續能力。  
3. **準備**：動員、後勤、醫療、金融、網路與社會控制是否同步。  
4. **機會**：美國、日本、韓國、菲律賓、澳洲及臺灣是否出現可利用的政治或軍事窗口。  
5. **成本**：制裁、戰損、政權風險、經濟衝擊及國際反應。  
6. **替代方案**：封鎖、隔離、灰色地帶、有限打擊是否比全面登陸更符合成本效益。
