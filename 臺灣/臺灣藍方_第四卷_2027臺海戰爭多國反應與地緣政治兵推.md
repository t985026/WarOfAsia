# 臺灣藍方｜第四卷：2027臺海戰爭多國反應與地緣政治兵推

> [!IMPORTANT]
> 本卷模擬的是各國政府在資訊不完整、國內政治限制、同盟承諾、軍事風險與經濟衝擊下的可能反應，不代表任何國家已預先承諾在特定時間採取特定軍事行動。
>
> 文件中的百分比為條件式分析區間，用於比較情境，不是情報預測、保證或精準機率。
>
> 本卷只討論國家決策、外交、經濟、通信、後勤、人道與防禦性軍事反應，不提供具體攻擊目標、部署座標、作戰程序或基礎設施破壞方法。

---

## 一、兵推目的

本卷承接前三卷的平時預防、危機應變與主動反制，模擬2027年中國對臺發動武裝攻擊後，各國與國際組織可能如何反應。

兵推重點包括：

1. 美國是否、何時以及在何種條件下直接介入。
2. 日本是否提供基地、後勤與自衛隊支援。
3. 菲律賓是否開放北部基地及巴士海峽支援。
4. 澳洲、韓國、英國、法國、加拿大與歐盟的角色。
5. 印度與東協如何在戰略自主、經濟依賴與區域安全間平衡。
6. 俄羅斯與北韓是否製造第二戰場或制裁緩衝。
7. 聯合國與其他國際制度能否產生實質作用。
8. 全球航運、保險、能源、金融與半導體市場反應。
9. 臺灣如何提高盟國快速介入與持續支援的意願。
10. 戰爭從72小時、14日、30日、90日到一年可能如何演變。

---

## 二、兵推共同假設

### 2.1 戰爭起點

假設中國於2027年發起明確武裝行動，包含：

- 大規模海空封控與軍事威懾。
- 臺灣約三分之二海底電纜失效。
- 電力、通信、金融、交通、政府、醫療及物流遭複合衝擊。
- 認知戰、網路攻擊、假命令及內應同步啟用。
- 臺灣政府仍維持合法且可驗證的基本指揮。
- 中國第一波尚未刻意攻擊美國、日本、菲律賓或澳洲領土及部隊。

### 2.2 為何設定「尚未攻擊盟國」

這是最具挑戰性的情境，因為中國可嘗試：

- 將戰爭包裝成「內政」或「有限執法」。
- 避免立即觸發盟國自衛及條約義務。
- 分化美國、日本、菲律賓、韓國與歐洲。
- 讓商業航運與保險業自行退出。
- 迫使臺灣在盟國完成決策前接受政治條件。

### 2.3 藍方戰略勝利條件

臺灣不需要在30日內恢復平時生活；只要達成以下條件，即視為拒止紅方快速政治勝利：

- 合法政府及國軍指揮持續。
- 未接受被迫投降或政治安排。
- 電力、水務、醫療、金融及通信維持最低功能。
- 可對盟國提出可信、分級且可執行的支援需求。
- 地方政府未全面脫離中央。
- 國際社會可驗證中國首先使用武力。
- 盟國逐步建立通信、經濟、後勤與安全支援。

# 第一篇｜美國反應

## 四、美國第一階段反應

美國2026年國防戰略將第一島鏈拒止防禦、嚇阻中國及提高區域盟國能力列為主要方向。這使美國在臺海戰爭中完全置身事外的可能性偏低，但不代表美國必然在第一小時直接開火。

### 4.1 開戰後0至6小時

美國最可能：

- 確認中國行動規模及臺灣合法政府狀態。
- 啟動總統、國家安全與國防決策程序。
- 提高印太司令部、太平洋海空軍與基地警戒。
- 分散高價值資產及加強基地防護。
- 向日本、菲律賓、澳洲、韓國及G7進行緊急磋商。
- 提供臺灣衛星、情報、網路防護與通信協助。
- 暫時避免宣布已進入對中戰爭。

| 美國行動 | 0–6小時可能性 |
|---|---:|
| 情報、衛星、資安及通信支援 | 95–99% |
| 區域軍力高度戒備及分散 | 90–98% |
| 緊急盟國磋商 | 95–99% |
| 立即金融與出口管制準備 | 85–95% |
| 直接對中國軍力開火 | 15–30% |

### 4.2 6至24小時

美國可能：

- 公開確認臺灣受到武裝攻擊。
- 公布第一輪中國軍工、金融、科技及官員限制。
- 增加區域海空兵力。
- 向臺灣提供優先支援清單。
- 要求中國停止攻擊並建立危機通信。
- 與日本協調基地使用及後勤。
- 與菲律賓協調北部基地、撤僑及人道支援。

### 4.3 24至72小時

此時美國面臨三個選項：

#### 選項A：大規模支援但暫不直接開火

- 提供情報、通信、武器、物資與後勤。
- 組織制裁及國際歸責。
- 建立人道及商業航運支援。
- 避免立即擴大為美中戰爭。

#### 選項B：有限軍事介入

- 保護特定國際交通與盟國資產。
- 加強區域拒止與防禦。
- 嚇阻中國擴大攻擊。

#### 選項C：直接進入區域戰爭

主要在中國攻擊美軍、盟國基地或第三國船艦時發生。

| 美國行動 | 72小時內 | 14日內 |
|---|---:|---:|
| 大規模非直接作戰支援 | 85–95% | 90–98% |
| 組織G7及盟國制裁 | 90–98% | 95–99% |
| 建立海空運輸或人道支援 | 45–70% | 55–80% |
| 直接軍事交火 | 30–50% | 40–65% |

## 五、美國介入的上修與下修條件

### 5.1 上修條件

- 中國攻擊美軍艦機或基地。
- 中國攻擊日本領土上的美軍設施。
- 中國攻擊第三國商船或航空器。
- 臺灣政府仍有效運作並正式請求援助。
- 中國造成大規模平民傷亡。
- 日本允許美軍完整使用基地。
- 中國封鎖國際航道並拒絕降級。

### 5.2 下修條件

- 臺灣政府指揮快速失能。
- 中國提出停火並將行動維持在模糊執法層級。
- 日本及菲律賓不願提供基地。
- 美國同時面臨其他重大戰區。
- 美國國內行政與國會嚴重分裂。
- 北韓升高危機，迫使美軍保留大量半島兵力。

# 第二篇｜日本反應

## 六、日本的戰略位置

日本是臺海戰爭中最關鍵的盟國節點之一，原因包括：

- 西南諸島鄰近臺灣。
- 駐日美軍基地對西太平洋行動重要。
- 日本海上交通、能源及國土安全受直接影響。
- 中國軍事行動可能接近或進入日本周邊海空域。
- 日本需同時處理基地防護、居民撤離及國內法律授權。

## 七、日本分階段反應

### 7.1 開戰後0至24小時

- 國家安全與危機管理機制啟動。
- 西南諸島、沖繩及主要基地提高警戒。
- 保護駐日美軍、自衛隊、港口、機場及通信。
- 增加海空監視及飛彈預警。
- 準備撤僑、居民疏散與避難。
- 與美國協商基地使用及自衛隊支援範圍。

### 7.2 24至72小時

| 日本行動 | 中國未攻擊日本 |
|---|---:|
| 保衛日本領土及西南諸島 | 95–99% |
| 保護駐日美軍與自衛隊基地 | 95–99% |
| 提供美軍基地、後勤及維修 | 75–90% |
| 情報、預警及周邊海空監視 | 90–98% |
| 撤僑、人道及交通支援 | 75–90% |
| 直接攻擊中國軍力 | 20–40% |

### 7.3 中國攻擊日本或在日美軍

若中國攻擊：

- 日本領土。
- 日本自衛隊。
- 在日美軍基地。
- 日本公務船、軍艦或航空器。

則日本直接軍事介入的可能性可上升至約80–95%。

## 八、日本國內政治反應

可能同時出現：

- 支持日美同盟與加強防衛。
- 反對日本被捲入戰爭。
- 沖繩基地、居民安全及撤離爭議。
- 能源、航運、金融與企業損失壓力。
- 對中國經濟報復的擔憂。

中國可能利用：

- 「美國利用日本作戰」敘事。
- 假美軍事故或污染消息。
- 沖繩地方與東京中央的矛盾。
- 對日本企業、觀光及市場施壓。

# 第三篇｜菲律賓、澳洲與韓國

## 九、菲律賓

菲律賓的重要性來自：

- 北部島嶼及巴士海峽地理位置。
- 美菲同盟與EDCA輪調及設施合作。
- 南海與臺海可能形成連動。
- 撤僑、人道救援及海空監視需求。

### 9.1 可能行動

| 菲律賓行動 | 可能性 |
|---|---:|
| 北部海空域及基地高度戒備 | 90–98% |
| 撤僑與人道救援 | 80–95% |
| 提供部分基地及後勤 | 45–70% |
| 巴士海峽情報及監視 | 55–75% |
| 直接參與對中國作戰 | 10–25% |

### 9.2 介入上修條件

- 中國攻擊菲律賓領土、部隊、船艦或基地。
- 中國同時在南海升高武裝壓力。
- 中國攻擊由菲律賓基地起飛或停靠的美軍。
- 菲律賓公民、撤僑船或航空器受到攻擊。

若上述條件成立，菲律賓大幅支援美方的可能性可上升至65–85%。

### 9.3 國內限制

- 對中國經濟依賴。
- 基地使用與主權爭議。
- 中央與地方政治差異。
- 對戰爭擴大至菲律賓本土的恐懼。

## 十、澳洲

澳洲可能扮演：

- 情報、衛星、資安及海纜支援者。
- 美軍基地與遠程後勤節點。
- G7夥伴的制裁及經濟安全合作方。
- 海上監視、航運及人道支援者。

| 澳洲行動 | 可能性 |
|---|---:|
| 外交譴責及制裁 | 90–98% |
| 情報、資安、衛星及海纜支援 | 80–95% |
| 提供基地、後勤與維修 | 70–90% |
| 海上監視與航運支援 | 50–70% |
| 直接參與作戰 | 25–45% |

直接作戰的可能性會隨美國介入、中國攻擊盟國及澳洲國內授權而上升。

## 十一、韓國

韓國在臺海戰爭中的首要考量仍是北韓。

### 11.1 最可能反應

- 全國及駐韓美軍提高戒備。
- 防範北韓飛彈、邊境及網路挑釁。
- 提供部分情報、資安與後方支援。
- 參與外交譴責與部分制裁。
- 保留主要兵力於朝鮮半島。

| 韓國行動 | 可能性 |
|---|---:|
| 防範北韓第二戰場 | 95–99% |
| 外交譴責及部分制裁 | 60–80% |
| 情報、資安及後方支援 | 40–65% |
| 直接派兵臺海 | 5–15% |

### 11.2 北韓牽制效應

若北韓同步：

- 試射飛彈。
- 增加邊境活動。
- 發動網路及金融攻擊。
- 宣布重大軍事演習。

韓國對臺海直接支援的空間會下降，美國也需保留更多半島兵力。

# 第四篇｜歐洲、G7與加拿大

## 十二、G7反應

最可能的G7行動：

- 緊急領袖與外長會議。
- 共同譴責以武力改變現狀。
- 中國軍工、金融、科技與官員制裁。
- 先進科技及設備出口限制。
- 海運、保險、投資及金融措施。
- 對臺資安、通信、人道與醫療支援。

| G7行動 | 可能性 |
|---|---:|
| 共同譴責 | 95–99% |
| 金融、科技及出口管制 | 80–95% |
| 中國軍工及金融實體制裁 | 75–90% |
| 人道、資安及通信支援 | 70–90% |
| 歐洲直接參與高強度作戰 | 10–25% |

## 十三、英國、法國與加拿大

### 英國

- 外交與金融制裁。
- 情報、資安及AUKUS協調。
- 可能派遣有限海空力量展示支持。
- 直接進入高強度作戰仍受距離與資源限制。

### 法國

- 關切印太海外領地及公民。
- 參與歐盟制裁與海上安全。
- 可能提供有限海空存在及撤僑支援。
- 對美中全面戰爭保持自主判斷。

### 加拿大

- G7制裁、情報、資安、人道及外交支援。
- 可能提供有限海上存在。
- 直接作戰的可能性低於美日澳。

## 十四、歐盟內部分歧

歐盟很可能在以下事項形成共識：

- 譴責武力改變現狀。
- 保護歐洲公民及企業。
- 實施部分金融與科技制裁。
- 支援臺灣通信及人道需求。

較難形成一致的事項：

- 全面對中國經濟切割。
- 直接參與軍事行動。
- 對所有中國銀行及企業實施最嚴格措施。
- 承擔長期能源、出口及產業損失。

# 第五篇｜印度與東協

## 十五、印度

印度最可能維持戰略自主，不會自動加入西方全面制裁或臺海作戰。

| 印度行動 | 可能性 |
|---|---:|
| 呼籲停火及和平解決 | 85–95% |
| 加強中印邊境警戒 | 55–75% |
| 與美日澳交換部分情報 | 30–50% |
| 加入全面制裁 | 10–25% |
| 直接介入臺海作戰 | 5–15% |

### 15.1 印度的間接作用

- 在中印邊境提高戒備，迫使中國保留西部資源。
- 維持印度洋海上監視。
- 與四方安全對話夥伴磋商。
- 保護印度公民、航運與供應鏈。
- 避免被任何一方要求完全選邊。

## 十六、東協整體

東協成員對中國的經濟、安全與政治關係不同，因此難以形成統一強硬立場。

| 東協行動 | 可能性 |
|---|---:|
| 呼籲和平、克制及對話 | 75–90% |
| 一致譴責中國 | 20–35% |
| 集體制裁 | 5–15% |
| 個別國家提供美軍支援 | 25–45% |
| 維持中立及人道角色 | 65–85% |

### 16.1 國別差異

- **新加坡**：可能提供有限後勤、金融監管、撤僑及資訊合作，但避免公開參戰。
- **越南**：提高軍事戒備，反對區域強制改變現狀，但維持自主立場。
- **印尼**：推動停火與東協外交，避免軍事介入。
- **馬來西亞及泰國**：以中立、航運與人道議題為主。
- **柬埔寨及寮國**：較不願公開採取強硬反中立場。
- **菲律賓**：因同盟與地理因素，反應最可能偏向美國。

# 第六篇｜俄羅斯與北韓

## 十七、俄羅斯

俄羅斯直接派遣大規模軍力進入臺海的可能性低，但可提供：

- 外交與宣傳支持。
- 聯合國安理會否決或阻礙。
- 能源、金融及制裁緩衝。
- 情報與技術合作。
- 在歐洲、北極或其他區域增加壓力。
- 協助中國分散美歐資源。

| 俄羅斯行動 | 可能性 |
|---|---:|
| 支持中國外交敘事 | 85–95% |
| 阻止安理會實質行動 | 80–95% |
| 能源、金融或制裁緩衝 | 60–80% |
| 在其他戰區加壓 | 50–70% |
| 直接派兵臺海 | 5–10% |

## 十八、北韓

北韓最具價值的作用是形成第二戰場。

| 北韓行動 | 可能性 |
|---|---:|
| 飛彈試射或軍事挑釁 | 50–75% |
| 網路及金融攻擊 | 45–70% |
| 牽制韓美兵力 | 70–90% |
| 提供中國有限物資或情報 | 20–40% |
| 直接參與臺海作戰 | 5–15% |

# 第七篇｜聯合國與國際制度

## 十九、聯合國安全理事會

中國是安理會常任理事國，對非程序性決議具有否決能力。因此：

- 安理會很可能召開緊急會議。
- 中國可否決直接譴責或授權強制行動的決議。
- 俄羅斯也可能支持中國或阻止西方方案。
- 安理會難以成為實際軍事或制裁授權中心。

| 安理會結果 | 可能性 |
|---|---:|
| 陷入否決與僵局 | 95–99% |
| 通過實質強制決議 | 1–5% |
| 通過有限人道或程序性措施 | 20–40% |

## 二十、聯合國大會與其他平台

可能出現：

- 緊急特別會議。
- 多數國家要求停火。
- 對使用武力及攻擊民用基礎設施的政治譴責。
- 全球南方國家在譴責、制裁與中立間分化。
- 國際法院及其他法律程序需要較長時間，無法即時解決戰局。

# 第八篇｜全球經濟與市場反應

## 二十一、開戰後0至24小時

最可能的市場反應：

- 臺灣及區域金融市場劇烈下跌或暫停部分交易。
- 航空及海運避開臺灣周邊。
- 戰爭保險及再保險費率急升。
- 半導體、電子、航運、能源及金融價格劇烈波動。
- 企業啟動人員撤離及供應鏈應變。
- 中國及香港市場承受資本外流壓力。
- 全球投資人轉向美元、黃金及其他避險資產。

## 二十二、7至30日

- 半導體與電子供應中斷。
- 航運改道及港口壅塞。
- 亞洲能源與原料價格上升。
- 中國與G7金融及科技關係迅速惡化。
- 跨國企業暫停中國及臺灣部分業務。
- 全球製造業面臨零件、晶片及物流短缺。
- 各國政府討論戰略物資配給與企業援助。

## 二十三、90日與一年

若戰爭未結束：

- 全球供應鏈形成西方、中國及中立市場三個區塊。
- 企業加速撤離高風險地區。
- 半導體、海纜、衛星、造船與軍工產能成為國家政策。
- 亞洲軍費及核武討論升高。
- 東協與全球南方承受更強烈的選邊壓力。
- 中國經濟可能面臨制裁、失業、出口及金融壓力。
- 臺灣則面臨長期重建、人口、金融與產業外移問題。

# 第九篇｜真實時間軸多國推演

## 二十四、戰前72小時

### 中國

- 宣布大型軍演、海警執法或禁限航區。
- 增加網路、認知與情報活動。
- 對外宣稱不會發動戰爭或指責臺灣挑釁。
- 警告外國不得介入。

### 臺灣

- 提高軍政戒備。
- 保護政府命令及通信。
- 向盟國通報異常。
- 加強海纜、金融、能源及醫療準備。
- 避免因單一情報造成恐慌。

### 美國及盟國

- 增加情報監視。
- 進行秘密磋商及軍力分散。
- 準備撤僑、制裁與後勤。
- 尚未公開宣布戰爭判斷。

### 全球市場

- 保險及航運風險先行升高。
- 企業減少臺灣周邊運輸。
- 金融市場提前反映戰爭風險。

---

## 二十五、開戰後0至6小時

### 臺灣

- 啟動國家持續運作。
- 驗證中央命令及代理順位。
- 實施通信、電力及金融分級。
- 向主要夥伴正式通報武裝攻擊。
- 公開可驗證的攻擊證據。

### 美國

- 啟動最高層國安決策。
- 提供情報、衛星、資安及通信。
- 印太基地及部隊進入高度戒備。
- 暫不必然直接開火。

### 日本

- 西南諸島及基地高度戒備。
- 防護在日美軍及自衛隊。
- 準備撤離與避難。
- 與美國協商基地使用。

### 其他國家

- 澳洲、韓國及菲律賓進入危機磋商。
- G7及歐盟準備共同聲明。
- 俄羅斯與北韓觀察並準備牽制。

---

## 二十六、6至24小時

最可能發生：

- G7召開緊急磋商。
- 美國及盟國公布首輪限制。
- 日本允許美軍增加基地及後勤使用。
- 澳洲提供情報與資安支援。
- 韓國提高對北韓戒備。
- 菲律賓啟動撤僑及有限基地協調。
- 英國、法國、加拿大及歐盟譴責中國。
- 俄羅斯支持中國敘事。
- 安理會召開會議但無法通過實質決議。

---

## 二十七、24至72小時的三個分岔

### 分岔A：中國未攻擊盟國

- 美國大量支援但可能暫不直接開火。
- 日本提供基地、情報與後勤。
- G7啟動金融與科技制裁。
- 菲律賓與澳洲提供不同程度的基地及後勤。
- 東協及印度呼籲停火。
- 中國試圖以停火談判分化盟國。

### 分岔B：中國攻擊美軍、日本或菲律賓資產

- 美國直接軍事反擊可能性升至85–95%。
- 日本直接介入可能性升至80–95%。
- 澳洲支援及可能作戰參與增加。
- 菲律賓基地與同盟合作大幅擴大。
- 戰爭轉為西太平洋區域戰爭。

### 分岔C：中國宣布停火但維持封鎖

- 印度、東協及部分歐洲國家要求談判。
- 美國與日本面臨是否維持或突破封鎖的決策。
- 臺灣受到更高的政治、金融及民生壓力。
- 中國以「有限行動」爭取國際中立。

# 第十篇｜14日、30日、90日及一年情境

## 二十八、14日內三條主路線

| 路線 | 中央估計 | 合理區間 |
|---|---:|---:|
| 大規模支援，但盟國暫不直接攻擊中國 | 40% | 30–50% |
| 美國主導直接介入，區域戰爭擴大 | 45% | 35–60% |
| 主要採制裁與人道支援，避免直接軍事介入 | 15% | 10–25% |

### 路線一：支援但不直接參戰

盟國提供：

- 情報、衛星及資安。
- 通信、物資、軍售及後勤。
- 金融、科技及出口制裁。
- 航運、保險及人道支援。

可能結果：

- 臺灣30日內維持政府運作：60–75%。
- 中國迫使重大政治讓步：25–40%。
- 封鎖及對峙可能持續一個月以上。

### 路線二：美日直接介入

可能結果：

- 臺灣30日內政府存續：75–90%。
- 中國快速迫使臺灣投降：5–15%。
- 區域戰爭擴大及持續：60–80%。
- 日本、菲律賓及美軍基地受攻擊風險極高。
- 全球經濟衝擊最大。

### 路線三：主要制裁而不直接介入

可能結果：

- 臺灣30日內維持完整運作：35–55%。
- 被迫接受停火或部分政治條件：40–60%。
- 中國加強封鎖、認知及經濟壓力。
- 制裁無法立即解除臺灣困境。

## 二十九、30日中央情境

最可能的中央情境不是：

- 中國30日內完成全面占領。
- 或盟國第一日即同步全面參戰。

更可能是：

> 臺灣遭重大基礎設施與經濟破壞，美國、日本、澳洲提供快速支援，美國逐步提高軍事介入，G7建立制裁，亞洲盟國依本國受攻擊程度加入，戰爭轉成封鎖、反封鎖、通信與後勤競爭。

| 30日結果 | 可能性 |
|---|---:|
| 臺灣政府仍有效運作 | 60–80% |
| 中國未取得政治投降 | 65–85% |
| 美中直接軍事交火 | 45–65% |
| 日本直接捲入軍事衝突 | 35–55% |
| 中國與G7形成全面經濟戰 | 80–95% |
| 戰爭持續超過30日 | 60–80% |
| 中國30日內完成全面占領 | 5–15% |
| 停火迫使臺灣接受部分條件 | 20–40% |

## 三十、90日情境

### 情境A：區域戰爭擴大

- 美日與中國直接交火。
- 菲律賓及澳洲支援深化。
- 北韓提高軍事壓力。
- G7與中國全面經濟切割。
- 臺灣持續獲援，但基礎設施及社會成本極高。

### 情境B：長期封鎖與談判

- 中國維持海空壓力。
- 盟國維持後勤、情報及部分航運支援。
- 東協、印度及歐洲推動停火。
- 臺灣面臨能源、醫療、金融及政治疲勞。

### 情境C：有限停火

- 雙方停止部分軍事行動。
- 封鎖、檢查或政治條件未完全解除。
- 國際監督及談判機制建立。
- 臺灣需避免停火被轉化為長期主權侵蝕。

## 三十一、一年情境

### 可能結果一：臺灣維持自主但嚴重受損

- 政府與國軍持續存在。
- 國際支援制度化。
- 經濟、人口及產業長期外移。
- 臺灣進入重建及高度安全化社會。

### 可能結果二：形成長期軍事分界與封控

- 臺海成為長期高風險區。
- 航運、保險及投資模式永久改變。
- 亞洲軍備競賽及核討論升高。

### 可能結果三：臺灣被迫接受不利政治安排

通常需要同時出現：

- 臺灣政府或軍事指揮失能。
- 盟國直接支援不足。
- 通信、能源及物資無法持續。
- 內部政治分裂。
- 中國仍有能力維持封鎖及控制升級。

### 可能結果四：中國承受重大內外壓力而降級

可能因素：

- 戰爭未能快速成功。
- 制裁及出口中斷。
- 軍事損失。
- 國內經濟、金融及民怨升高。
- 盟國合作比北京預期更強。

# 第十一篇｜臺灣如何提高盟國介入意願

## 三十二、前72小時的外交與支援順序

臺灣不應只提出「請派兵」，而應提供可執行的分級需求。

### 第一順位：維持合法政府與通信

- 衛星頻寬。
- 情報及預警。
- 網路防禦。
- 政府身分、憑證及命令驗證。
- 海纜與跨境通信支援。

### 第二順位：維持民生與經濟

- 醫療、藥品及大量傷患支援。
- 能源及關鍵維修零件。
- 金融、支付及流動性支援。
- 航運、保險及人道物資。

### 第三順位：安全與拒止

- 海空域監視。
- 封鎖法律歸責。
- 商業交通線支援。
- 防禦性軍事後勤及戰力支援。

## 三十三、讓盟國相信援助有效

臺灣必須證明：

- 合法政府仍存在。
- 命令可驗證。
- 援助可安全接收及分配。
- 敏感情報可受到保護。
- 政府沒有因假命令或政治分裂失能。
- 臺灣仍有明確防衛意志。
- 國際支援不會立即落入紅方控制。

## 三十四、證據與國際歸責

臺灣應快速整理：

- 中國首先使用武力的時間線。
- 海纜、通信及民用設施受損證據。
- 平民傷亡及人道需求。
- 網路、假命令及資訊操作證據。
- 對國際航運、航空及第三國公民的影響。

公開內容需兼顧：

- 可驗證。
- 不洩漏敏感防禦資訊。
- 多語言。
- 由盟國或獨立機構交叉確認。

10. 未將臺灣政府是否撐過72小時視為盟國決策核心。

# 第十三篇｜兵推裁決

## 三十七、中央裁決

在「中國首先攻擊臺灣、切斷大量海纜、破壞基礎設施，但第一波避免攻擊盟國」的情境下：

- 盟國立即提供情報、通信、資安與外交支援的可能性極高。
- G7建立制裁及經濟安全措施的可能性高。
- 美國在第一日直接開火仍具有不確定性。
- 美國介入機率會在72小時至14日內隨戰局升高。
- 日本最可能先提供基地、後勤、預警及國土防衛。
- 菲律賓及澳洲可能提供不同程度的基地、情報及後勤。
- 韓國以防止北韓第二戰場為主要任務。
- 歐洲主要採制裁、資安、人道及經濟措施。
- 印度及多數東協國家偏向停火、中立與人道角色。
- 俄羅斯與北韓會增加中國的外交、經濟與戰略空間。
- 聯合國安理會幾乎必然僵局。

## 三十八、最重要的分岔點

1. 中國是否攻擊美軍及盟國資產。  
2. 臺灣是否撐過前72小時。  
3. 日本是否允許美軍充分使用基地。  
4. 菲律賓是否開放北部後勤與監視節點。  
5. 北韓是否同步製造危機。  
6. 中國是否宣布停火但維持實質封鎖。  
7. 臺灣能否提供可信證據及分級支援需求。  
8. 盟國國內政治是否支持持續承擔成本。

## 三十九、臺灣的戰略重點

> 臺灣最重要的工作不是預設盟國一定如何反應，而是讓各國在自身法律與政治條件下，都有充分理由、可信資訊及可執行方案，逐步提高對臺支援並降低中國快速迫降的可能。
