# 臺灣藍方國家持續運作與全社會防衛架構

> 文件定位：防禦研究、政策規劃、跨部門演練與韌性建設  
> 版本：1.0  
> 日期：2026-08-03  
> 語言：臺灣繁體中文  
> 使用限制：本文件只描述防禦架構、持續運作、風險治理與演練需求；不列出特定設施位置、弱點、攻擊優先序、破壞方法或可供敵對行為者直接利用的細節。

---


## 0. 執行摘要

臺灣藍方不能只以「擊退軍事進犯」作為唯一目標。現代國家級衝突可能同時結合政治滲透、軍事壓迫、海空封控、海底電纜與衛星通信降級、供應鏈與能源短缺、網路預置、金融恐慌、深偽命令、假旗事件、地方治理失序及認知戰。

因此，本架構把國家防衛定義為五項同時成立的能力：

1. **合法指揮持續存在**：任何單一人物、建築或指揮節點失效，都不能讓憲政與軍政命令中斷。
2. **軍事與公共安全系統持續運作**：感測、通信、後勤、警消、海巡、醫療與地方治理必須能降級但不中斷。
3. **關鍵基礎設施具備替代與復原能力**：海纜、電力、電信、金融、港口、醫療、供水、糧食與數位身分均需建立多層備援。
4. **社會能辨識可信資訊**：即使網路降速、深偽與假公告同時出現，人民仍能確認合法政府、金融狀態、避難資訊與民生供應。
5. **國家能持續接收外援並恢復**：外交、安全通信、港口與機場接收、海關查驗、國際標準與物資分配均須事先制度化。

本文件分為四卷：

- 第一卷：國家指揮與軍事防衛
- 第二卷：關鍵基礎設施與數位韌性
- 第三卷：民生、地方與社會韌性
- 第四卷：危機推演、復原與國際支援

### 0.1 最高原則

> 任何一個人、建築、基地、海纜、港口、資料中心、承包商、雲端供應商或指揮節點失效，都不能單獨使整個國家停止運作。

### 0.2 證據與規劃等級

| 等級 | 定義 | 文件用途 |
|---|---|---|
| A級 | 已有公開案件、法律、政策或官方演練支持 | 可直接納入制度建設 |
| B級 | 官方風險評估、盟國經驗或跨域趨勢支持 | 應納入演練與風險管理 |
| C級 | 最壞情境紅隊推演，尚無法證明已部署 | 僅用於壓力測試，不作為指控 |
| D級 | 需受限情資、技術鑑識或司法證據確認 | 不應寫入公開版本的具體判定 |

### 0.3 治理底線

- 依**行為、金流、權限、通聯、技術鑑識及司法證據**判斷風險。
- 不以國籍、族群、宗教、政黨或政策立場作為涉敵推定。
- 反滲透不能取代正當法律程序。
- 戰時效率與民主監督必須同時存在。
- 所有受限清冊均應分級、留痕、定期稽核並設置申訴與更正機制。

# 第一卷：國家指揮與軍事防衛

## 1. 國家指揮與憲政延續

### 1.1 防護對象不是建築，而是功能

總統府、行政院、國安會、中央部會及其他憲政機關都應被視為「功能集合」，而不是單一地點。藍方需要保護：

- 合法統治與代理順位
- 國家安全決策
- 軍政命令授權
- 跨部會危機協調
- 中央與地方權限轉換
- 對內與對外可信訊息發布
- 機密資料與歷史紀錄
- 國際承認與友盟聯絡

### 1.2 憲政延續最低能力

| 功能 | 最低要求 | 驗證方式 |
|---|---|---|
| 代理順位 | 法律明確、名冊即時、跨機關理解一致 | 無預警桌上推演 |
| 異地辦公 | 至少具備多個分散地點與遠端替代 | 真實切換測試 |
| 命令驗證 | 密碼學簽章、人工複核、離線驗證碼 | 深偽與帳號遭竊演練 |
| 中央地方協調 | 失聯時可依法預授權 | 24至72小時失聯演練 |
| 國際通信 | 具備不同供應商與不同傳輸介質 | 斷網情境實測 |
| 公共資訊 | 網路、廣播、簡訊與實體據點多路發布 | 全國訊息一致性稽核 |

### 1.3 必須演練的情境

- 主要政府辦公場所無法使用。
- 高階首長部分失聯或同時無法履職。
- 假總統、假院長或假部長影片宣布停戰、撤離或金融管制。
- 中央與地方收到互相矛盾的命令。
- 官方社群帳號遭盜用。
- 國際媒體無法確認合法政府是否仍運作。
- 外部通訊品質嚴重下降，但國內網路仍部分可用。
- 法律授權與實際執行之間出現空窗。

### 1.4 建議制度

1. 建立「國家持續運作法制盤點」，逐條檢視代理、授權、緊急採購、資料共享與地方預授權。
2. 建立高階命令的多因子簽章制度，且不得只依賴網際網路。
3. 建立跨政府輪替仍可持續的制度化SOP，避免政策只依賴個別首長。
4. 建立每年至少一次的「合法政府持續存在」全國演練。
5. 受限清冊不得只列主要辦公地點，還須列替代地點、通信、電力、交通、醫療與人員輪替依賴。

## 2. 軍事指揮、管制、通信、情報與監偵

### 2.1 目標

確保部分感測器、資料鏈或指揮節點失效時，國軍仍能形成可用情勢圖、驗證命令、分配資源並維持跨軍種協同。

### 2.2 核心能力

- 聯合作戰與跨軍種指揮
- 空情、海情、地面與網路情勢融合
- 雷達、光電、無人系統與友盟情資交叉驗證
- 軍事資料鏈與備援通信
- 電子戰與定位授時備援
- 假情報、資料污染與深偽命令排除
- 基層單位在失聯情境下的預授權與任務式指揮
- 與警政、海巡、消防、電信及交通機關的必要資訊交換

### 2.3 共同情勢圖的可信度管理

共同情勢圖不應只有「顯示資料」，還要顯示：

- 資料來源
- 更新時間
- 信心水準
- 是否經第二來源驗證
- 是否可能遭到干擾或欺騙
- 失聯或異常區域
- 決策者應採取的保守假設

### 2.4 失聯時的指揮原則

- 預先定義最低合法授權。
- 任務目標優先於逐項指令。
- 明確規定不得因單一未驗證訊息改變重大行動。
- 同一命令應能透過至少兩種不同介質確認。
- 每一層指揮官都必須知道何時等待、何時自主處置、何時回報。

## 3. 戰力保存與基地韌性

### 3.1 公開規劃應列功能，不列弱點

公開版可列：

- 戰力分散與機動
- 替代作業地點
- 跑道、港勤、道路與通信搶修
- 裝備維修、備件與燃料
- 防空、防無人機與周界警戒
- 傷患後送與人員輪替
- 軍民承包商風險
- 基地周邊可疑監視與資料蒐集防護

受限版才列：

- 個別節點
- 依賴關係
- 最大可容忍中斷時間
- 備援切換條件
- 修復人員、設備與零件需求

### 3.2 戰力保存成熟度

| 等級 | 特徵 |
|---|---|
| 1 | 依賴主要固定設施，備援停留在文件 |
| 2 | 有替代地點但未實際切換 |
| 3 | 可在演習中完成有限切換 |
| 4 | 可在跨系統失效下持續任務 |
| 5 | 可在長期封控與多點受損下分散作戰並持續補充 |

## 4. 後勤、維修與戰力再生

### 4.1 後勤不是倉庫，而是流動系統

應同時盤點：

- 燃料
- 彈藥
- 備件
- 維修工具
- 工程車輛
- 醫療與傷患後送
- 人員輪替
- 軍民運輸
- 倉儲與配送
- 港口、機場、公路、鐵路與海運
- 資料系統與人工替代流程

### 4.2 修復能力

藍方需建立「國家修復產業鏈清冊」：

- 海纜與電信搶修
- 電力輸配與大型設備
- 港口、機場、道路、橋梁與鐵路
- 工業控制系統
- 大型機械與特殊零件
- 外國原廠與技術支援
- 工程人員住宿、交通、安全與輪班
- 物料耗盡後的替代方案

### 4.3 不可忽略的人因

- 維修人員疲勞
- 家屬安全與心理壓力
- 交通不便
- 假派工與假命令
- 承包商帳號遭盜用
- 優先順序衝突
- 民眾阻擋、圍觀或搶購造成的延誤

## 5. 後備、動員與民力整合

### 5.1 必須回答的問題

- 後備部隊在不同危機階段的具體任務是什麼？
- 哪些專業人力必須動員，哪些不宜離開原職？
- 工程、醫療、資安、通信、運輸及能源人力如何認證？
- 民間志工如何避免重複報到或未授權行動？
- 車輛、機具、倉儲及場地徵用如何補償與追蹤？
- 中央與地方的指揮權如何分配？
- 民間組織是否具備背景查核與身分驗證？

### 5.2 民力整合原則

- 專業優先，不追求人數虛高。
- 任務、權限與責任明確。
- 志工與正式執法人員權限分開。
- 物資、人員與交通均應數位及紙本雙軌管理。
- 禁止自發武裝、私設檢查哨或未授權拘留。

## 6. 情報融合、反情報與內部威脅

### 6.1 國家級威脅融合中心

應整合：

- 國安
- 軍事
- 警政
- 調查
- 海巡
- 海關
- 移民
- 金融
- 資安
- 電信
- 地方政府
- 關鍵產業通報

### 6.2 六類關係圖

1. 人與人  
2. 人與公司  
3. 公司與金流  
4. 帳號與設備  
5. 設備與事件  
6. 事件與上層指揮或受益者  

### 6.3 內部威脅風險

- 金錢利誘
- 債務
- 家屬壓力
- 犯罪或私密把柄
- 政治或理念認同
- 海外職涯與商業利益
- 先接受小任務後逐步被綁定
- 退役人員接觸現役人員
- 外包商與臨時帳號濫用

### 6.4 主動通報與減責

藍方應建立可保密的主動通報機制：

- 第一次遭接觸即可求助。
- 被脅迫者不應自動視為敵對代理人。
- 依主動性、持續性、損害與配合程度區分責任。
- 提供法律、財務、心理與家屬安全協助。
- 防止受脅迫者因害怕被處罰而轉入地下。

### 6.5 防止反情報被污染

演練下列情境：

- 大量假檢舉
- 偽造金流與通聯
- 假文件與AI生成證據
- 冒充吹哨者
- 誘使政府錯抓無辜人士
- 真正網絡利用政治爭議掩護撤離

## 7. 警政、消防、海巡與國內秩序

### 7.1 核心任務

- 重要人員與維修團隊安全
- 假爆炸、假火災與大量報案分流
- 港口、沿岸與海上事件處置
- 維持交通、配送與醫療通道
- 防止代理暴力、黑幫或極端團體擴大混亂
- 監所、拘留、證人與線民安全
- 跨縣市支援與資源調度

### 7.2 治安韌性指標

- 報案系統降級後是否可運作
- 跨縣市警力調度時間
- 消防與醫療派遣是否共享情勢
- 假警報辨識率
- 重要修復隊伍護送能力
- 監所備援電力、供水與通信
- 證據與案件紀錄的離線保存

---

## 8. 法律、司法與民主監督

### 8.1 戰時法治底線

- 緊急權力必須有法律依據與期限。
- 搜索、拘捕、凍結資產與通信監察須有授權及紀錄。
- 軍事與民事權限界線清楚。
- 反滲透措施須提供申訴與更正。
- 假資訊不能成為壓制合法批評的理由。
- 戰時採購、徵用與資源分配須可稽核。
- 司法、檢察及證據保存須具備異地與離線能力。

### 8.2 監督設計

- 事前法律審查
- 事中留痕與多方授權
- 事後國會、司法與審計檢視
- 機密內容分級揭露
- 錯誤措施的補償與更正

# 第二卷：關鍵基礎設施與數位韌性

## 9. 海底電纜與對外通信

### 9.1 核心問題

不能只問「臺灣有幾條海纜」，而要問：

- 每條線路承載哪些政府、金融、軍事、醫療與商業功能？
- 登陸站、國內骨幹及資料中心是否集中？
- 多條海纜中斷後，剩餘容量如何分配？
- 衛星、微波與無線電能支撐哪些最低功能？
- 維修船、許可、零件、人員與安全護送多久能到位？
- 離島如何維持通信？
- 海纜事件如何區分事故、過失、犯罪與敵對行動？

### 9.2 通信優先級

| 優先級 | 服務 |
|---|---|
| 第一級 | 國家指揮、國防、警政、電力、水務、醫療、外交安全通信 |
| 第二級 | 金融清算、港口物流、政府公共資訊、關鍵企業 |
| 第三級 | 一般商業服務、影音串流與非必要流量 |

### 9.3 必要能力

- 海纜狀態監控與跨機關共享
- 多家國際業者與不同路徑
- 國內流量本地化
- 重要服務可在國際斷線時維持
- 海纜維修契約、船舶、備料與國際協作
- 危機時流量優先排序
- 對民眾公開實際影響，避免「局部降速」被誤認為「全面斷網」

## 10. 衛星、電信、微波與緊急通信

### 10.1 多層備援原則

固定網路、行動網路、衛星、微波、短波、專網與實體傳遞應形成多層體系，且：

- 不依賴單一國家
- 不依賴單一業者
- 不依賴單一軌道或頻段
- 不使用相同帳號與管理平台
- 不共享同一電力與機房單點

### 10.2 基地台與核心網路韌性

- 基地台備用電力
- 優先燃料配送
- 可移動基地台
- 核心網路異地備援
- 政府與警消優先通話
- 國內簡訊與警報
- 漫遊與跨業者互援
- 網路降速下的必要服務白名單

### 10.3 緊急命令的離線驗證

政府與軍方命令應能透過：

- 預先發放的驗證碼表
- 密碼學簽章
- 多人共同確認
- 廣播與實體公告交叉驗證
- 不同通信介質重複確認

## 11. 數位身分、憑證與信任基礎

### 11.1 保護對象

- 政府憑證
- 電子簽章
- 公務高權限帳號
- 國民身分驗證
- 金融與醫療認證
- DNS與網域
- 時間同步
- 官方社群帳號
- 緊急警報系統
- 裝置與軟體更新簽章

### 11.2 最黑暗情境

不是全面斷網，而是：

- 系統仍能運作，但資料真假不明。
- 官員仍能發文，但帳號已被冒用。
- 民眾看到警報，卻無法確認來源。
- 銀行餘額存在，卻無法確認交易是否正確。
- 不同機關使用不同時間基準，導致紀錄與命令順序混亂。

### 11.3 復原要求

- 快速撤銷與重發憑證
- 乾淨根憑證與離線保管
- 重要帳號雙人管理
- 高風險操作實體授權
- 被盜帳號的替代發布管道
- 公眾可查驗的官方驗證頁面與離線方式

---

## 12. 網路防禦、供應鏈安全與可信復原

### 12.1 防禦重點

- 行政網與工控網隔離
- 特權帳號管理
- 零信任與最小權限
- 軟體物料清單
- 韌體與更新簽章
- 遠端維護限制
- 外包商與承包商背景及權限管理
- 長期日誌與異常行為分析
- 資料外洩、篡改與可用性同時監控

### 12.2 備份不等於可復原

每套備份都要回答：

- 是否與主系統使用同一管理帳號？
- 是否可能已被同步污染？
- 是否離線？
- 是否異地？
- 是否定期真實還原？
- 還原後如何確認資料可信？
- 是否有乾淨作業系統與應用程式映像？
- 是否保留足夠長期日誌追查潛伏？

### 12.3 網路預置應對

藍方應假設敵對行為者可能在危機前已取得部分存取，演練：

- 高權限帳號同時失效
- 多個外包商憑證被濫用
- 監控畫面與現場狀況不一致
- 大量假警報
- 勒索軟體掩護國家行動
- 修復時再次遭入侵
- 備份與更新伺服器被污染

# 第四卷：危機推演、復原與國際支援

## 29. 危機階段模型

### 29.1 第一階段：平時塑形

可能特徵：

- 滲透、資金與人員接觸
- 網路預置
- 供應鏈依賴
- 認知議題測試
- 海上與空中灰色地帶壓力
- 對政府與企業應變流程蒐情

藍方任務：

- 發現與拆網
- 降低依賴
- 建立備援
- 強化通報
- 進行壓力測試

### 29.2 第二階段：壓力升高

可能特徵：

- 軍演
- 海警與執法敘事
- 網攻增加
- 海纜或航運事件
- 貿易與市場壓力
- 社群假訊息同步增加

藍方任務：

- 提升警戒但避免過度反應
- 啟動跨部門融合
- 保護重要人員與節點
- 對外溝通
- 預置民生與金融措施

### 29.3 第三階段：複合壓迫

可能特徵：

- 海空隔離
- 通訊降級
- 能源與港口受壓
- 金融恐慌
- 內應或代理事件
- 深偽命令

藍方任務：

- 維持合法指揮
- 進入最低持續運作模式
- 分散資源
- 驗證命令
- 控制恐慌
- 接收外援

### 29.4 第四階段：高強度危機

藍方目標：

- 國家不失去合法性
- 軍政指揮不中斷
- 民生最低功能持續
- 外援通道存在
- 社會不因假訊息自我瓦解
- 關鍵資料與證據保存
- 為恢復與究責保留能力

---

## 30. 演練設計

### 30.1 第一級：單點故障

- 一條海纜
- 一處電信節點
- 一間醫院
- 一個港口資訊系統
- 一個政府高權限帳號
- 一個地方資料中心

### 30.2 第二級：跨系統失效

- 停電加電信降速
- 海纜加雲端故障
- 港口阻塞加假缺糧消息
- 銀行延遲加擠兌
- 水務資料異常加污染謠言
- 物流系統故障加道路堵塞

### 30.3 第三級：區域危機

- 一縣市與中央部分失聯
- 多間醫院超載
- 交通與供水同時異常
- 地方首長遭深偽冒充
- 大量人口跨區移動
- 鄰近縣市同時求援

### 30.4 第四級：全國複合壓力

- 高強度海上脅迫
- 多條海纜異常
- 能源進口減少
- 網路及金融攻擊
- 認知戰
- 內部破壞或假旗事件
- 軍事活動同步升高

### 30.5 第五級：國家指揮受損

- 中央主要辦公場所無法使用
- 軍政高層部分失聯
- 中央地方命令不一致
- 國際通信受阻
- 假投降聲明
- 國內外質疑合法政府狀態

## 31. 演練方法

### 31.1 不只做成功劇本

演練必須加入：

- 通訊真的中斷
- 備援切換失敗
- 錯誤情報
- 承包商未到場
- 零件不足
- 跨機關資料不一致
- 人員疲勞
- 民眾不配合
- 媒體質疑
- 法律授權爭議

### 31.2 紅隊、藍隊與白隊

- **紅隊**：設計複合壓力、資訊污染與決策困境。
- **藍隊**：執行政府、軍事、企業與地方應變。
- **白隊**：裁判、法遵、資料紀錄與安全控制。
- **紫隊**：促進紅藍即時學習，但不洩漏真實受限弱點。

### 31.3 演練產出

每次演練必須留下：

- 決策時間
- 資源請求
- 失敗點
- 權責衝突
- 通信狀態
- 備援切換
- 公眾訊息
- 法律問題
- 修復時間
- 改善責任人與期限

## 32. 1：1國家功能與資產清冊

### 32.1 公開版與受限版

**公開版**只列：

- 功能類別
- 主管機關
- 防護原則
- 演練制度
- 社會配合方式

**受限版**逐一列出節點，但不公開名稱、位置、依賴與缺口。

### 32.2 清冊欄位

| 欄位 | 說明 |
|---|---|
| 資產編號 | 不以公開名稱作唯一識別 |
| 核心功能 | 維持何種國家能力 |
| 主管與備援單位 | 誰負責、誰接手 |
| 主要與替代節點 | 主要失效後的替代 |
| 上游依賴 | 電力、電信、燃料、雲端、人員、供應商 |
| 下游影響 | 失效後影響哪些服務 |
| MTPD | 最大可容忍中斷時間 |
| MBCO | 最低業務持續能力 |
| RTO | 目標復原時間 |
| RPO | 可容忍資料損失 |
| 降級模式 | 完整功能不可用時如何運作 |
| 修復需求 | 人員、設備、零件、交通、安全 |
| 高權限人員 | 內部與承包商權限 |
| 命令驗證 | 防止假指令 |
| 公眾訊息 | 如何證明功能仍運作 |
| 最近演練 | 是否真實切換 |
| 缺口與期限 | 未改善、改善中、已驗證 |

### 32.3 清冊安全

- 最小知悉
- 分區存放
- 查閱留痕
- 定期更正
- 不在單一系統保存全貌
- 防止內部人員一次匯出
- 對外合作只分享必要資訊
- 離職、調職即時撤權

## 34. 戰後與危機後復原

### 34.1 復原不只是修復設施

還包括：

- 合法政府與公共信任
- 經濟與金融
- 教育與公共服務
- 傷亡與失蹤
- 心理與社會創傷
- 司法與究責
- 數據與歷史紀錄
- 企業與就業
- 國際關係
- 地方重建

### 34.2 復原優先順序

1. 生命安全

4. 糧食、燃料、物流
5. 金融與企業支付
6. 教育與社會服務
7. 長期產業與基礎設施重建

### 34.3 防止二次傷害

- 重建資金貪腐

- 錯誤拘捕
- 假失蹤與死亡名單
- 資料遺失
- 社會污名化
- 創傷後政治操控
- 敵對網絡趁復原期重新建立

## 35. 建設時程

### 35.1 第一階段：0至180日

1. 完成國家功能與關鍵節點清冊。
2. 檢視中央與地方代理順位。
3. 建立高階命令驗證制度。
4. 盤點海纜、衛星、微波及緊急通信。
5. 確認能源、醫療、糧食與燃料最低維持量。
6. 清查高權限帳號及關鍵承包商。
7. 進行港口、金融及地方政府聯合桌上推演。
8. 建立全國可信訊息入口。
9. 建立主動通報與受脅迫者支援。
10. 為每項缺口指定責任人與期限。

### 35.2 第二階段：6至24個月

- 異地指揮中心實際切換
- 多層通信備援
- 分散式能源與物資
- 港口及物流人工替代流程
- 政府與關鍵企業離線作業
- 國家威脅融合平台
- 地方實兵演練
- 海纜搶修與國際協作
- 金融低頻寬與離線支付
- 醫療及長照韌性提升

### 35.3 第三階段：2至5年

- 30至90日國家持續運作能力
- 自主維修與關鍵零件
- 多層國際通信
- 分散式國防與工業生產
- 區域救援與補給走廊
- 無預警跨系統壓力測試
- 跨政府輪替的制度化持續
- 國際聯合演練
- 全國韌性稽核與公開摘要

## 37. 國家級自我審查清單

### 指揮

- [ ] 代理順位是否所有相關機關理解一致？
- [ ] 主要辦公場所失效後是否曾實際切換？
- [ ] 假命令與深偽是否有離線驗證？
- [ ] 中央失聯時地方是否有預授權？

### 軍事與公共安全

- [ ] 部分感測器失效時是否仍能形成情勢圖？
- [ ] 基層失聯時是否知道合法自主範圍？
- [ ] 警消海巡是否能共享最低必要資料？
- [ ] 後勤與修復人員是否受到保護？

### 通信與數位

- [ ] 多條海纜中斷時是否有流量排序？
- [ ] 衛星、微波與無線電是否真實可用？
- [ ] 政府核心服務能否在國際斷網時運作？
- [ ] 備份是否曾真實還原？
- [ ] 憑證遭竊時是否能快速重建信任？

### 民生

- [ ] 醫療、供水、能源與糧食最低維持量是否可驗證？
- [ ] 物資是否分散？
- [ ] 弱勢人口是否有配送與避難計畫？
- [ ] 金融與支付是否具備降級模式？

### 社會與法治

- [ ] 是否有單一可信資訊入口？
- [ ] 假訊息處理是否兼顧言論自由？
- [ ] 反滲透是否有申訴、更正與監督？
- [ ] 是否防止國籍與政治立場污名化？

### 復原

- [ ] 每項關鍵功能是否有RTO、RPO與MBCO？
- [ ] 修復人力、零件與交通是否盤點？
- [ ] 外援接收是否有標準化流程？
- [ ] 每次演練的改善是否有人負責並按期完成？

## 38. 結論

臺灣藍方的成功，不應以「所有設施毫髮無傷」衡量，而應以：

- 合法政府是否持續存在
- 軍政命令是否可信
- 戰力是否能保存與再生
- 民生最低功能是否持續
- 社會是否仍相信可驗證資訊
- 地方是否能依法運作
- 國際支援是否能進入
- 國家是否能修復、學習並繼續抵抗

作為最終標準。

> 真正的國家韌性，是在部分失敗已不可避免時，仍不讓任何單點失敗演變成全國性崩潰。
