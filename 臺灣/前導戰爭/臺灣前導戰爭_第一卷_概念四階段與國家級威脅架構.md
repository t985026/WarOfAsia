# 臺灣前導戰爭｜第一卷：概念、四階段與國家級威脅架構

## 一、前導戰爭定義

前導戰爭是正式武裝攻擊之前，透過政治、情報、網路、通信、金融、經濟、犯罪、軍事演習與外交分化，預先削弱臺灣國家功能與抵抗意志。

它不一定有正式宣戰、飛彈攻擊或單一公開指揮鏈，更可能偽裝成事故、商業決策、一般犯罪、網路事件、軍演、外交警告與市場反應。

## 二、戰略目的

1. 讓臺灣無法判斷戰爭是否已開始。  
2. 讓中央與地方收到互相矛盾命令。  
3. 使軍政人員不相信通信、憑證與情報。  
4. 以停電、斷網、缺貨、搶購與假消息製造恐慌。  
5. 使企業認為抵抗只會增加成本。  
6. 延遲盟國判斷與介入。  
7. 讓航運、航空、保險及外資自行撤離。  
8. 迫使國軍與政府提前消耗戰備、人力與政治信用。  

## 三、四個階段

### 第一階段：長期塑形

時間可能為開戰前數年至半年：

- 蒐集政府、軍隊、企業、通信、修復與社會資料。
- 培養政治、媒體、地方、企業與社團接觸面。
- 增加市場、軟體、雲端、VPN、eSIM與供應鏈依賴。
- 找出制度、修復能力與社會矛盾。
- 長期灌輸「抵抗無用、盟國不會來」。

### 第二階段：作戰準備

時間可能為開戰前六個月至一個月：

- 網路與情報活動增加。
- 供應商、遠端維護與高權限帳號異常。
- 海纜、物流、航運與金融壓力測試。
- 軍演、海警與準封鎖法律敘事。
- 外國企業及航運降低對臺服務。

### 第三階段：危機啟動

時間可能為開戰前30日至7日：

- 多起看似無關事故與異常同時發生。
- 臺灣難以判斷是否全面提高戒備。
- 政府提早消耗政治信用與戰備資源。
- 國內及盟國對事件性質分歧。

### 第四階段：最後塑形

時間可能為開戰前7日至數小時：

- 破壞命令可信度。
- 降低通信與金融服務。
- 阻礙動員與修復。
- 製造逃難、搶購及投降壓力。
- 把軍演轉為封鎖、有限打擊或全面戰爭。

## 四、十二個國家功能領域

| 領域 | 前導戰爭目標 |
|---|---|
| 政治 | 使國安決策被視為政黨操作 |
| 政府 | 破壞中央地方與命令可信度 |
| 情報 | 蒐集人員、流程、帳號與代理順位 |
| 供應鏈 | 控制資料、零件、遠端維護與替代能力 |
| 網路 | 長期設伏，危機時中斷或誤導 |
| 通信 | 降低海纜、電信、衛星與政府通信可靠性 |
| 能源水務 | 造成服務不穩、限電與民生恐慌 |
| 金融經濟 | 擠兌、資本外流、停產與企業反對 |
| 交通物流 | 使航運、航空、港口與配送萎縮 |
| 醫療社會 | 耗損醫療、製造物資恐慌與秩序問題 |
| 軍事灰區 | 消耗戒備、壓縮海空空間 |
| 外交盟國 | 延遲美日菲韓澳及歐洲共同判斷 |

## 五、三個關鍵係數

### 同步性

單一事件不足以證明前導戰爭；三個以上領域同步升高，風險顯著上升。

### 任務化

一般情報活動若開始關注危機期限、待命啟用、代理順位、修復人員、通信切換、物資與動員，代表已從蒐集轉為準備。

### 不可逆性

高風險徵候包括：

- 部隊演習後未返回。
- 民用運輸轉入特殊狀態。
- 醫療及後勤大量準備。
- 資本、出境、網路與外企管理同步收緊。
- 重要人員、設備與物資實際轉移。

## 六、紅方理想成果

- 政府存在，但命令不被相信。
- 基礎設施存在，但服務不穩。
- 國軍有戰力，但已提前消耗。
- 盟國支持臺灣，但尚未完成決策。
- 民眾未遭全面攻擊，卻已認為抵抗無意義。

## 七、藍方勝利條件

- 政府能正確判斷危機。
- 高階命令可驗證。
- 關鍵服務可降級不停擺。
- 地方能在中央失聯時接替。
- 社會不因假消息及搶購失控。
- 內應與供應鏈風險可依法隔離。
- 盟國取得可信、及時且一致的情勢資訊。

| 等級 | 定義 | 使用原則 |
