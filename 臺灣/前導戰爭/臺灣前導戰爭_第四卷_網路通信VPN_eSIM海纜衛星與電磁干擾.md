# 臺灣前導戰爭｜第四卷：網路、通信、VPN、eSIM、海纜、衛星與電磁干擾

## 一、文件目的

建立面對長期網路設伏、通信供應鏈風險、多點海纜異常、衛星及定位干擾、VPN與eSIM資料集中時的預警與防禦架構。

## 二、長期網路設伏

戰略目的：

- 平時蒐集資料與帳號。
- 危機時中斷、刪除、加密或誤導。
- 使政府無法分辨哪些系統可信。
- 延長復原時間。

徵候：

- 長期低流量異常連線。
- 不明高權限帳號。
- 備份、管理及更新系統異常存取。
- 同一工具跨政府、金融、電信及能源出現。
- 平時次要系統在危機前被大量掃描。

## 三、一般網路犯罪掩護

國家行動可能被包裝成勒索軟體、詐騙、駭客炫技、商業糾紛或供應鏈事故。藍方需比較時間、目標組合、工具重複性及與軍演、外交、金融、海纜事件的同步。

## 四、軟體更新與憑證信任

風險：

- 更新供應鏈遭污染。
- 憑證被冒用或撤銷失敗。
- 政府網站及文件遭偽造。
- 真實命令也被懷疑。

防禦：

- 更新簽章驗證。
- 軟體白名單。
- 離線版本。
- 備份與生產環境分離。
- 緊急憑證撤銷與重發演練。
- 乾淨管理環境。

## 五、VPN與eSIM資料集中

VPN可能掌握來源IP、連線時間、流量大小、DNS、目的服務、帳號、付款及裝置資料。

eSIM及電信可能掌握訂閱識別、基地台與大致位置、漫遊、上游電信商、啟用、付款及裝置識別。

高風險組合：

```text
真實身分與付款
＋
SIM／eSIM識別
＋
基地台與移動
＋
VPN來源與出口
＋
DNS與服務連線
＋
裝置及廣告識別
```

單純低價或中國資本背景不能直接證明情報活動；需依控制權、資料流、法域、權限及協同行為判斷。

## 六、危機時通信停用

可能效果：

- 特定人員或企業失聯。
- 使用者被迫改用不可信平台。
- 政府、企業與海外聯絡中斷。
- 大量設定檔同時失效。

防禦：

- 公務白名單。
- 多家電信及跨網漫遊。
- 實體SIM、eSIM與衛星備援。
- 快速撤銷高風險設定檔。
- 關鍵通信不依賴單一App。

## 七、行動與網路壅塞

紅方不一定要完全中斷，只要利用大量流量、假警報與影片、集中查詢、更新與雲端同步、反覆斷線重連，就可壓縮關鍵頻寬。

優先順序：

1. 國家指揮。  
2. 國防、警消、海巡。  
3. 電力、水務與電信。  
4. 醫療。  
5. 外交與盟國。  
6. 金融清算。  
7. 港口物流。  
8. 公共資訊。  

## 八、多點海纜異常

風險上修：

- 多條路徑短期連續異常。
- 異常船舶與軍演同步。
- 修復船受到阻礙。
- 海纜事件伴隨網攻、金融與假消息。
- 剩餘路由也出現壅塞或設定問題。

防禦：

- 路徑及登陸區分散。
- 跨業者容量調度。
- 衛星、微波與無線電。
- 關鍵頻寬優先。
- 修復外交與保險機制。
- 不把衛星視為全民海纜容量的完全替代。

## 九、衛星、定位與時間同步

可能效果：

- 航運、航空與物流可靠性下降。
- 緊急通信品質不穩。
- 金融與電力時間同步異常。
- 民間事故及軍事誤判增加。

防禦：

- 多重定位與時間來源。
- 地面、無線電與離線替代。
- 重要系統監測時間漂移。
- 導航異常與設備故障分開判斷。

## 十、公共警報與無線電

可能出現假空襲、假撤離、假災難或真實警報受干擾。藍方需統一警報格式、多平台交叉驗證、民眾教育及保留傳統廣播。

## 十一、可信復原

1. 隔離受影響系統。  
2. 建立乾淨管理環境。  
3. 重發密鑰、帳號與憑證。  
4. 驗證軟體映像及備份。  
5. 分階段恢復。  
6. 比對資料完整性。  
7. 長期監控。  
8. 第三方覆核。  

## 十二、兵推注入

1. 三分之二海纜路徑失效。  
2. 大型eSIM供應商停止服務。  
3. VPN出口轉往高風險法域。  
4. 政府憑證信任出現爭議。  
5. 衛星容量不足以支援所有機關。  
6. 行動網路只剩30%服務能力。  
7. 海纜修復船無法立即進入。  
8. DNS、時間同步及金融系統同時異常。  

## 十三、KPI

| 指標 | 建議衡量 |
|---|---|
| 海纜失效後關鍵服務 | 維持率 |
| 衛星及微波切換 | 啟動時間 |
| 關鍵頻寬分級 | 完成時間 |
| 憑證撤銷與重發 | 恢復時間 |
| 跨網漫遊 | 覆蓋率 |
| 低頻寬政府服務 | 可用率 |
| 可信復原 | 通過驗證時間 |

## 十四、結論

通信前導戰爭不一定讓臺灣完全斷網，而是：

> 讓政府、軍隊、金融、企業與民眾無法確定目前使用的網路、身分、時間、位置與命令是否可信。

## 評估方法

| 等級 | 定義 | 使用原則 |
|---|---|---|
| A | 官方法律、制度、公開活動與確認案件 | 基準事實 |
| B | 官方威脅評估、可信研究與多來源判斷 | 主要結論 |
| C | 依公開能力與行為建立的條件式情境 | 明確標示推演 |
| D | 未交叉驗證傳聞或單一匿名指控 | 不納入核心結論 |

同時觀察意圖、能力、準備、跨領域同步、不可逆性及紅方失敗條件。
