# 臺灣前導戰爭｜第二卷：政治、政府運作與認知戰干擾

## 一、文件目的

分析紅方如何降低政府命令可信度、放大政黨極化、破壞中央地方協調，並讓社會對國安措施失去信任。

## 二、政黨與社會極化

### 戰略目的

- 使國安政策被視為政黨鬥爭。
- 讓政府無法取得提高戒備的政治支持。
- 把外部威脅轉化為內部互相指控。
- 污名化反滲透、民防、軍購及盟國合作。

### 可觀察徵候

- 多個媒體、帳號、社團與政治人物突然使用相似敘事。
- 假民調、假文件、深偽與剪輯影片同時出現。
- 境外資金或廣告來源不透明。
- 國安議題被包裝成單一政黨陰謀。

### 藍方防禦

- 跨黨派最低國安共識。
- 公開證據級別與不確定性。
- 區分政治意見與秘密委託。
- 重大措施附法律、期限與監督。

## 三、中央與地方分化

可能目標：

- 讓地方不相信中央命令。
- 製造地方自行談判或拒絕動員的印象。
- 中央失聯時造成行政停擺。

高風險情境：

- 假中央公文。
- 假地方首長聲明。
- 假停班、撤離、配給與封路命令。
- 同一事件出現不同編號與版本。

防禦：

- 中央地方共同事件編號。
- 高階命令數位簽章。
- 第二通信管道人工覆核。
- 地方72小時最低行政預授權。

## 四、假投降、撤離與停戰命令

可能形式：

- 假總統或行政院影片。
- 假國防部停火公告。
- 假盟國撤離及放棄臺灣聲明。
- 假地方政府與中國簽署協議。

防禦原則：

- 投降、停火、撤離與重大動員命令需多重驗證。
- 建立全國通用驗證格式。
- 電視、廣播、簡訊、官方網站、衛星與地方系統同步。
- 事前教育民眾哪些命令必須二次驗證。

## 五、假政府失能敘事

常見內容：

- 中央政府已失聯。
- 總統或行政團隊已撤離。
- 國軍不再接受中央指揮。
- 地方政府各自處理。
- 盟國只協助撤僑，不會支援臺灣。

藍方需固定發布、公布最低政府功能、承認已知與未知，避免過度樂觀破壞信任。

## 六、媒體與平台干擾

風險：

- 股權及廣告資金不透明。
- 內容農場、協同帳號及演算法放大。
- 假直播、假記者與假專家。
- 大量檢舉使官方帳號停權。
- 假查核機構與假官方更正。

防禦：

- 最終受益人及政治廣告透明。
- 平台保留危機時政府驗證機制。
- 民間媒體與查核組織交叉確認。
- 不把所有異議內容視為敵對資訊。

## 七、社會信任攻擊

紅方可利用政黨、世代、地區、族群與職業矛盾，以及軍民資源、避難、配給、傷亡與外國居民議題。

藍方需：

- 公平、可解釋的配給規則。
- 多語資訊。
- 申訴與更正機制。
- 不以族群或國籍集體懷疑。

## 八、行政塞車

可能形式：

- 大量假檢舉、申訴與陳情。
- 假冒機關間公文。
- 不實資料要求。
- 假災情與假失蹤人口。
- 自動化電話及電子郵件壅塞。

藍方需事件分級、緊急與行政訊息分流、關鍵機關離線作業。

## 九、風險分級

| 等級 | 狀態 |
|---|---|
| 綠 | 一般政治競爭與境外宣傳 |
| 黃 | 多帳號及組織同步放大敘事 |
| 橙 | 假命令、媒體協同與中央地方爭議同步 |
| 紅 | 假投降、通信異常與地方行政失序同時出現 |

## 十、兵推注入

1. 假總統宣布停火。  
2. 兩個地方政府收到不同中央命令。  
3. 社群平台暫停官方帳號。  
4. 反滲透措施被操作成族群獵巫。  
5. 政黨對威脅等級完全不同。  
6. 盟國撤僑被描述成放棄臺灣。  
7. 假傷亡名單引發抗議。  
8. 假配給名單造成地區衝突。  

## 十一、KPI

| 指標 | 建議衡量 |
|---|---|
| 高階命令驗證 | 分鐘級至小時級 |
| 假消息更正 | 首輪回應時間 |
| 中央地方一致性 | 相同事件編號與版本率 |
| 官方帳號韌性 | 多平台持續發布率 |
| 多語覆蓋 | 主要外語及弱勢族群覆蓋 |
| 社會信任 | 可辨識官方驗證方式比例 |

## 十二、結論

政治與認知戰最危險的成果不是讓所有人相信紅方，而是：

> 讓臺灣社會不再相信任何人，導致真實政府命令、預警與盟國支援都失去效果。

## 評估方法

| 等級 | 定義 | 使用原則 |
|---|---|---|
| A | 官方法律、制度、公開活動與確認案件 | 基準事實 |
| B | 官方威脅評估、可信研究與多來源判斷 | 主要結論 |
| C | 依公開能力與行為建立的條件式情境 | 明確標示推演 |
| D | 未交叉驗證傳聞或單一匿名指控 | 不納入核心結論 |

同時觀察意圖、能力、準備、跨領域同步、不可逆性及紅方失敗條件。
