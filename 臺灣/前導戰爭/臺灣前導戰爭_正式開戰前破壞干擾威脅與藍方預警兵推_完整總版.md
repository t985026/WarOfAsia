# 臺灣前導戰爭｜第一卷：概念、四階段與國家級威脅架構

## 一、前導戰爭定義

前導戰爭是正式武裝攻擊之前，透過政治、情報、網路、通信、金融、經濟、犯罪、軍事演習與外交分化，預先削弱臺灣國家功能與抵抗意志。

它不一定有正式宣戰、飛彈攻擊或單一公開指揮鏈，更可能偽裝成事故、商業決策、一般犯罪、網路事件、軍演、外交警告與市場反應。

## 二、戰略目的

1. 讓臺灣無法判斷戰爭是否已開始。  
2. 讓中央與地方收到互相矛盾命令。  
3. 使軍政人員不相信通信、憑證與情報。  
4. 以停電、斷網、缺貨、搶購與假消息製造恐慌。  
5. 使企業認為抵抗只會增加成本。  
6. 延遲盟國判斷與介入。  
7. 讓航運、航空、保險及外資自行撤離。  
8. 迫使國軍與政府提前消耗戰備、人力與政治信用。  

## 三、四個階段

### 第一階段：長期塑形

時間可能為開戰前數年至半年：

- 蒐集政府、軍隊、企業、通信、修復與社會資料。
- 培養政治、媒體、地方、企業與社團接觸面。
- 增加市場、軟體、雲端、VPN、eSIM與供應鏈依賴。
- 找出制度、修復能力與社會矛盾。
- 長期灌輸「抵抗無用、盟國不會來」。

### 第二階段：作戰準備

時間可能為開戰前六個月至一個月：

- 網路與情報活動增加。
- 供應商、遠端維護與高權限帳號異常。
- 海纜、物流、航運與金融壓力測試。
- 軍演、海警與準封鎖法律敘事。
- 外國企業及航運降低對臺服務。

### 第三階段：危機啟動

時間可能為開戰前30日至7日：

- 多起看似無關事故與異常同時發生。
- 臺灣難以判斷是否全面提高戒備。
- 政府提早消耗政治信用與戰備資源。
- 國內及盟國對事件性質分歧。

### 第四階段：最後塑形

時間可能為開戰前7日至數小時：

- 破壞命令可信度。
- 降低通信與金融服務。
- 阻礙動員與修復。
- 製造逃難、搶購及投降壓力。
- 把軍演轉為封鎖、有限打擊或全面戰爭。

## 四、十二個國家功能領域

| 領域 | 前導戰爭目標 |
|---|---|
| 政治 | 使國安決策被視為政黨操作 |
| 政府 | 破壞中央地方與命令可信度 |
| 情報 | 蒐集人員、流程、帳號與代理順位 |
| 供應鏈 | 控制資料、零件、遠端維護與替代能力 |
| 網路 | 長期設伏，危機時中斷或誤導 |
| 通信 | 降低海纜、電信、衛星與政府通信可靠性 |
| 能源水務 | 造成服務不穩、限電與民生恐慌 |
| 金融經濟 | 擠兌、資本外流、停產與企業反對 |
| 交通物流 | 使航運、航空、港口與配送萎縮 |
| 醫療社會 | 耗損醫療、製造物資恐慌與秩序問題 |
| 軍事灰區 | 消耗戒備、壓縮海空空間 |
| 外交盟國 | 延遲美日菲韓澳及歐洲共同判斷 |

## 五、三個關鍵係數

### 同步性

單一事件不足以證明前導戰爭；三個以上領域同步升高，風險顯著上升。

### 任務化

一般情報活動若開始關注危機期限、待命啟用、代理順位、修復人員、通信切換、物資與動員，代表已從蒐集轉為準備。

### 不可逆性

高風險徵候包括：

- 部隊演習後未返回。
- 民用運輸轉入特殊狀態。
- 醫療及後勤大量準備。
- 資本、出境、網路與外企管理同步收緊。
- 重要人員、設備與物資實際轉移。

## 六、紅方理想成果

- 政府存在，但命令不被相信。
- 基礎設施存在，但服務不穩。
- 國軍有戰力，但已提前消耗。
- 盟國支持臺灣，但尚未完成決策。
- 民眾未遭全面攻擊，卻已認為抵抗無意義。

## 七、藍方勝利條件

- 政府能正確判斷危機。
- 高階命令可驗證。
- 關鍵服務可降級不停擺。
- 地方能在中央失聯時接替。
- 社會不因假消息及搶購失控。
- 內應與供應鏈風險可依法隔離。
- 盟國取得可信、及時且一致的情勢資訊。

# 臺灣前導戰爭｜第二卷：政治、政府運作與認知戰干擾

## 一、文件目的

分析紅方如何降低政府命令可信度、放大政黨極化、破壞中央地方協調，並讓社會對國安措施失去信任。

## 二、政黨與社會極化

### 戰略目的

- 使國安政策被視為政黨鬥爭。
- 讓政府無法取得提高戒備的政治支持。
- 把外部威脅轉化為內部互相指控。
- 污名化反滲透、民防、軍購及盟國合作。

### 可觀察徵候

- 多個媒體、帳號、社團與政治人物突然使用相似敘事。
- 假民調、假文件、深偽與剪輯影片同時出現。
- 境外資金或廣告來源不透明。
- 國安議題被包裝成單一政黨陰謀。

### 藍方防禦

- 跨黨派最低國安共識。
- 公開證據級別與不確定性。
- 區分政治意見與秘密委託。
- 重大措施附法律、期限與監督。

## 三、中央與地方分化

可能目標：

- 讓地方不相信中央命令。
- 製造地方自行談判或拒絕動員的印象。
- 中央失聯時造成行政停擺。

高風險情境：

- 假中央公文。
- 假地方首長聲明。
- 假停班、撤離、配給與封路命令。
- 同一事件出現不同編號與版本。

防禦：

- 中央地方共同事件編號。
- 高階命令數位簽章。
- 第二通信管道人工覆核。
- 地方72小時最低行政預授權。

## 四、假投降、撤離與停戰命令

可能形式：

- 假總統或行政院影片。
- 假國防部停火公告。
- 假盟國撤離及放棄臺灣聲明。
- 假地方政府與中國簽署協議。

防禦原則：

- 投降、停火、撤離與重大動員命令需多重驗證。
- 建立全國通用驗證格式。
- 電視、廣播、簡訊、官方網站、衛星與地方系統同步。
- 事前教育民眾哪些命令必須二次驗證。

## 五、假政府失能敘事

常見內容：

- 中央政府已失聯。
- 總統或行政團隊已撤離。
- 國軍不再接受中央指揮。
- 地方政府各自處理。
- 盟國只協助撤僑，不會支援臺灣。

藍方需固定發布、公布最低政府功能、承認已知與未知，避免過度樂觀破壞信任。

## 六、媒體與平台干擾

風險：

- 股權及廣告資金不透明。
- 內容農場、協同帳號及演算法放大。
- 假直播、假記者與假專家。
- 大量檢舉使官方帳號停權。
- 假查核機構與假官方更正。

防禦：

- 最終受益人及政治廣告透明。
- 平台保留危機時政府驗證機制。
- 民間媒體與查核組織交叉確認。
- 不把所有異議內容視為敵對資訊。

## 七、社會信任攻擊

紅方可利用政黨、世代、地區、族群與職業矛盾，以及軍民資源、避難、配給、傷亡與外國居民議題。

藍方需：

- 公平、可解釋的配給規則。
- 多語資訊。
- 申訴與更正機制。
- 不以族群或國籍集體懷疑。

## 八、行政塞車

可能形式：

- 大量假檢舉、申訴與陳情。
- 假冒機關間公文。
- 不實資料要求。
- 假災情與假失蹤人口。
- 自動化電話及電子郵件壅塞。

藍方需事件分級、緊急與行政訊息分流、關鍵機關離線作業。

## 九、風險分級

| 等級 | 狀態 |
|---|---|
| 綠 | 一般政治競爭與境外宣傳 |
| 黃 | 多帳號及組織同步放大敘事 |
| 橙 | 假命令、媒體協同與中央地方爭議同步 |
| 紅 | 假投降、通信異常與地方行政失序同時出現 |

## 十、兵推注入

1. 假總統宣布停火。  
2. 兩個地方政府收到不同中央命令。  
3. 社群平台暫停官方帳號。  
4. 反滲透措施被操作成族群獵巫。  
5. 政黨對威脅等級完全不同。  
6. 盟國撤僑被描述成放棄臺灣。  
7. 假傷亡名單引發抗議。  
8. 假配給名單造成地區衝突。  

## 十一、KPI

| 指標 | 建議衡量 |
|---|---|
| 高階命令驗證 | 分鐘級至小時級 |
| 假消息更正 | 首輪回應時間 |
| 中央地方一致性 | 相同事件編號與版本率 |
| 官方帳號韌性 | 多平台持續發布率 |
| 多語覆蓋 | 主要外語及弱勢族群覆蓋 |
| 社會信任 | 可辨識官方驗證方式比例 |

## 十二、結論

政治與認知戰最危險的成果不是讓所有人相信紅方，而是：

> 讓臺灣社會不再相信任何人，導致真實政府命令、預警與盟國支援都失去效果。

# 臺灣前導戰爭｜第三卷：情報、內應、人員與供應鏈干擾

## 一、文件目的

處理軍政人員、承包商、供應商、軟體、雲端與遠端維護如何成為前導戰爭風險面，並建立不獵巫、可驗證、可依法處理的防禦架構。

## 二、人員吸收與秘密委託

可能目標：

- 取得人員、流程、帳號、代理順位與修復能力資訊。
- 危機時延遲通報、誤導或阻礙協調。
- 找出債務、家庭、利益及脅迫弱點。
- 建立危機期間待命任務。

高風險徵候：

- 不符合職務需要的大量下載。
- 對代理順位、備援通信、修復隊及動員流程異常關注。
- 異常金流、接觸及海外行程。
- 危機前突然請假、失聯、離職或要求調動。
- 接受未揭露的外國政府、政黨或國企任務。

## 三、人員生命週期管理

- 任用前查核。
- 高權限持續查核。
- 最小權限。
- 職務分離與輪調。
- 異常下載及登入監控。
- 離職即時撤權。
- 退休後敏感接觸通報。
- 債務、脅迫及家屬支援。
- 主動通報減責與保護。

## 四、供應商與承包商

風險：

- 合法維護權限被濫用。
- 多層轉包掩蓋控制人。
- 危機時停止服務、延遲零件或拒絕支援。
- 遠端管理平台成為共同失敗點。
- 同一供應商跨政府、金融、電信、能源及醫療。

預警：

- 控制權突然變更。
- 維護帳號權限提高。
- 海外遠端連線增加。
- 關鍵零件及更新同步延遲。
- 最終受益人及資料流不透明。

防禦：

- 供應商分級。
- 控制權變更通報。
- 高風險遠端維護雙人審批。
- 重要系統具人工及替代供應商模式。
- 關鍵備件不得集中單一來源。

## 五、政府與軍政個資外洩

可能用途：

- 精準詐騙與假冒。
- 人際關係圖。
- 家庭、財務與職務脅迫。
- 假公文、假帳號及深偽。
- 找出代理人、修復人員及核心決策者。

藍方需敏感個資去集中化、硬體金鑰或通行金鑰、外洩後重發憑證，並保護受影響家庭。

## 六、任務化轉換

風險最高的不是資料被看過，而是情報任務開始關注：

- 何時切換備援。
- 誰能代理首長。
- 誰可以恢復系統。
- 哪些供應商有遠端權限。
- 哪些人員會在危機時到場。
- 哪些物資、車輛及設備可調度。

## 七、犯罪與地下金融代理

可能領域：

- 詐騙。
- 地下匯兌。
- 黑市與假物資。
- 幫派、暴力及恐嚇。
- 偽造文件及帳號。
- 洗錢與第三方支付。

不能因犯罪事件發生就自動歸責國家，應觀察金流、指揮、期限、目標及與軍演、網攻、外交壓力的同步。

## 八、法律與權利護欄

- 秘密委託需具體定義。
- 依法調查與司法審查。
- 保護證人及通報者。
- 犯罪所得依法沒收。
- 不以政治立場、國籍或族裔推定犯罪。
- 避免重要案件遭資訊洩漏及政治操作。

## 九、供應鏈風險矩陣

| 類別 | 主要風險 | 替代要求 |
|---|---|---|
| 雲端 | 帳號、資料、備份集中 | 跨雲與離線 |
| 電信 | 單一業者與遠端管理 | 跨網漫遊與多供應商 |
| 軟體 | 更新及簽章失效 | 白名單與離線版本 |
| 維修 | 人員與零件不到場 | 跨區與本地備件 |
| 金融科技 | 支付及身分集中 | 低頻寬與人工模式 |
| 醫療 | 病歷及設備遠端依賴 | 離線病歷與現地操作 |

## 十、兵推注入

1. 高權限承包商帳號異常登入。  
2. 重要供應商控制權突然變更。  
3. 修復人員遭恐嚇或大量失聯。  
4. 備份管理帳號與生產系統同時停用。  
5. 外洩資料真假混雜。  
6. 承包商拒絕危機支援。  
7. 重要零件因海外行政措施延遲。  
8. 反間諜案件引發政治與族群爭議。  

## 十一、KPI

| 指標 | 建議衡量 |
|---|---|
| 高權限異常偵測 | 分鐘至小時 |
| 離職撤權 | 即時完成率 |
| 控制權透明 | 揭露率 |
| 替代供應商 | 關鍵功能覆蓋率 |
| 主動通報 | 保護與處理時間 |
| 修復人力 | 替補到場時間 |
| 備件 | 最低可持續天數 |

## 十二、結論

真正危險的內應不是單一「間諜身分」，而是：

> 在危機時握有合法權限、知道制度依賴、能延遲修復，又不易被立即歸責的人員與供應鏈節點。

同時觀察意圖、能力、準備、跨領域同步、不可逆性及紅方失敗條件。

# 臺灣前導戰爭｜第四卷：網路、通信、VPN、eSIM、海纜、衛星與電磁干擾

## 一、文件目的

建立面對長期網路設伏、通信供應鏈風險、多點海纜異常、衛星及定位干擾、VPN與eSIM資料集中時的預警與防禦架構。

## 二、長期網路設伏

戰略目的：

- 平時蒐集資料與帳號。
- 危機時中斷、刪除、加密或誤導。
- 使政府無法分辨哪些系統可信。
- 延長復原時間。

徵候：

- 長期低流量異常連線。
- 不明高權限帳號。
- 備份、管理及更新系統異常存取。
- 同一工具跨政府、金融、電信及能源出現。
- 平時次要系統在危機前被大量掃描。

## 三、一般網路犯罪掩護

國家行動可能被包裝成勒索軟體、詐騙、駭客炫技、商業糾紛或供應鏈事故。藍方需比較時間、目標組合、工具重複性及與軍演、外交、金融、海纜事件的同步。

## 四、軟體更新與憑證信任

風險：

- 更新供應鏈遭污染。
- 憑證被冒用或撤銷失敗。
- 政府網站及文件遭偽造。
- 真實命令也被懷疑。

防禦：

- 更新簽章驗證。
- 軟體白名單。
- 離線版本。
- 備份與生產環境分離。
- 緊急憑證撤銷與重發演練。
- 乾淨管理環境。

## 五、VPN與eSIM資料集中

VPN可能掌握來源IP、連線時間、流量大小、DNS、目的服務、帳號、付款及裝置資料。

eSIM及電信可能掌握訂閱識別、基地台與大致位置、漫遊、上游電信商、啟用、付款及裝置識別。

高風險組合：

```text
真實身分與付款
＋
SIM／eSIM識別
＋
基地台與移動
＋
VPN來源與出口
＋
DNS與服務連線
＋
裝置及廣告識別
```

單純低價或中國資本背景不能直接證明情報活動；需依控制權、資料流、法域、權限及協同行為判斷。

## 六、危機時通信停用

可能效果：

- 特定人員或企業失聯。
- 使用者被迫改用不可信平台。
- 政府、企業與海外聯絡中斷。
- 大量設定檔同時失效。

防禦：

- 公務白名單。
- 多家電信及跨網漫遊。
- 實體SIM、eSIM與衛星備援。
- 快速撤銷高風險設定檔。
- 關鍵通信不依賴單一App。

## 七、行動與網路壅塞

紅方不一定要完全中斷，只要利用大量流量、假警報與影片、集中查詢、更新與雲端同步、反覆斷線重連，就可壓縮關鍵頻寬。

優先順序：

1. 國家指揮。  
2. 國防、警消、海巡。  
3. 電力、水務與電信。  
4. 醫療。  
5. 外交與盟國。  
6. 金融清算。  
7. 港口物流。  
8. 公共資訊。  

## 八、多點海纜異常

風險上修：

- 多條路徑短期連續異常。
- 異常船舶與軍演同步。
- 修復船受到阻礙。
- 海纜事件伴隨網攻、金融與假消息。
- 剩餘路由也出現壅塞或設定問題。

防禦：

- 路徑及登陸區分散。
- 跨業者容量調度。
- 衛星、微波與無線電。
- 關鍵頻寬優先。
- 修復外交與保險機制。
- 不把衛星視為全民海纜容量的完全替代。

## 九、衛星、定位與時間同步

可能效果：

- 航運、航空與物流可靠性下降。
- 緊急通信品質不穩。
- 金融與電力時間同步異常。
- 民間事故及軍事誤判增加。

防禦：

- 多重定位與時間來源。
- 地面、無線電與離線替代。
- 重要系統監測時間漂移。
- 導航異常與設備故障分開判斷。

## 十、公共警報與無線電

可能出現假空襲、假撤離、假災難或真實警報受干擾。藍方需統一警報格式、多平台交叉驗證、民眾教育及保留傳統廣播。

## 十一、可信復原

1. 隔離受影響系統。  
2. 建立乾淨管理環境。  
3. 重發密鑰、帳號與憑證。  
4. 驗證軟體映像及備份。  
5. 分階段恢復。  
6. 比對資料完整性。  
7. 長期監控。  
8. 第三方覆核。  

## 十二、兵推注入

1. 三分之二海纜路徑失效。  
2. 大型eSIM供應商停止服務。  
3. VPN出口轉往高風險法域。  
4. 政府憑證信任出現爭議。  
5. 衛星容量不足以支援所有機關。  
6. 行動網路只剩30%服務能力。  
7. 海纜修復船無法立即進入。  
8. DNS、時間同步及金融系統同時異常。  

## 十三、KPI

| 指標 | 建議衡量 |
|---|---|
| 海纜失效後關鍵服務 | 維持率 |
| 衛星及微波切換 | 啟動時間 |
| 關鍵頻寬分級 | 完成時間 |
| 憑證撤銷與重發 | 恢復時間 |
| 跨網漫遊 | 覆蓋率 |
| 低頻寬政府服務 | 可用率 |
| 可信復原 | 通過驗證時間 |

## 十四、結論

通信前導戰爭不一定讓臺灣完全斷網，而是：

> 讓政府、軍隊、金融、企業與民眾無法確定目前使用的網路、身分、時間、位置與命令是否可信。

|---|---|---|
| A | 官方法律、制度、公開活動與確認案件 | 基準事實 |
| B | 官方威脅評估、可信研究與多來源判斷 | 主要結論 |
| C | 依公開能力與行為建立的條件式情境 | 明確標示推演 |
| D | 未交叉驗證傳聞或單一匿名指控 | 不納入核心結論 |

同時觀察意圖、能力、準備、跨領域同步、不可逆性及紅方失敗條件。

# 臺灣前導戰爭｜第五卷：能源、金融、交通、醫療、物流與社會秩序干擾

## 一、文件目的

分析紅方如何在正式開戰前，透過服務不穩、假消息、供應鏈中斷、商業退出與犯罪代理，讓臺灣民生與經濟先進入戰時狀態。

## 二、電力系統不穩

可能目的：

- 迫使分區限電。
- 影響通信、水務、醫療與金融。
- 製造全臺即將停電的恐慌。
- 讓企業停產並要求政府降級。

藍方防禦：

- 電網區域化與降級運作。
- 醫療、通信、水務與國家指揮優先。
- 工控與遠端維護隔離。
- 修復人員與備件保護。
- 公開服務及修復進度。

## 三、燃料與能源配送

紅方不必破壞大型設施，也可透過假缺油、物流資訊異常、交通壅塞、商業配送中止及供應商拒絕服務，造成加油站排隊與軍民資源競爭。

藍方需：

- 軍民能源分級。
- 跨區調度。
- 紙本與離線配送。
- 重要車隊及醫療優先。
- 假缺油訊息快速澄清。

## 四、水務與公共衛生

可能干擾：

- 水質污染謠言。
- 假停水通知。
- 供水與污水控制異常。
- 大量搶水。
- 水務修復人員受阻。

防禦：

- 水質資訊透明。
- 區域與移動供水。
- 醫療、消防及弱勢優先。
- 不公開敏感設施弱點。

## 五、銀行擠兌與支付恐慌

常見敘事：

- 銀行即將停業。
- 政府將凍結存款。
- 新臺幣無法兌換。
- ATM現金不足。
- 外資已全面撤離。

藍方需：

- 維持核心清算。
- 合理提款及轉帳管理。
- 低頻寬支付。
- 現金與ATM調度。
- 中央銀行、金管機關及主要銀行共同發布。

## 六、股匯市與企業信心

可能目的：

- 讓市場先於戰爭崩潰。
- 迫使企業撤人、撤資與停產。
- 讓企業公開反對提高戒備。
- 製造失業與產業外移恐慌。

防禦：

- 市場穩定與流動性機制。
- 企業緊急融資。
- 替代市場及盟國支援。
- 交易與資本措施設定期限及監督。

## 七、關鍵物資與原料

可能受影響：

- 能源與工業原料。
- 醫療用品。
- 通信與電力零件。
- 交通維修件。
- 食品與飼料。

藍方不能只計算庫存，還要計算配送、修復人力、替代來源、港口保險、支付及通關。

## 八、航運與保險自行退出

紅方不一定宣布封鎖，只要有大型軍演、禁限航區、船舶安全疑慮、港口排程不可信及保險費率上升，就可能形成實質物流下降。

藍方需：

- 與盟國建立航運及保險支援。
- 公開商港服務狀態。
- 區分撤僑、商業退出與政治放棄。

## 九、航空與撤離

風險：

- 大量離境需求。
- 外國撤僑被解讀為放棄臺灣。
- 航空公司自行停飛。
- 機場、票務與交通資訊不可信。

防禦：

- 外國居民及使館固定聯絡。
- 撤離與戰略支持分開說明。
- 保留人道與外交交通能力。

## 十、交通與物流資訊

可能干擾：

- 號誌、票務及導航異常。
- 假封路與假交通管制。
- 錯誤配送及倉儲資訊。
- 阻礙搶修、醫療與物資運輸。

藍方需人工與紙本模式、重要路線優先、跨縣市物流協同與多來源驗證。

## 十一、醫療耗損

可能形式：

- 假大量傷患。
- 假疫情或污染。
- 假醫院關閉。
- 電話、預約與查詢壅塞。
- 藥品與設備供應延遲。

優先功能：

- 急重症。
- 透析。
- 血液。
- 氧氣。
- 關鍵藥品。
- 離線病歷。
- 跨區醫療。

## 十二、犯罪、地下金融與黑市

可能涉及：

- 詐騙。
- 地下匯兌。
- 假物資交易。
- 黑市炒作。
- 幫派與恐嚇。
- 洗錢及第三方支付。

需依金流、指揮、任務期限與同步性判斷，不能將所有犯罪直接視為國家行動。

## 十三、搶購與物資恐慌

常見敘事：

- 糧食只剩數日。

- 政府物資被軍方徵用。
- 特定地區將被放棄。

藍方需公開配送計畫、不公開敏感庫存位置，並透過超商、郵政、物流與地方共同配售。

## 十四、兵推注入

1. 兩家主要銀行遭假倒閉消息。  
2. 重要港口服務降至40%。  
3. 航運保險停止承保。  
4. 某區域長時間限電。  
5. 假水質污染造成搶水。  
6. 大型醫院電話及網路壅塞。  
7. 油料配送資訊遭偽造。  
8. 黑市物資及地下匯兌升高。  

## 十五、KPI

| 指標 | 建議衡量 |
|---|---|
| 電力最低服務 | 關鍵設施供電率 |
| 金融清算 | 可用率 |

| 物流 | 重要物資配送完成率 |
| 航運 | 最低商業連結 |
| 社會 | 搶購與假消息降溫時間 |

## 十六、結論

民生前導戰爭最危險的不是某一設施被摧毀，而是：

> 電力、金融、交通、醫療與物流各自只下降一部分，卻因資訊不可信與搶購形成跨領域連鎖失能。

# 臺灣前導戰爭｜第六卷：軍事灰色地帶、海警準封鎖與盟國分化

## 一、文件目的

分析紅方如何利用軍演、海警、海空壓力、假停火、法律敘事及對盟國的政治經濟脅迫，在未全面開戰前壓縮臺灣行動空間。

## 二、軍演消耗戰

可能目的：

- 迫使國軍反覆提高戒備。
- 消耗飛行、航行、維修與人力。
- 讓民眾對警報疲乏。
- 隱藏真正攻擊前的異常。
- 測試臺灣及盟國反應時間。

藍方需分級反應、保存重要戰力，避免每次演習都用最高成本反應，並建立由演訓轉為戰爭準備的判斷標準。

## 三、海警與準封鎖

可能目的：

- 建立中國單方面執法常態。
- 測試商船、海巡、海軍及盟國反應。
- 不宣戰即壓縮臺灣海空空間。
- 使保險與航運自行撤離。

藍方需：

- 區分執法、灰區、準封鎖及正式軍事攻擊。
- 海巡、海軍、外交及司法共同記錄。
- 與商業航運及盟國建立一致說法。
- 避免被迫接受中國法律框架。

## 四、軍事欺騙與錯誤方向

可能目的：

- 讓臺灣只注意軍事方向。
- 忽略網路、金融、海纜、內應與修復。
- 讓盟國對真正意圖產生不同判斷。
- 製造錯誤動員與資源配置。

藍方需軍事、民生、網路與外交共同情勢圖，設置紅隊與反證程序。

## 五、假停火與假談判

可能目的：

- 延遲臺灣動員。
- 分化盟國。
- 讓企業及航運等待結果。
- 在談判期間繼續準備。
- 迫使臺灣接受單方面海空管制。

藍方需：

- 停火必須有可驗證行動。
- 談判與戰備不可互相取代。
- 航運、海纜修復與人道通道需具體條件。
- 防止暫時安排永久化。

## 六、對美國的分化

敘事：

- 中國行動只是內政或有限執法。
- 臺灣先挑釁。
- 中國不會攻擊第三國。
- 美國介入將造成核戰與全球經濟崩潰。

藍方需提供中國首先使用武力的時間線、民用設施及商業交通受影響證據，並分級提出支援需求。

## 七、對日本的分化

可能工具：

- 沖繩及基地爭議。
- 日本企業與能源航線威脅。
- 撤離及核戰恐懼。
- 歷史與國內政治。

藍方需強調日本本土、海纜、航運與居民安全，並建立非軍事及防禦型支援清單。

## 八、對菲律賓的分化

可能工具：

- 經濟、觀光與南海壓力。
- 將基地使用描述為犧牲菲律賓。
- 放大中央與地方差異。
- 威脅撤僑及商業交通。

藍方需聚焦巴士海峽監視、撤僑、人道及航運合作，尊重其法律與政治程序。

## 九、對韓國的牽制

可能工具：

- 北韓核飛彈與邊境壓力。
- 宣稱駐韓美軍支援臺海會削弱半島防衛。
- 對韓企業、半導體與供應鏈施壓。
- 放大日韓歷史矛盾。

藍方應將韓國角色定位為半島穩定、後方、資安、醫療與供應鏈支援，不預設直接派兵。

## 十、俄羅斯與北韓分散資源

可能目的：

- 在其他戰區增加壓力。
- 使美國、日本、韓國及歐洲分散資源。
- 在聯合國阻止實質決議。
- 支持反制裁與反干涉敘事。

## 十一、東協與全球南方

紅方敘事：

- 臺海是中國內政。
- 制裁傷害全球經濟。
- 西方利用亞洲對抗中國。
- 應優先停火，不應支援臺灣。

藍方需強調國際航行、海纜、民用設施、經濟及人道外溢。

2. 日本因基地爭議延遲決策。  
3. 菲律賓只同意撤僑與人道。  
4. 韓國因北韓試射限制支援。

灰色地帶與盟國分化的目的不是讓所有國家支持中國，而是：

# 臺灣前導戰爭｜第七卷：戰前最後72小時複合預警與危機儀表板

## 一、目的

建立最後72小時國家級預警框架，避免因單一事件誤判，也避免多領域同步升高時仍以一般事故處理。

## 二、十二項高危險組合

1. 大型軍演部隊演習後未明顯返回。  
2. 民用運輸、物流、醫療及通信轉為特殊狀態。  
3. 中國同步收緊出境、資本、網路及外企管理。  
4. 宣傳由和平統一轉向犧牲、長期鬥爭及戰爭不可避免。  
5. 臺灣多條海纜、網路、金融及政府系統同時異常。  
6. 假投降、假撤離及假金融崩潰訊息集中出現。  
7. 軍政、電信、能源、醫療及修復人員遭異常接觸或脅迫。  
8. 北韓同步提高飛彈、網路及軍事活動。  
9. 俄羅斯在其他地區增加壓力。  
10. 中國完成「臺灣先挑釁」國際敘事。  
11. 外國航空、航運、保險與企業同步降低對臺服務。  
12. 美國、日本、韓國及菲律賓對事件性質明顯分歧。  

## 三、五種跨領域組合

### 命令可信度破壞

```text
政府個資外洩
＋高階帳號遭冒用
＋深偽影片
＋中央地方通信異常
＋假投降或撤離命令
```

### 通信孤立

```text
多條海纜異常
＋電信壅塞
＋VPN／eSIM停用
＋衛星與定位干擾
＋DNS或政府憑證問題
```

### 金融與物資恐慌

```text
假銀行倒閉
＋ATM排隊
＋能源與糧食謠言
＋物流資訊異常
＋航運保險撤出
```

### 內應與修復破壞

```text
高權限帳號異常
＋承包商停止服務
＋修復人員遭恐嚇或失聯
＋備件延遲
＋假維修命令
```

### 盟國決策分化

```text
中國有限行動敘事
＋北韓第二戰場
＋日本基地爭議
＋菲律賓政治分歧
＋歐洲經濟顧慮
```

## 四、危機分級

### 綠色

一般灰色地帶、宣傳與網路活動，沒有跨領域同步。

### 黃色

兩個以上領域升高，仍可由常態機制處理。

### 橙色

政治、軍事、通信、金融或民生至少三領域同步，部分服務轉入降級。

### 紅色

部隊、民用運輸、醫療、資本與通信出現不可逆準備，臺灣命令、金融、通信及海纜同時受影響。

## 五、指標評分

| 分數 | 意義 |
|---:|---|
| 0 | 未出現 |
| 1 | 單一弱訊號 |
| 2 | 多來源支持但規模有限 |
| 3 | 官方或高可信證據，影響顯著 |
| 4 | 與其他領域同步且具有危機啟用特徵 |

不得只看總分。三個以上領域同時達3分，應視為高度危險。

## 六、最後72小時時間表

### T-72至T-48

- 確認軍演是否超出演訓。
- 驗證高階命令、代理順位與盟國聯絡。
- 檢查海纜、衛星、金融、能源及醫療備援。
- 暫停非必要高風險遠端維護。

### T-48至T-24

- 啟動跨部會共同情勢圖。
- 地方政府進入最低持續準備。
- 對高風險供應商及帳號採限制。
- 與盟國確認第一順位通信及情報支援。
- 準備公共資訊及反假命令說明。

### T-24至T-6

- 實施頻寬、能源與金融優先排序。
- 啟動重要人員替補與異地辦公。
- 提高醫療、救援及物資配送準備。
- 公布官方命令驗證方式。
- 確保盟國可辨識合法政府。

### T-6至T0

- 凍結非必要高權限帳號。
- 切換部分關鍵通信與備援。
- 保存戰力並避免不必要消耗。
- 發布簡短、一致、可驗證資訊。
- 停火、投降與撤離命令必須多重確認。

## 七、決策門檻

### 國家級應變

- 三個以上領域達3分。
- 或任一不可逆軍事／民用動員指標達4分。

### 地方預授權

- 中央通信可靠度顯著下降。
- 或假命令與地方行政異常同步。

### 頻寬及能源分級

- 海纜或電信服務降至平時60%以下。
- 或國家指揮、金融及醫療開始競爭容量。

### 盟國緊急支援

- 中國軍事、通信及經濟壓力同步。
- 或商業航運、保險及外國企業開始撤離。

## 八、誤判護欄

- 單一海纜事故不自動歸責。

- 政治意見不等於秘密代理。
- 市場下跌不等於敵對攻擊。
- 軍演與戰爭需觀察不可逆準備。
- 歸責需技術、情報、法律及外交交叉確認。

# 臺灣前導戰爭｜第八卷：兵推注入事件、裁決規則與演練手冊

## 一、兵推目的

將前七卷轉化為可執行的桌上推演、跨部會演練與全社會韌性測試。

## 二、參演角色

- 國家安全及行政決策層。
- 國防、海巡、警政與調查機關。
- 數位、電信與關鍵基礎設施機關。
- 金融、能源、交通、衛生及地方政府。
- 電信、雲端、金融、物流、醫療及零售企業。
- 媒體、查核、民防與社會組織。
- 美國、日本、菲律賓、韓國、澳洲及歐洲聯絡組。

## 三、基本規則

1. 紅方資訊不完整且可能矛盾。  
2. 藍方不能假設所有事件由同一方造成。  
3. 每項決策記錄法律依據、證據級別及副作用。  
4. 不公開真實設施弱點、座標、帳號及容量。  
5. 每輪評估社會信任與盟國反應。  
6. 以國家功能持續為主，不以所有服務正常為勝利。

## 六、演練階段

### 第一輪：長期塑形

測試供應鏈、政治資金、替代通信及人員。

### 第二輪：危機前30日

測試風險是否任務化、戒備與市場溝通、盟國共同情勢。

### 第三輪：最後72小時

測試命令、中央地方、海纜、通信、金融、能源、外交及公共資訊。

### 第四輪：開戰後72小時

測試政府持續、地方預授權、醫療物資、盟國支援、假投降與內應隔離。

## 七、裁決面向

每輪以0至100評分：

| 面向 | 判斷 |
|---|---|
| 政府指揮 | 是否持續且命令可信 |
| 國防安全 | 是否保存戰力與共同情勢 |
| 通信 | 是否維持關鍵頻寬 |
| 金融 | 是否維持清算及必要支付 |
| 能源水務 | 是否維持最低服務 |
| 醫療 | 是否維持急重症與大量傷患 |
| 物流物資 | 是否避免失序與搶購 |
| 社會信任 | 是否能辨識官方資訊 |
| 反情報 | 是否精準隔離而不獵巫 |
| 盟國合作 | 是否取得及有效使用支援 |

## 八、裁決規則

### 戰略拒止成功

- 政府指揮≥70。
- 國防安全≥65。
- 通信、金融、能源及醫療平均≥55。
- 社會信任≥50。
- 盟國合作≥60。
- 未接受被迫投降或不可逆政治條件。

### 嚴重危機但仍存續

- 政府指揮50–69。
- 關鍵服務平均40–54。
- 地方仍能運作。
- 盟國可辨識合法政府。

### 戰略失敗

- 高階命令無法驗證。
- 中央地方長時間失去共同情勢。
- 關鍵服務平均低於40。
- 大規模政治投降或行政分裂。
- 盟國無法確認合法政府及需求。

## 九、決策紀錄

每項決策記錄：

1. 已知事實。  
2. 未確認事項。  
3. 證據級別。  
4. 法律與權責。  
5. 選擇方案。  
6. 預期副作用。  
7. 盟國及民眾反應。  
8. 重新評估時間。  

## 十、演練KPI

| KPI | 建議目標 |
|---|---|
| 高階命令驗證 | 15分鐘內首輪確認 |
| 跨部會共同情勢 | 60分鐘內建立 |
| 地方預授權 | 中央失聯後立即啟動 |
| 頻寬與能源分級 | 2小時內 |
| 金融最低服務 | 持續可用 |
| 假消息首輪回應 | 30分鐘至1小時 |
| 盟國支援需求 | 6小時內排序 |
| 修復人員替補 | 依功能設定小時級目標 |

## 十一、演練後檢討

必須回答：

- 哪些決策依賴單一人員或系統。
- 哪些備援只存在文件上。
- 哪些地方沒有接替能力。
- 哪些供應商無替代。
- 哪些公共資訊容易被誤解。
- 哪些盟國支援沒有請求格式。
- 哪些措施可能侵犯權利或造成獵巫。
- 哪些功能需要下一輪真實切換。

## 十二、結論

有效兵推不是問能否阻止所有攻擊，而是：

> 當政治、通信、金融、民生、軍事與國際事件同時失去可信度時，臺灣是否仍能正確判斷、合法命令、持續服務、保護社會並取得盟國支援。

## 評估方法

| 等級 | 定義 | 使用原則 |
|---|---|---|
| A | 官方法律、制度、公開活動與確認案件 | 基準事實 |
| B | 官方威脅評估、可信研究與多來源判斷 | 主要結論 |
| C | 依公開能力與行為建立的條件式情境 | 明確標示推演 |
| D | 未交叉驗證傳聞或單一匿名指控 | 不納入核心結論 |

同時觀察意圖、能力、準備、跨領域同步、不可逆性及紅方失敗條件。
