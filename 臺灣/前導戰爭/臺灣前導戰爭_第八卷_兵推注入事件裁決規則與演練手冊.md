# 臺灣前導戰爭｜第八卷：兵推注入事件、裁決規則與演練手冊

## 一、兵推目的

將前七卷轉化為可執行的桌上推演、跨部會演練與全社會韌性測試。

## 二、參演角色

- 國家安全及行政決策層。
- 國防、海巡、警政與調查機關。
- 數位、電信與關鍵基礎設施機關。
- 金融、能源、交通、衛生及地方政府。
- 電信、雲端、金融、物流、醫療及零售企業。
- 媒體、查核、民防與社會組織。
- 美國、日本、菲律賓、韓國、澳洲及歐洲聯絡組。

## 三、基本規則

1. 紅方資訊不完整且可能矛盾。  
2. 藍方不能假設所有事件由同一方造成。  
3. 每項決策記錄法律依據、證據級別及副作用。  
4. 不公開真實設施弱點、座標、帳號及容量。  
5. 每輪評估社會信任與盟國反應。  
6. 以國家功能持續為主，不以所有服務正常為勝利。

## 六、演練階段

### 第一輪：長期塑形

測試供應鏈、政治資金、替代通信及人員。

### 第二輪：危機前30日

測試風險是否任務化、戒備與市場溝通、盟國共同情勢。

### 第三輪：最後72小時

測試命令、中央地方、海纜、通信、金融、能源、外交及公共資訊。

### 第四輪：開戰後72小時

測試政府持續、地方預授權、醫療物資、盟國支援、假投降與內應隔離。

## 七、裁決面向

每輪以0至100評分：

| 面向 | 判斷 |
|---|---|
| 政府指揮 | 是否持續且命令可信 |
| 國防安全 | 是否保存戰力與共同情勢 |
| 通信 | 是否維持關鍵頻寬 |
| 金融 | 是否維持清算及必要支付 |
| 能源水務 | 是否維持最低服務 |
| 醫療 | 是否維持急重症與大量傷患 |
| 物流物資 | 是否避免失序與搶購 |
| 社會信任 | 是否能辨識官方資訊 |
| 反情報 | 是否精準隔離而不獵巫 |
| 盟國合作 | 是否取得及有效使用支援 |

## 八、裁決規則

### 戰略拒止成功

- 政府指揮≥70。
- 國防安全≥65。
- 通信、金融、能源及醫療平均≥55。
- 社會信任≥50。
- 盟國合作≥60。
- 未接受被迫投降或不可逆政治條件。

### 嚴重危機但仍存續

- 政府指揮50–69。
- 關鍵服務平均40–54。
- 地方仍能運作。
- 盟國可辨識合法政府。

### 戰略失敗

- 高階命令無法驗證。
- 中央地方長時間失去共同情勢。
- 關鍵服務平均低於40。
- 大規模政治投降或行政分裂。
- 盟國無法確認合法政府及需求。

## 九、決策紀錄

每項決策記錄：

1. 已知事實。  
2. 未確認事項。  
3. 證據級別。  
4. 法律與權責。  
5. 選擇方案。  
6. 預期副作用。  
7. 盟國及民眾反應。  
8. 重新評估時間。  

## 十、演練KPI

| KPI | 建議目標 |
|---|---|
| 高階命令驗證 | 15分鐘內首輪確認 |
| 跨部會共同情勢 | 60分鐘內建立 |
| 地方預授權 | 中央失聯後立即啟動 |
| 頻寬與能源分級 | 2小時內 |
| 金融最低服務 | 持續可用 |
| 假消息首輪回應 | 30分鐘至1小時 |
| 盟國支援需求 | 6小時內排序 |
| 修復人員替補 | 依功能設定小時級目標 |

## 十一、演練後檢討

必須回答：

- 哪些決策依賴單一人員或系統。
- 哪些備援只存在文件上。
- 哪些地方沒有接替能力。
- 哪些供應商無替代。
- 哪些公共資訊容易被誤解。
- 哪些盟國支援沒有請求格式。
- 哪些措施可能侵犯權利或造成獵巫。
- 哪些功能需要下一輪真實切換。

## 十二、結論

有效兵推不是問能否阻止所有攻擊，而是：

> 當政治、通信、金融、民生、軍事與國際事件同時失去可信度時，臺灣是否仍能正確判斷、合法命令、持續服務、保護社會並取得盟國支援。

## 評估方法

| 等級 | 定義 | 使用原則 |
|---|---|---|
| A | 官方法律、制度、公開活動與確認案件 | 基準事實 |
| B | 官方威脅評估、可信研究與多來源判斷 | 主要結論 |
| C | 依公開能力與行為建立的條件式情境 | 明確標示推演 |
| D | 未交叉驗證傳聞或單一匿名指控 | 不納入核心結論 |

同時觀察意圖、能力、準備、跨領域同步、不可逆性及紅方失敗條件。
