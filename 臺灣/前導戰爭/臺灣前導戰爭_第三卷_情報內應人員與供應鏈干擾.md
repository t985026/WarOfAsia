# 臺灣前導戰爭｜第三卷：情報、內應、人員與供應鏈干擾

## 一、文件目的

處理軍政人員、承包商、供應商、軟體、雲端與遠端維護如何成為前導戰爭風險面，並建立不獵巫、可驗證、可依法處理的防禦架構。

## 二、人員吸收與秘密委託

可能目標：

- 取得人員、流程、帳號、代理順位與修復能力資訊。
- 危機時延遲通報、誤導或阻礙協調。
- 找出債務、家庭、利益及脅迫弱點。
- 建立危機期間待命任務。

高風險徵候：

- 不符合職務需要的大量下載。
- 對代理順位、備援通信、修復隊及動員流程異常關注。
- 異常金流、接觸及海外行程。
- 危機前突然請假、失聯、離職或要求調動。
- 接受未揭露的外國政府、政黨或國企任務。

## 三、人員生命週期管理

- 任用前查核。
- 高權限持續查核。
- 最小權限。
- 職務分離與輪調。
- 異常下載及登入監控。
- 離職即時撤權。
- 退休後敏感接觸通報。
- 債務、脅迫及家屬支援。
- 主動通報減責與保護。

## 四、供應商與承包商

風險：

- 合法維護權限被濫用。
- 多層轉包掩蓋控制人。
- 危機時停止服務、延遲零件或拒絕支援。
- 遠端管理平台成為共同失敗點。
- 同一供應商跨政府、金融、電信、能源及醫療。

預警：

- 控制權突然變更。
- 維護帳號權限提高。
- 海外遠端連線增加。
- 關鍵零件及更新同步延遲。
- 最終受益人及資料流不透明。

防禦：

- 供應商分級。
- 控制權變更通報。
- 高風險遠端維護雙人審批。
- 重要系統具人工及替代供應商模式。
- 關鍵備件不得集中單一來源。

## 五、政府與軍政個資外洩

可能用途：

- 精準詐騙與假冒。
- 人際關係圖。
- 家庭、財務與職務脅迫。
- 假公文、假帳號及深偽。
- 找出代理人、修復人員及核心決策者。

藍方需敏感個資去集中化、硬體金鑰或通行金鑰、外洩後重發憑證，並保護受影響家庭。

## 六、任務化轉換

風險最高的不是資料被看過，而是情報任務開始關注：

- 何時切換備援。
- 誰能代理首長。
- 誰可以恢復系統。
- 哪些供應商有遠端權限。
- 哪些人員會在危機時到場。
- 哪些物資、車輛及設備可調度。

## 七、犯罪與地下金融代理

可能領域：

- 詐騙。
- 地下匯兌。
- 黑市與假物資。
- 幫派、暴力及恐嚇。
- 偽造文件及帳號。
- 洗錢與第三方支付。

不能因犯罪事件發生就自動歸責國家，應觀察金流、指揮、期限、目標及與軍演、網攻、外交壓力的同步。

## 八、法律與權利護欄

- 秘密委託需具體定義。
- 依法調查與司法審查。
- 保護證人及通報者。
- 犯罪所得依法沒收。
- 不以政治立場、國籍或族裔推定犯罪。
- 避免重要案件遭資訊洩漏及政治操作。

## 九、供應鏈風險矩陣

| 類別 | 主要風險 | 替代要求 |
|---|---|---|
| 雲端 | 帳號、資料、備份集中 | 跨雲與離線 |
| 電信 | 單一業者與遠端管理 | 跨網漫遊與多供應商 |
| 軟體 | 更新及簽章失效 | 白名單與離線版本 |
| 維修 | 人員與零件不到場 | 跨區與本地備件 |
| 金融科技 | 支付及身分集中 | 低頻寬與人工模式 |
| 醫療 | 病歷及設備遠端依賴 | 離線病歷與現地操作 |

## 十、兵推注入

1. 高權限承包商帳號異常登入。  
2. 重要供應商控制權突然變更。  
3. 修復人員遭恐嚇或大量失聯。  
4. 備份管理帳號與生產系統同時停用。  
5. 外洩資料真假混雜。  
6. 承包商拒絕危機支援。  
7. 重要零件因海外行政措施延遲。  
8. 反間諜案件引發政治與族群爭議。  

## 十一、KPI

| 指標 | 建議衡量 |
|---|---|
| 高權限異常偵測 | 分鐘至小時 |
| 離職撤權 | 即時完成率 |
| 控制權透明 | 揭露率 |
| 替代供應商 | 關鍵功能覆蓋率 |
| 主動通報 | 保護與處理時間 |
| 修復人力 | 替補到場時間 |
| 備件 | 最低可持續天數 |

## 十二、結論

真正危險的內應不是單一「間諜身分」，而是：

> 在危機時握有合法權限、知道制度依賴、能延遲修復，又不易被立即歸責的人員與供應鏈節點。

## 評估方法

| 等級 | 定義 | 使用原則 |
|---|---|---|
| A | 官方法律、制度、公開活動與確認案件 | 基準事實 |
| B | 官方威脅評估、可信研究與多來源判斷 | 主要結論 |
| C | 依公開能力與行為建立的條件式情境 | 明確標示推演 |
| D | 未交叉驗證傳聞或單一匿名指控 | 不納入核心結論 |

同時觀察意圖、能力、準備、跨領域同步、不可逆性及紅方失敗條件。
