# 臺灣前導戰爭｜第六卷：軍事灰色地帶、海警準封鎖與盟國分化

## 一、文件目的

分析紅方如何利用軍演、海警、海空壓力、假停火、法律敘事及對盟國的政治經濟脅迫，在未全面開戰前壓縮臺灣行動空間。

## 二、軍演消耗戰

可能目的：

- 迫使國軍反覆提高戒備。
- 消耗飛行、航行、維修與人力。
- 讓民眾對警報疲乏。
- 隱藏真正攻擊前的異常。
- 測試臺灣及盟國反應時間。

藍方需分級反應、保存重要戰力，避免每次演習都用最高成本反應，並建立由演訓轉為戰爭準備的判斷標準。

## 三、海警與準封鎖

可能目的：

- 建立中國單方面執法常態。
- 測試商船、海巡、海軍及盟國反應。
- 不宣戰即壓縮臺灣海空空間。
- 使保險與航運自行撤離。

藍方需：

- 區分執法、灰區、準封鎖及正式軍事攻擊。
- 海巡、海軍、外交及司法共同記錄。
- 與商業航運及盟國建立一致說法。
- 避免被迫接受中國法律框架。

## 四、軍事欺騙與錯誤方向

可能目的：

- 讓臺灣只注意軍事方向。
- 忽略網路、金融、海纜、內應與修復。
- 讓盟國對真正意圖產生不同判斷。
- 製造錯誤動員與資源配置。

藍方需軍事、民生、網路與外交共同情勢圖，設置紅隊與反證程序。

## 五、假停火與假談判

可能目的：

- 延遲臺灣動員。
- 分化盟國。
- 讓企業及航運等待結果。
- 在談判期間繼續準備。
- 迫使臺灣接受單方面海空管制。

藍方需：

- 停火必須有可驗證行動。
- 談判與戰備不可互相取代。
- 航運、海纜修復與人道通道需具體條件。
- 防止暫時安排永久化。

## 六、對美國的分化

敘事：

- 中國行動只是內政或有限執法。
- 臺灣先挑釁。
- 中國不會攻擊第三國。
- 美國介入將造成核戰與全球經濟崩潰。

藍方需提供中國首先使用武力的時間線、民用設施及商業交通受影響證據，並分級提出支援需求。

## 七、對日本的分化

可能工具：

- 沖繩及基地爭議。
- 日本企業與能源航線威脅。
- 撤離及核戰恐懼。
- 歷史與國內政治。

藍方需強調日本本土、海纜、航運與居民安全，並建立非軍事及防禦型支援清單。

## 八、對菲律賓的分化

可能工具：

- 經濟、觀光與南海壓力。
- 將基地使用描述為犧牲菲律賓。
- 放大中央與地方差異。
- 威脅撤僑及商業交通。

藍方需聚焦巴士海峽監視、撤僑、人道及航運合作，尊重其法律與政治程序。

## 九、對韓國的牽制

可能工具：

- 北韓核飛彈與邊境壓力。
- 宣稱駐韓美軍支援臺海會削弱半島防衛。
- 對韓企業、半導體與供應鏈施壓。
- 放大日韓歷史矛盾。

藍方應將韓國角色定位為半島穩定、後方、資安、醫療與供應鏈支援，不預設直接派兵。

## 十、俄羅斯與北韓分散資源

可能目的：

- 在其他戰區增加壓力。
- 使美國、日本、韓國及歐洲分散資源。
- 在聯合國阻止實質決議。
- 支持反制裁與反干涉敘事。

## 十一、東協與全球南方

紅方敘事：

- 臺海是中國內政。
- 制裁傷害全球經濟。
- 西方利用亞洲對抗中國。
- 應優先停火，不應支援臺灣。

藍方需強調國際航行、海纜、民用設施、經濟及人道外溢。

## 十二、盟國分化矩陣

| 國家 | 紅方工具 | 藍方優先議題 |
|---|---|---|
| 美國 | 核升級與戰爭成本 | 合法政府、航行與區域安全 |
| 日本 | 基地、沖繩與經濟 | 本土安全、海纜與航運 |
| 菲律賓 | 南海、經濟與基地政治 | 巴士海峽、撤僑與人道 |
| 韓國 | 北韓及供應鏈 | 半島穩定、資安與後方 |
| 澳洲 | 對中貿易 | 情報、海纜、衛星與航運 |
| 歐洲 | 經濟成本 | 金融、科技、人道與規則 |
| 東協 | 中立與內政敘事 | 航運、經濟及人道 |

## 十三、兵推注入

1. 中國宣布有限海警執法，商船停止靠港。  
2. 日本因基地爭議延遲決策。  
3. 菲律賓只同意撤僑與人道。  
4. 韓國因北韓試射限制支援。  
5. 美國提供情報但暫不直接介入。  
6. 俄羅斯在其他戰區升高壓力。  
7. 東協只要求雙方克制。  
8. 中國提出停火但維持海上檢查。  

## 十四、KPI

| 指標 | 建議衡量 |
|---|---|
| 盟國共同情勢認定 | 完成時間 |
| 支援需求排序 | 24小時內 |
| 海警與軍事歸類 | 跨部會一致性 |
| 商業航運維持 | 最低比例 |
| 國際證據發布 | 多語與交叉驗證 |
| 停火監督 | 可驗證行動比例 |

## 十五、結論

灰色地帶與盟國分化的目的不是讓所有國家支持中國，而是：

> 讓每個國家基於不同理由延遲決策，使臺灣在最關鍵的前72小時缺乏足夠支援。

## 評估方法

| 等級 | 定義 | 使用原則 |
|---|---|---|
| A | 官方法律、制度、公開活動與確認案件 | 基準事實 |
| B | 官方威脅評估、可信研究與多來源判斷 | 主要結論 |
| C | 依公開能力與行為建立的條件式情境 | 明確標示推演 |
| D | 未交叉驗證傳聞或單一匿名指控 | 不納入核心結論 |

同時觀察意圖、能力、準備、跨領域同步、不可逆性及紅方失敗條件。
