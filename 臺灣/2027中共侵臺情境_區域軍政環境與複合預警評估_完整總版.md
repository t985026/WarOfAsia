# 2027中共侵臺評估｜第一卷：基準情境與周邊國家軍政環境

## 一、執行摘要

2027更適合被理解為「能力節點」而不是「開戰截止日」。美國國防部2025年報告表示，中國要求解放軍在2027年底前具備對臺作戰並取得勝利的能力；這代表北京希望增加可用選項，不等於已完成不可逆的開戰決策。

截至2026年8月4日，最可能持續的行動仍是：

- 認知作戰
- 網路攻擊與長期設伏
- 間諜與人員吸收
- 經濟、外交與法律脅迫
- 海警、軍艦、軍機及公務船常態施壓
- 大型環臺軍演與封鎖演練
- 對美日韓菲澳同盟體系的分化

全面兩棲登陸具有最高軍事與政治風險，因此未必是第一選項。更合理的升級鏈為：

```text
常態灰色地帶
→ 高強度軍演及海警包圍
→ 短期海關式檢查／隔離
→ 選擇性準封鎖
→ 有限打擊或外離島危機
→ 視臺灣與盟國反應決定是否擴大
```

## 二、基準情境機率

| 情境 | 2027年底前基準區間 | 主要理由 |
|---|---:|---|
| 認知戰、網攻、間諜、政治與經濟脅迫持續 | 80–95% | 已是常態競爭工具 |
| 大型環臺軍演、海警包圍、封鎖演練 | 70–90% | 可施壓、蒐集反應且低於全面戰爭 |
| 短期海上檢查、隔離或準封鎖 | 25–40% | 可測試盟國與商業反應 |
| 有限精準打擊、外離島或局部危機 | 10–25% | 升級風險高但可作強制手段 |
| 全面兩棲入侵臺灣本島 | 10–20% | 後勤、聯合指揮、城市戰與外國介入風險極高 |
| 高度危機但最終沒有開戰 | 40–60% | 軍演與脅迫可作政治工具，不必轉成戰爭 |

這些區間互相重疊，因為同一年可能先出現軍演、隔離與危機降級，而非只有單一結果。

## 三、美國軍政環境

### 3.1 戰略角色

美國是最重要的外部嚇阻者，具備：

- 全球情報、衛星與偵察能力
- 印太海空軍及核嚇阻
- 日本、韓國、菲律賓、澳洲等同盟與基地網絡
- 對中國金融、科技、航運及供應鏈施壓能力
- 對臺軍售、訓練、後勤與通信支援能力

### 3.2 美國可能採取的行動

| 行動 | 可能性 |
|---|---|
| 情報預警、衛星監視與公開歸責 | 高 |
| 軍售、彈藥、通信、資安與後勤支援 | 高 |
| 聯合制裁及國際聯盟 | 高 |
| 海空軍直接介入 | 中至高，取決於中國行動型態 |
| 對模糊海警或海關隔離立即開戰 | 不確定 |
| 對美軍基地或艦機遭攻擊後擴大介入 | 顯著上升 |

### 3.3 美國的不確定因素

- 國內政治與國會支持
- 全球其他戰區
- 彈藥與工業產能
- 中國是否先攻擊美軍
- 臺灣是否被國際社會認為改變現狀
- 日本與菲律賓是否提供充分基地及後勤
- 核升級風險

## 四、日本軍政環境

日本是臺海危機最直接受影響的盟國節點之一，因為：

- 西南諸島鄰近臺灣
- 駐日美軍基地具有重大作用
- 日本海空交通線與臺海安全相連
- 中國軍事活動可能直接影響日本領空、領海與專屬經濟區
- 日本需同時處理居民避難與基地運用

### 4.1 可能角色

- 保衛日本領土與西南諸島：高
- 提供美軍基地、情報、後勤：高
- 非戰鬥性支援臺灣與區域航運：中至高
- 直接參與臺灣本島作戰：中，取決於日本是否遭攻擊及法律認定
- 與美國共同實施制裁及海上安全支援：高

### 4.2 中國可能對日本採取的分化

- 沖繩基地爭議
- 地方政府與中央政府立場差異
- 假美軍事故、污染或犯罪消息
- 經濟報復與觀光限制
- 強化「日本被美國拖入戰爭」敘事
- 在東海與西南諸島增加壓力

## 五、韓國軍政環境

韓國的首要軍事威脅仍是北韓。臺海危機期間，韓國很可能優先：

- 防止北韓乘機挑釁
- 保留部隊於朝鮮半島
- 保護美軍後方基地與韓國領土
- 支持情報、外交、制裁及部分後勤

### 5.1 可能角色

| 行動 | 可能性 |
|---|---|
| 外交與制裁支持 | 中至高 |
| 情報及美軍後方支援 | 中 |
| 直接出兵臺海 | 低至中 |
| 因北韓升高威脅而限制支援 | 高可能性 |

### 5.2 中國的分化重點

- 放大反美與反日敘事
- 影響政黨、媒體、商界及地方交流
- 強化「臺海與韓國無關」
- 配合北韓製造第二戰場壓力
- 削弱美日韓情報共享

## 六、菲律賓軍政環境

菲律賓北部與巴丹群島靠近巴士海峽，對臺灣南方航道與區域後勤重要。

### 6.1 可能角色

- 美軍基地輪調與後勤：中至高
- 海上監視及南海牽制：高
- 人道救援與撤僑：高
- 直接參戰：中低至中
- 受國內政治與對中經濟關係影響：高

### 6.2 風險

- 菲國內部對美軍使用基地的爭議
- 中國在南海同步升高壓力
- 地方政治與中央不同調
- 北部島嶼居民安全與疏散
- 港口機場遭網路及資訊壓力

## 七、澳洲軍政環境

澳洲可能提供：

- 情報與資安
- 外交與制裁
- 北部基地及後勤
- 海上監視與盟國協同
- 海纜與衛星通信支援

直接作戰介入取決於美國行動、澳洲國內決策及中國是否攻擊盟軍。

## 八、北韓與俄羅斯

### 8.1 北韓

最可能的作用不是直接進入臺海，而是：

- 飛彈試射
- 邊境挑釁
- 網路攻擊
- 迫使韓國與美軍保留兵力
- 增加日本飛彈防禦負擔

### 8.2 俄羅斯

可能提供：

- 外交支持
- 能源與經濟緩衝
- 情報或技術交流
- 在其他戰區增加美歐壓力
- 與中國進行海空展示

直接參與臺海戰事的可能性低於間接牽制。

## 九、區域聯動判斷

| 區域條件 | 對中國風險計算的影響 |
|---|---|
| 美日基地及聯合指揮順暢 | 降低中國開戰意願 |
| 韓國被北韓牢牢牽制 | 增加中國機會 |
| 菲律賓限制美軍使用北部基地 | 增加中國機會 |
| 澳洲明確加入後勤與制裁 | 提高中國成本 |
| 日本國內基地爭議失控 | 增加準封鎖或有限行動可能 |
| 盟國公開分歧 | 可能誘發北京測試 |
| 盟國建立共同反脅迫與航運保障 | 降低隔離成功率 |

## 十、基準情境的主要上修條件

- 解放軍高層清洗結束且指揮穩定
- 沿海軍民後勤、交通、醫療同步戰備
- 部隊演習後不撤回
- 出境、資本、網路及外企活動同步受限
- 間諜任務由蒐集轉為待命與啟用
- 多點海纜、政府、金融及電力系統同步異常
- 美日韓菲澳出現明顯政治分裂
- 北京宣傳從勝利敘事轉向犧牲與長期戰爭

## 十一、主要下修條件

- 黨軍權力衝突持續
- 聯合作戰與裝備品質問題惡化
- 中國經濟與地方財政承受重大壓力
- 美國與盟國嚇阻部署透明且可信
- 臺灣社會韌性與後備改革顯著提升
- 中國無法建立制裁、能源與金融緩衝
- 俄羅斯或北韓無法提供牽制
- 危機溝通與政治談判仍有效

## 十二、本卷結論

2027的主問題不是「會不會在某一天突然登陸」，而是：

> 北京是否在2026至2027年間，同時完成政治控制、軍事指揮、民間動員、經濟防制裁、盟國分化與臺灣內部破壞的組合準備。

只看軍演會高估或低估風險；必須把軍政、經濟、社會、情報、網路與區域外交放入同一框架。

## 評估方法與證據分級

### 證據分級

| 等級 | 定義 | 文件處理方式 |
|---|---|---|
| A級 | 法律、官方制度、官方公開案件、可驗證軍事活動 | 可作為基準事實 |
| B級 | 官方威脅評估、可信研究或多個獨立來源支持 | 可作為主要判斷依據 |
| C級 | 根據已知能力與行為建立的條件式推演 | 必須清楚標示「假設」 |
| D級 | 缺乏可靠來源、僅有傳聞或無法交叉驗證 | 不納入主要結論 |

### 機率區間的意義

| 區間 | 用語 | 意義 |
|---:|---|---|
| 0–10% | 極低 | 需要多項重大條件改變 |
| 10–25% | 低至中 | 不能排除，但不是主要路徑 |
| 25–40% | 中等 | 具有可行性，須納入實際準備 |
| 40–65% | 中高 | 多項條件若成立，風險顯著 |
| 65–85% | 高 | 應視為主要規劃情境 |
| 85–100% | 極高 | 幾乎確定會持續或發生某種形式 |

### 評估軸線

1. **意圖**：北京政治領導是否認為行動有利且可控。  
2. **能力**：解放軍及黨國體系是否具備執行與持續能力。  
3. **準備**：動員、後勤、醫療、金融、網路與社會控制是否同步。  
4. **機會**：美國、日本、韓國、菲律賓、澳洲及臺灣是否出現可利用的政治或軍事窗口。  
5. **成本**：制裁、戰損、政權風險、經濟衝擊及國際反應。  
6. **替代方案**：封鎖、隔離、灰色地帶、有限打擊是否比全面登陸更符合成本效益。

# 2027中共侵臺評估｜第二卷：中共黨政軍衝突與決策風險

## 一、情境定義

本卷依使用者指定條件，將「中國10月1日大會議後軍政衝突」明確定義為：

> **假設自2026年10月1日後，中共重大政治會議、國慶、人事調整或軍中清洗之後，黨中央與解放軍高層出現權力重組、抗命疑慮、忠誠清查、指揮信任下降或政策分歧。**

這是C級條件式假設，不是截至2026年8月4日已發生的事實。

## 二、黨軍衝突的四種型態

### 2.1 忠誠與人事清洗

- 高階將領被調查或撤換
- 戰區、火箭軍、裝備及聯勤體系人事重組
- 政治工作與軍事專業發生衝突
- 領導層更重視忠誠而非戰力

### 2.2 戰略判斷分歧

- 軍方認為全面行動風險過高
- 黨中央要求更強硬展示
- 軍方主張延後但宣傳要求立即表態
- 不同戰區對主要方向判斷不同

### 2.3 腐敗與戰備信任危機

- 裝備妥善率不可信
- 採購與工程品質遭質疑
- 彈藥、燃料及後勤數字失真
- 演訓成果被誇大
- 高層無法確定真實作戰能力

### 2.4 指揮與責任恐懼

- 將領不敢主動決策
- 基層等待書面命令
- 危機中缺乏彈性
- 部門互相推責
- 壞消息延遲上報

## 三、對侵臺風險的雙重效果

### 3.1 短期：全面入侵風險下降

全面兩棲作戰需要：

- 高度信任的聯合指揮
- 軍種協同
- 持續後勤
- 大量民用交通動員
- 複雜的海空與資訊整合
- 對重大損失承擔政治責任

黨軍衝突未解時，這些條件反而較弱。

### 3.2 短期：示威與誤判風險上升

內部權力不穩可能增加：

- 大型軍演
- 對臺高強度壓迫
- 民族主義宣傳
- 外交與經濟報復
- 局部海空危機
- 以外部敵人轉移政治焦點

### 3.3 中期：若清洗完成，風險可能反升

若在6至18個月內出現：

- 人事清洗停止
- 忠誠派全面接管
- 戰區與軍種指揮穩定
- 裝備與聯勤接受重新驗證
- 重大演習恢復
- 民間動員同步加速

則政治領導可能認為軍隊更可控，侵臺或準封鎖風險上升。

## 四、時間軸評估

| 時段 | 可能影響 |
|---|---|
| 衝突後0–3個月 | 全面入侵下降；軍演與對外示強增加 |
| 3–6個月 | 觀察清洗、人事、演訓與後勤是否穩定 |
| 6–12個月 | 若忠誠與指揮重整完成，風險重新上升 |
| 12–18個月 | 若民間動員及制裁準備同步，可能成為作戰窗口 |
| 衝突長期未解 | 登陸風險下降，但誤判及有限危機維持高位 |

## 五、政權轉移危機的判斷

「利用外部戰爭轉移內部危機」不能被視為自動規律。領導層同樣可能因內部不穩而避免高風險戰爭。

需判斷：

- 領導人是否需要展現威望
- 軍隊是否足以信任
- 經濟能否承受制裁
- 社會是否接受犧牲
- 外部盟國是否分裂
- 是否存在可控的有限選項

## 六、黨軍衝突的可觀察指標

### 6.1 人事

- 戰區主官頻繁更換
- 火箭軍、裝備、聯勤高層異常調整
- 長期職缺或代理
- 政治工作幹部升遷異常
- 重要將領缺席重大活動

### 6.2 宣傳

- 強調「軍隊絕對忠誠」
- 頻繁要求政治整訓
- 對腐敗與兩面人高強度批判
- 軍事專業議題被政治口號取代
- 突然宣稱整肅已取得決定性勝利

### 6.3 演訓

- 演習規模與後勤不匹配
- 高階聯合演習暫停或更換指揮
- 演習後部隊長期留在前沿
- 新任主官快速進行大規模演練
- 民用船舶、鐵路、醫療首次同步加入

### 6.4 情報與內部控制

- 軍人及家屬出境限制
- 軍工及技術人員集中管理
- 內部通信與文件權限收緊
- 軍中社群與私人通信大幅限制
- 大量調查資料不再公開

## 七、四種黨軍情境

### 情境A：清洗持續、指揮失序

- 全面登陸：下修
- 軍演與對外示強：上修
- 誤判：上修
- 網路、認知、經濟脅迫：維持高位

### 情境B：忠誠派接管但專業下降

- 政治意圖：上升
- 執行品質：不確定
- 有限危機：上升
- 全面入侵：中度上升但失敗風險高

### 情境C：清洗結束且專業驗證完成

- 指揮與執行能力：上升
- 作戰窗口：顯著上升
- 尤其需觀察民間動員與後勤

### 情境D：黨內和軍內都選擇降級

- 可能以經濟、外交、認知及灰區取代戰爭
- 2027仍是能力節點，但不是作戰窗口

## 八、核與危機穩定

黨軍衝突也可能影響：

- 戰略預警可信度
- 假命令風險
- 火箭軍指揮安全
- 核常力量混淆
- 高層危機溝通

文件不涉及部署位置或作戰程序，只強調：內部指揮不信任會提高外部誤判，因此美中危機溝通與盟國情報驗證更重要。

## 九、對臺灣及盟國的政策意涵

### 9.1 不應採取的判斷

- 看見清洗就認定中國即將開戰
- 看見軍隊混亂就放鬆準備
- 認為內鬥必然阻止有限軍事危機
- 以未經證實的人事傳聞作決策

### 9.2 應採取的準備

- 同時追蹤人事、演訓、後勤與社會控制
- 建立「清洗完成後風險反升」指標
- 防止示威軍演意外轉成危機
- 加強領導命令與軍事資訊驗證
- 向盟國分享不確定性，不只分享單一結論

## 十、本卷結論

2026年10月1日後若出現黨軍衝突，最合理的判斷是：

> 短期全面侵臺能力下降，但軍演、局部挑釁、認知戰、經濟壓迫與誤判風險上升；若清洗在2027前完成，並伴隨指揮、聯勤、交通、醫療及社會控制同步恢復，則風險可能迅速反升。

## 評估方法與證據分級

### 證據分級

| 等級 | 定義 | 文件處理方式 |
|---|---|---|
| A級 | 法律、官方制度、官方公開案件、可驗證軍事活動 | 可作為基準事實 |
| B級 | 官方威脅評估、可信研究或多個獨立來源支持 | 可作為主要判斷依據 |
| C級 | 根據已知能力與行為建立的條件式推演 | 必須清楚標示「假設」 |
| D級 | 缺乏可靠來源、僅有傳聞或無法交叉驗證 | 不納入主要結論 |

### 機率區間的意義

| 區間 | 用語 | 意義 |
|---:|---|---|
| 0–10% | 極低 | 需要多項重大條件改變 |
| 10–25% | 低至中 | 不能排除，但不是主要路徑 |
| 25–40% | 中等 | 具有可行性，須納入實際準備 |
| 40–65% | 中高 | 多項條件若成立，風險顯著 |
| 65–85% | 高 | 應視為主要規劃情境 |
| 85–100% | 極高 | 幾乎確定會持續或發生某種形式 |

### 評估軸線

1. **意圖**：北京政治領導是否認為行動有利且可控。  
2. **能力**：解放軍及黨國體系是否具備執行與持續能力。  
3. **準備**：動員、後勤、醫療、金融、網路與社會控制是否同步。  
4. **機會**：美國、日本、韓國、菲律賓、澳洲及臺灣是否出現可利用的政治或軍事窗口。  
5. **成本**：制裁、戰損、政權風險、經濟衝擊及國際反應。  
6. **替代方案**：封鎖、隔離、灰色地帶、有限打擊是否比全面登陸更符合成本效益。

# 2027中共侵臺評估｜第三卷：十七項複合條件與風險重估

## 一、使用方式

本卷完整納入使用者提出的17項條件，逐項區分：

- 是否已有公開證據
- 對侵臺意圖、能力、準備或機會的影響
- 對灰色地帶、準封鎖、有限打擊與全面登陸的不同權重
- 可能的誤判與反效果
- 應觀察的升級條件

## 二、十七項條件完整評估


1. **2026年10月1日後黨政與軍方衝突**  
   短期降低全面登陸能力，但增加軍演、對外示強與誤判；若清洗完成且指揮集中，中期風險反升。

2. **中國間諜活動持續**  
   常態蒐集本身不是開戰指標；若任務轉向代理順位、戰時通信、動員、修復、待命或破壞，警示性大幅提高。

3. **控制中國人民出境**  
   個別公務員與敏感產業管制可能是常態；若擴大到技術人員、軍人家屬、外企員工及一般居民，且與資本及物流管制同步，屬高級預警。

4. **對外網路加強監控**  
   一般審查不足以證明作戰準備；若國際VPN、跨境企業通信、境外雲端、國營電信與沿海流量同步進入特殊管制，警示性提高。

5. **持續滲透韓國政治**  
   目的可能是阻止韓國提供美軍後方支援、放大反美反日爭議並迫使韓國專注北韓。需以金流、委託與協同行為判斷，不能以政治立場推定。

6. **搗亂日本軍政**  
   沖繩基地爭議、地方反對港口機場使用、假美軍事件、經濟報復與日美指揮權爭論，可延遲日本決策；但過度施壓也可能反向強化日美同盟。

7. **分化臺灣社群對立**  
   可能放大「美國會放棄臺灣」「備戰等於引戰」「政府已投降」「特定族群是內應」等敘事，目標是破壞信任與動員。

8. **持續收買臺灣人員**  
   高風險接觸面包括現退役軍人、公務員、承包商、電信能源港口交通、科技軍工及地方政治人員。由一般資料轉向危機程序和高權限，風險顯著上升。

9. **搗亂政府機關體制**  
   假公文、假命令、資料外洩、大量假檢舉、司法行政塞車、中央地方衝突及官員深偽，目標是延長每一道決策的確認時間。

10. **間諜滲透與軍事破壞**  
    若出現取得戰時門禁、高權限、修復節點、應變時間，或與網攻同步的待命任務，應視為接近危機啟用的高級警報。公開版不記載具體方法。

11. **滲透人員或間諜處罰偏輕**  
    這是臺灣自身脆弱性乘數。除刑度外，應改善證據能力、秘密委託規範、犯罪所得沒收、持續查核與主動通報減責。

12. **引入毒品、黑道並持續擾亂秩序**  
    官方案件支持黑道與地下金融曾成為滲透媒介；但「中國政府直接以毒品作為侵臺工具」缺乏足夠公開證據，須列為C至D級假設。危機時犯罪代理可透過假報案、暴力、恐嚇及交通秩序擾亂增加警消負擔。

13. **持續破壞海底電纜**  
    2025年臺灣發生多起權宜輪違規破壞通訊海纜事件，促使行政院推動海纜七法。單一事件不必然是敵對行動；多點、連續、船舶行為異常、維修受阻並與網攻軍演同步時，準封鎖風險上升。

14. **引用更多軍政設施進行模擬攻堅**  
    實體模型、專業藍軍、兵棋、數位模擬及城鎮戰訓練代表能力準備，但不等於已下政治命令。若模型更新與跨軍種、後勤、民用運輸及長期控制訓練結合，警示性更高。

15. **電資戰持續竊取民政、廉政資訊**  
    可能用於掌握代理順位、人事弱點、反間諜案件、假文件及官員互信破壞。公開資料可支持中共持續針對關鍵基礎設施進行網駭與設伏，但特定廉政資料是否遭大規模竊取仍需個案證據。

16. **持續試探並縮減臺灣實際海空活動空間**  
    共機、共艦、公務船及海警常態活動可消耗應變、改變中線現狀、蒐集反應並為封鎖建立存在。其對準封鎖及突然轉實戰的風險影響高。

17. **上述行動持續累積並跨領域同步**  
    單一事件可能是背景噪音；政治控制、民用動員、間諜啟用、多點海纜、網攻、盟國分化與大型軍演同時出現時，才構成系統性危機準備。

| 分化臺灣社群 | 極高 | 高 | 高 | 高 | 持續性高 |
| 收買臺灣人員 | 高 | 高 | 高 | 高 | 任務啟用時極高 |
| 搗亂政府體制 | 高 | 高 | 高 | 中高 | 高 |
| 間諜軍事破壞 | 中 | 高 | 極高 | 高 | 極高 |
| 輕罰與制度缺口 | 乘數 | 乘數 | 乘數 | 乘數 | 脆弱性指標 |
| 毒品黑道秩序戰 | 中高 | 中 | 中 | 低至中 | 證據需嚴格分級 |
| 海纜破壞 | 中高 | 極高 | 高 | 中高 | 多點同步時極高 |
| 軍政模型攻堅 | 中 | 中高 | 高 | 高 | 能力指標 |
| 電資戰竊取資料 | 高 | 高 | 高 | 中高 | 高 |
| 縮減海空空間 | 極高 | 極高 | 高 | 中高 | 高 |
| 跨領域累積 | 極高 | 極高 | 極高 | 高 | 最重要 |

## 四、加入條件後的重估

| 情境 | 基準區間 | 多數條件成立後 | 說明 |
|---|---:|---:|---|
| 認知、網路、間諜與政治戰 | 80–95% | 90–98% | 幾乎必然持續 |
| 大型軍演與包圍演練 | 70–90% | 85–95% | 可作施壓與預演 |
| 短期準封鎖或海關式隔離 | 25–40% | 45–65% | 若海纜、海警、航運與網攻同步 |
| 有限打擊或外離島危機 | 10–25% | 20–35% | 取決於政治與盟國反應 |
| 全面兩棲入侵 | 10–20% | 20–35% | 仍非最可能第一步 |
| 高度危機但最終未開戰 | 40–60% | 50–70% | 脅迫可能取得部分政治效果 |

## 五、黨軍衝突的修正

若黨軍衝突在2027仍未解決：

- 全面入侵可下修至約15–25%
- 但軍演、誤判、網路、認知及有限危機維持高位

若出現以下組合：

- 清洗結束
- 指揮集中
- 重要部隊人事穩定
- 大規模軍民動員
- 沿海交通與醫療戰備
- 出境、資本與網路同步管制
- 部隊及後勤演習後不撤回

則全面侵臺可上調至約30–45%。

## 六、因果鏈

```text
內部政治控制收緊
        ↓
軍隊人事與指揮重新集中
        ↓
對外網路、人口與資本管制
        ↓
民用交通、醫療、能源、港口進入戰備
        ↓
臺灣內部網絡與盟國分化同步啟用
        ↓
大型軍演、海警隔離、海纜與網路異常
        ↓
準封鎖或有限軍事危機
        ↓
視國際反應決定擴大或降級
```

## 七、不可直接成立的推論

下列推論應避免：

- 有間諜案件 = 已決定2027入侵
- 有海纜事故 = 一定由中國政府下令
- 韓國存在親中人士 = 韓國政治被控制
- 日本有反基地運動 = 中國代理
- 黑道與毒品案件 = 中國國家行動
- 建立模型區 = 已下令攻打該設施
- 中國加強網路監控 = 已進入戰時
- 軍方清洗 = 必然以戰爭轉移危機

## 八、判斷重點

最重要的不是事件總數，而是：

1. 是否跨政治、軍事、經濟、網路與社會領域同步。  
2. 是否從蒐集、施壓轉為待命、動員與實際啟用。  
3. 是否出現不可逆準備，例如廣泛徵用、醫療戰備與部隊不撤回。  
4. 是否建立對制裁、能源、金融與人口流動的國內控制。  
5. 是否同時削弱美日韓菲澳協同。

## 評估方法與證據分級

### 證據分級

| 等級 | 定義 | 文件處理方式 |
|---|---|---|
| A級 | 法律、官方制度、官方公開案件、可驗證軍事活動 | 可作為基準事實 |
| B級 | 官方威脅評估、可信研究或多個獨立來源支持 | 可作為主要判斷依據 |
| C級 | 根據已知能力與行為建立的條件式推演 | 必須清楚標示「假設」 |
| D級 | 缺乏可靠來源、僅有傳聞或無法交叉驗證 | 不納入主要結論 |

### 機率區間的意義

| 區間 | 用語 | 意義 |
|---:|---|---|
| 0–10% | 極低 | 需要多項重大條件改變 |
| 10–25% | 低至中 | 不能排除，但不是主要路徑 |
| 25–40% | 中等 | 具有可行性，須納入實際準備 |
| 40–65% | 中高 | 多項條件若成立，風險顯著 |
| 65–85% | 高 | 應視為主要規劃情境 |
| 85–100% | 極高 | 幾乎確定會持續或發生某種形式 |

### 評估軸線

1. **意圖**：北京政治領導是否認為行動有利且可控。  
2. **能力**：解放軍及黨國體系是否具備執行與持續能力。  
3. **準備**：動員、後勤、醫療、金融、網路與社會控制是否同步。  
4. **機會**：美國、日本、韓國、菲律賓、澳洲及臺灣是否出現可利用的政治或軍事窗口。  
5. **成本**：制裁、戰損、政權風險、經濟衝擊及國際反應。  
6. **替代方案**：封鎖、隔離、灰色地帶、有限打擊是否比全面登陸更符合成本效益。

# 2027中共侵臺評估｜第四卷：新增預警指標與危機儀表板

## 一、目的

本卷將17項條件擴充為36項預警指標，建立可每週、每月追蹤的跨領域儀表板。

## 二、新增18至36項預警


18. **宣傳由「和平統一」轉向「犧牲與長期戰爭」**  
    若官方大量強調承受制裁、為統一犧牲經濟、戰爭不可避免及個人服從國家需要，預警價值高於一般民族主義。

19. **大規模反制裁與金融隔離準備**  
    國企去美元、限制外匯、要求企業回收海外資產、囤積能源糧食、測試跨境支付替代。

20. **外國企業與人員離境障礙**  
    外企主管出境受限、航班異常減少、領事服務受阻、外國使館家屬收到撤離建議。

21. **黨軍清洗突然結束並完成接管**  
    戰區、火箭軍、裝備、聯勤及政治工作出現穩定忠誠團隊，且恢復高強度聯合演訓。

22. **民用運輸轉入軍事優先**  
    滾裝船、鐵路、公路、港口、民航空域及沿海貨運出現大規模、持續且無合理商業原因的軍事優先。

23. **醫療與大量傷患準備**  
    血液、外科物資、藥品異常囤積，沿海醫院取消服務，醫護限制休假，軍民醫療演練增加。

24. **後備、民兵及技術人員動員**  
    大量預備役通知，港口、通信、能源、工程人員被集中管理，民兵任務轉向交通、通信及設施保障。

25. **聯勤活動超過演訓需求**  
    燃料、彈藥、備件前推，大量臨時倉儲，港口鐵路長時間管制，演習部隊不返回原駐地。

26. **網路潛伏節點由蒐集轉為破壞或阻斷**  
    多個後門同步啟動，電力、金融、通信、政府受到一致干擾，資料被刪除或修復遭阻止。

27. **間諜任務期限突然縮短**  
    要求立即取得資料、在特定日期待命、拍攝戰時流程、準備通信或交通條件。

28. **政府與軍方高敏感個資集中外洩**  
    代理順位、家屬、住址、移動、高權限帳號、修復及動員人員資料外洩。

29. **中國集中撤離海外公民或發布特殊旅遊警告**  
    若集中於日本、菲律賓、臺灣周邊及美軍基地所在國，警示性升高。

30. **北韓同步升高軍事危機**  
    飛彈、邊境、網路或海上挑釁，牽制美韓與日本飛彈防禦。

31. **俄羅斯同步製造其他戰區壓力**  
    分散美歐外交、情報、彈藥與海空資源，不必直接參與臺海。

32. **提前建立「臺灣先挑釁」的國際敘事**  
    外交部、國營媒體、學者、海外帳號同步使用高度一致的法律與戰爭歸責論述。

33. **大量假投降、假撤離、假銀行訊息同步出現**  
    尤其與軍演、海纜或網攻同日發生。

34. **地方政府與中央接獲不同命令**  
    可能反映深偽、假公文、通信污染或帳號入侵。

35. **關鍵維修及政府人員大量遭恐嚇、收買或失聯**  
    目標可能是使復原與指揮體系無法運作。

36. **臺灣政治危機與軍事危機同步**  
    選舉或罷免爭議、預算僵局、合法性爭議、街頭衝突與高強度軍演同時出現。


## 三、四大領域

| 領域 | 主要指標 |
|---|---|
| 政治控制 | 清洗、領導安全、出境限制、宣傳、資本控制 |
| 軍事動員 | 部隊、聯勤、民船、交通、醫療、後備 |
| 非軍事準備 | 能源、糧食、金融、網路、法律、外企控制 |
| 危機塑形 | 間諜、海纜、認知、盟國分化、灰色地帶 |

## 四、綠黃橙紅分級

### 綠色：常態競爭

- 一般軍演
- 常態共機共艦活動
- 宣傳與外交抗議
- 間諜與網路蒐集
- 無廣泛民用動員

### 黃色：多領域升高

- 兩個以上領域同時升高
- 軍演規模增大
- 網路與認知行動增加
- 局部出境或資本管制
- 盟國受到政治分化

### 橙色：危機準備

- 政治控制、軍事動員、網路預置同步
- 海警或海軍封控演練
- 民用交通、醫療、能源進入特殊狀態
- 間諜任務轉為待命
- 多點海纜或政府系統異常

### 紅色：作戰窗口

- 真實徵用及大規模民間動員
- 部隊演習後不撤回
- 醫療大量傷患準備
- 廣泛出境、資本、網路管制
- 海空封控與網路破壞同步
- 內外情報網實際啟用
- 國際敘事與撤僑同步完成

## 五、分數模型

每個指標可使用：

| 分數 | 意義 |
|---:|---|
| 0 | 未出現 |
| 1 | 單一或弱訊號 |
| 2 | 多來源支持，規模有限 |
| 3 | 官方或高可信證據，規模顯著 |
| 4 | 與其他領域同步，出現不可逆準備 |

### 5.1 不使用單純總分

不能只把36項相加，應加入「同步係數」：

- 同一領域多項：提高關注
- 三個以上領域同時：風險顯著上修
- 軍事動員＋非軍事準備＋危機塑形：最重要
- 只有宣傳與軍演：不得直接判定紅色

每月回答：

## 八、假旗、事故與誤報防護

### 8.1 海纜

- 單一事故不得立即歸責
- 應查船舶、海象、工程、故障型態及時間關聯
- 多點同步才提高敵對判斷

### 8.2 網路

- 區分犯罪、勒索、事故與國家行動
- 以惡意程式、基礎設施、指揮關係及行動節奏歸責

### 8.3 政治事件

- 親中立場不等於代理
- 需確認秘密委託、資金、權限與協同

### 8.4 軍事演習

- 規模不是唯一指標
- 重點是後勤、民用動員、演習後撤回及醫療準備

## 九、觸發門檻

### 黃色觸發

- 任兩領域達到顯著變化
- 啟動跨部會每日評估
- 加強海纜、資安及反情報

### 橙色觸發

- 三領域同步
- 民用運輸、醫療或能源出現戰備
- 啟動國家級備援與盟國情報協調

### 紅色觸發

- 不可逆動員＋部隊不撤回
- 海空封控＋網路破壞
- 大規模出境資本管制
- 啟動國家持續運作及全社會防衛

## 十、本卷結論

預警系統的目的不是準確猜中某一天，而是：

> 在北京仍可選擇降級時提高嚇阻，在不可逆準備出現時迅速轉入國家持續運作，並避免單一假消息或事故引發自我製造的危機。

## 評估方法與證據分級

### 證據分級

| 等級 | 定義 | 文件處理方式 |
|---|---|---|
| A級 | 法律、官方制度、官方公開案件、可驗證軍事活動 | 可作為基準事實 |
| B級 | 官方威脅評估、可信研究或多個獨立來源支持 | 可作為主要判斷依據 |
| C級 | 根據已知能力與行為建立的條件式推演 | 必須清楚標示「假設」 |
| D級 | 缺乏可靠來源、僅有傳聞或無法交叉驗證 | 不納入主要結論 |

### 機率區間的意義

| 區間 | 用語 | 意義 |
|---:|---|---|
| 0–10% | 極低 | 需要多項重大條件改變 |
| 10–25% | 低至中 | 不能排除，但不是主要路徑 |
| 25–40% | 中等 | 具有可行性，須納入實際準備 |
| 40–65% | 中高 | 多項條件若成立，風險顯著 |
| 65–85% | 高 | 應視為主要規劃情境 |
| 85–100% | 極高 | 幾乎確定會持續或發生某種形式 |

### 評估軸線

1. **意圖**：北京政治領導是否認為行動有利且可控。  
2. **能力**：解放軍及黨國體系是否具備執行與持續能力。  
3. **準備**：動員、後勤、醫療、金融、網路與社會控制是否同步。  
4. **機會**：美國、日本、韓國、菲律賓、澳洲及臺灣是否出現可利用的政治或軍事窗口。  
5. **成本**：制裁、戰損、政權風險、經濟衝擊及國際反應。  
6. **替代方案**：封鎖、隔離、灰色地帶、有限打擊是否比全面登陸更符合成本效益。

## 一、總體目標

臺灣與盟國的目標不是保證所有設施不受損，而是：

> 任何一位領導人、任何一處指揮節點、任何一條海纜、任何一座港口、任何一個資料中心或任何一名內應，都不能單獨使臺灣停止指揮、防衛、救援、金融運作或國際聯絡。

### 評估軸線

1. **意圖**：北京政治領導是否認為行動有利且可控。  
2. **能力**：解放軍及黨國體系是否具備執行與持續能力。  
3. **準備**：動員、後勤、醫療、金融、網路與社會控制是否同步。  
4. **機會**：美國、日本、韓國、菲律賓、澳洲及臺灣是否出現可利用的政治或軍事窗口。  
5. **成本**：制裁、戰損、政權風險、經濟衝擊及國際反應。  
6. **替代方案**：封鎖、隔離、灰色地帶、有限打擊是否比全面登陸更符合成本效益。

# 2027中共侵臺評估｜第六卷：VPN、eSIM資料風險與經濟民怨戰爭轉移情境

## 一、執行摘要

本卷回答兩個問題：

1. 若中共、受中國法律管轄的企業或不透明中國資本控制VPN、eSIM及跨境通信平台，是否可能造成資訊外洩或成為戰前情報工具？
2. 若中國經濟持續下行、房地產與地方財政惡化、民怨升高，中共是否可能透過對臺軍事危機或戰爭壓制內部壓力？

核心判斷如下：

- **VPN與eSIM確實具有資料集中及流量關聯風險。**最容易被取得的不是所有加密內容，而是身分、付款、來源IP、連線時間、裝置、基地台位置、漫遊、流量大小、DNS或目標服務等中繼資料。
- **eSIM協定本身並不天然不安全。**GSMA表示，在端點誠實且未遭控制的條件下，遠端SIM配置協定能達成其安全目標；高風險情境是合法端點、SM-DP+、eUICC、轉售平台、上游電信商或應用程式遭控制。
- **低價不能單獨證明情報意圖。**低價可能源自批發流量、創投補貼、促銷、較低成本上游或只提供數據服務；但「異常低價、所有權不透明、過度權限、資料跨境、路由異常、針對敏感族群促銷」同時出現時，應提高供應鏈審查等級。
- **經濟下行可能提高民族主義、軍演、灰色地帶、準封鎖或有限危機的誘因，卻不會自動導向全面侵臺。**全面戰爭可能造成制裁、傷亡、出口中斷、金融控制與政權責任，失敗時反而放大民怨。
- 真正危險的組合是：**經濟與政治壓力＋黨軍清洗完成＋軍隊可信＋反制裁準備＋盟國分裂＋民用動員＋對臺內應及通信平台可被啟用。**

---

## 二、法律與制度性風險

### 2.1 中國國家情報法

《中華人民共和國國家情報法》第7條規定，任何組織和公民應依法支持、協助和配合國家情報工作；第14條規定，國家情報工作機構可要求有關機關、組織和公民提供必要支持、協助和配合。

這不等於每一家中國企業都會主動替情報機關工作，但對受中國境內法律及實際控制權支配的公司而言，形成以下制度風險：

- 可能收到非公開的資料調取或協助要求
- 企業管理層可能難以拒絕國安或情報機關
- 海外使用者難以確認是否曾發生調取
- 公司公開隱私承諾可能與境內法律義務衝突
- 母公司、子公司及技術承包商之間可能形成間接調取鏈

### 2.2 判斷時不能只看註冊地

需要辨識：

- 最終受益人
- 董事會與否決權
- 技術及金鑰控制者
- 母公司實際所在地
- 資料中心與備份所在地
- SM-DP+、VPN控制面及日誌系統所在地
- 上游電信商及核心網路
- 軟體開發、更新及簽章控制者
- 是否可由境外母公司遠端管理

一家在歐洲、香港、新加坡或其他地區註冊的品牌，仍可能由其他法域的實際控制人、平台或上游通信商控制。

---

## 三、VPN可取得哪些資料

VPN將使用者流量透過其基礎設施轉送，因此使用者把部分信任從原本的網路供應商轉移給VPN業者。FTC提醒，VPN應用程式可能存取使用者傳送的資料，消費者應了解其權限、是否加密及是否與第三方分享資訊。

### 3.1 即使使用HTTPS，VPN仍可能掌握

- 來源公網IP
- 帳號、電子郵件及付款資料
- 連線開始與結束時間
- 使用的VPN出口伺服器
- 資料傳輸量及流量型態
- 裝置類型、作業系統及應用程式版本
- DNS查詢，視架構與設定而定
- 連線目標IP、網域或服務類型，視加密與協定而定
- 同一帳號在不同國家、裝置及時間的活動

HTTPS通常保護網頁內容、密碼及訊息正文，但不能完全消除中繼資料與流量型態。

### 3.2 VPN最壞情況

| 風險面向 | 最壞情境 |
|---|---|
| 大規模日誌 | 業者實際保存原始IP、時間、出口及服務活動 |
| 流量關聯 | 將使用者登入時間與外部網站、政府或媒體系統活動比對 |
| DNS控制 | 記錄、阻斷或重新導向網域查詢 |
| 軟體更新 | 透過被控制的更新管道增加監控、裝置識別或持久權限 |
| 根憑證 | 誘導安裝根憑證，擴大解密、攔截或重新簽發風險 |
| 選擇性服務阻斷 | 在危機時阻止特定政府、金融、新聞、通信或安全服務 |
| 人員辨識 | 找出軍政、公務、承包商、科技、記者及社運相關使用者 |
| 社會圖譜 | 依共同時間、目的地及帳號活動推測組織與人際關係 |
| 危機啟用 | 平時蒐集，戰時進行定向阻斷、誤導或帳號分類 |

### 3.3 不能忽略應用程式權限

VPN應用程式若要求以下權限，應說明其必要性：

- 聯絡人
- 精確位置
- 相簿及檔案
- 麥克風
- 輔助使用權限
- 裝置管理員
- 安裝未知應用程式
- 根憑證或本機CA

單純VPN服務通常不需要大量與通信隧道無關的個人資料權限。

## 四、eSIM與旅遊eSIM風險

### 4.1 eSIM協定本身

GSMA的eSIM架構允許營運商設定檔安全下載至裝置中的eUICC。其生態通常包含：

- 使用者裝置
- eUICC安全元件
- 本機設定檔助理
- SM-DP+設定檔伺服器
- eSIM銷售或轉售平台
- 上游行動網路營運商
- 漫遊與核心網路

eSIM本身不代表比實體SIM更容易洩密；兩者都需要電信商處理訂閱識別、基地台、位置、流量與漫遊資料。

### 4.2 旅遊eSIM的額外信任鏈

許多旅遊eSIM品牌是轉售商，實際鏈路可能是：

```text
使用者手機
→ 當地基地台
→ 當地合作電信商
→ 漫遊樞紐或上游核心網路
→ eSIM批發商或平台
→ 網際網路出口
```

因此需要知道：

- 真正的電信訂閱由誰發行
- 流量在哪一國家或地區離開行動核心網路
- 是否使用永久漫遊
- 上游是否能看到使用者長期位置及裝置識別
- App是否另行蒐集分析、廣告或身分資料

### 4.3 eSIM最壞情況

| 風險面向 | 最壞情境 |
|---|---|
| SM-DP+或設定檔平台被控制 | 錯誤配置、帳號接管、服務中斷或使用者分類 |
| 上游電信商不透明 | 流量經過未預期法域、核心網路或資料處理者 |
| 位置與移動 | 形成跨國行程、基地台活動及出差規律 |
| 裝置識別 | 將eSIM識別、裝置、付款及帳號綁定 |
| 應用程式權限 | 額外取得位置、廣告識別、裝置資訊或聯絡資料 |
| 危機停用 | 特定國家、群組、職業或方案突然失去通信 |
| 人員圖譜 | 依同時出現位置、旅程與流量模式判斷團隊關係 |

### 4.4 GSMA安全分析的限制

GSMA在2024年對相關研究的說明指出，在端點誠實且未遭控制時，消費者遠端SIM配置協定具有充分防護；相關高風險研究情境通常假設SM-DP+或eUICC等端點已遭入侵或控制。

因此真正要問的不是只有「eSIM協定是否安全」，而是：

> 誰控制合法端點、設定檔、簽章、更新、核心網路、使用者資料與停用權限？

---

## 五、同一集團控制VPN與eSIM的資料融合風險

最壞情況不是單一產品，而是同一實際控制者或資料合作網絡同時掌握：

```text
真實身分及付款
＋
eSIM／SIM訂閱識別
＋
基地台及移動位置
＋
VPN來源IP及出口IP
＋
DNS、目的地及流量型態
＋
裝置識別及應用程式分析
```

### 5.1 可推導的情報價值

即使不能直接讀取端對端加密內容，仍可能推導：

- 使用者在哪裡、何時上線
- 是否在政府、軍事、科技或媒體場所附近活動
- 是否與其他人同時移動或連線
- 是否固定連接政府、企業、雲端或新聞服務
- 出差、值班、演習或會議時間
- 某一敏感帳號的使用者真實身分
- 危機時哪些人仍保持通信

### 5.2 與廣告科技及資料經紀商結合

若同一集團還控制或合作於：

- 廣告SDK
- 裝置分析
- 身分驗證
- 電子郵件
- 雲端儲存
- 付款平台
- 旅遊及訂房

可進一步把網路中繼資料與現實身分、位置及社群關係合併。

## 六、便宜價格是否構成證據

### 6.1 合理的低價來源

- 批發採購大量行動數據
- 創投或市場擴張補貼
- 只提供數據、不含電話及簡訊
- 使用成本較低的漫遊或核心網路
- 流量到期未使用
- 客服及實體門市成本低
- 短期促銷或交叉銷售

### 6.2 高風險組合

低價只有在與以下因素組合時，才應提高調查層級：

- 找不到最終受益人
- 公司頻繁改名或轉移法域
- 不公開上游電信商
- 不說明資料保存地與期限
- VPN無日誌聲明未經獨立驗證
- eSIM路由及出口國異常
- 強制側載APK或安裝根憑證
- App要求大量非必要權限
- 更新簽章及開發團隊不透明
- 與中國國企、軍工、國安或高風險資料平台存在控制關係
- 針對軍公教、國防承包商、記者、學生、科技人員提供長期免費方案

### 6.3 分析結論

> **異常低價是商業與安全盡職調查的觸發點，不是間諜活動的定罪證據。**

## 七、個人、企業及政府風險分級

| 使用情境 | 中繼資料風險 | 內容風險 | 整體判斷 |
|---|---:|---:|---|
| 透明可信本地電信商eSIM＋HTTPS | 中 | 低 | 一般電信風險 |
| 所有權及上游不透明的旅遊eSIM | 中高 | 低至中 | 需查路由與法域 |
| 所有權及日誌不透明的VPN | 高 | 低至中 | 信任轉移給VPN業者 |
| 同一控制方提供VPN＋eSIM | 極高 | 中 | 可進行多端流量關聯 |
| 要求根憑證、側載或高權限 | 極高 | 高 | 重大供應鏈風險 |
| 軍政人員以消費型服務處理公務 | 極高 | 極高 | 不應允許 |

## 八、反制方針

### 8.1 一般使用者

- 查明公司及母公司
- 查詢實際上游電信商
- 避免來源不明免費VPN
- 不安裝不明根憑證
- 不側載不明VPN或eSIM App
- 關閉非必要權限
- 使用端對端加密通信
- 政府及金融帳號使用通行金鑰或硬體安全金鑰
- 將敏感工作與私人旅遊設備分開

### 8.2 企業

- 建立VPN、eSIM及電信商白名單
- 禁止員工使用未核准公共VPN處理公司資料
- 使用企業自建或經評估的零信任存取
- MDM限制設定檔、VPN及根憑證
- 監控流量出口國及路由異常
- 審查最終受益人與資料法域
- 對供應商要求獨立安全、隱私及日誌稽核
- 準備供應商撤換及憑證撤銷程序

### 8.3 軍政及關鍵基礎設施

- 公務設備不得使用未核准旅遊eSIM與消費型VPN
- 將VPN、eSIM、漫遊、SM-DP+及核心網路納入供應鏈安全
- 禁止單一供應商同時控制身分、通信、VPN、資料分析及裝置管理
- 要求資料在可信法域儲存與處理
- 要求可驗證的更新簽章及建置流程
- 監測eSIM與VPN流量出口、DNS及控制面
- 建立危機時快速撤銷設定檔、帳號及憑證的能力
- 準備替代電信商、衛星及緊急通信
- 對高敏感人員進行通信安全教育及異常接觸通報

## 九、經濟下行是否會促使中共以戰爭轉移民怨

### 9.1 核心結論

> **可能增加外部危機的政治誘因，但經濟越差並不代表全面侵臺機率必然越高。**

截至2026年7月，世界銀行預估中國2026年成長約4.4%、2027年約4.3%，主要風險包括內需偏弱、房地產調整及消費者謹慎；IMF在2026年7月更新中預估中國2026年成長約4.6%。這反映經濟放緩及結構性壓力，但不等於經濟已崩潰或民怨已達戰爭觸發點。

### 9.2 戰爭或外部危機的短期政治功能

外部危機可能：

- 將經濟問題改寫為外國圍堵
- 強化民族主義及政權保衛者形象
- 合法化審查、出境、金融與社會控制
- 壓縮反對及政策批評
- 把不滿者描述為受外國影響
- 短期產生「團結在旗幟下」效果

威權政府具備較強的媒體、審查與組織動員能力，可能延長短期凝聚效果。

### 9.3 為何全面侵臺可能反而放大民怨

全面戰爭可能造成：

- 出口及供應鏈中斷
- 能源與原料成本上升
- 金融制裁、資本及外匯管制
- 青年動員與軍人傷亡
- 沿海製造、港口及城市經濟停滯
- 海外資產凍結
- 房地產及地方財政進一步惡化
- 軍事失敗直接歸責最高領導層

因此只有在領導層認為能快速、低成本取勝，或認為不行動的政權風險更高時，全面戰爭才可能成為轉移壓力工具。

## 十、經濟與政治組合的風險矩陣

| 中國內部情境 | 灰色地帶／軍演 | 準封鎖或有限危機 | 全面侵臺 |
|---|---:|---:|---:|
| 經濟放緩、政權穩定 | 上升 | 小幅上升 | 變化有限 |
| 經濟下行、民怨增加 | 高 | 中 | 低至中 |
| 經濟下行、黨內權力衝突 | 極高示威風險 | 中高 | 短期可能下降 |
| 民怨高、黨軍清洗未完成 | 高 | 高 | 因指揮信任下降而下修 |
| 民怨高、清洗完成、軍隊可信 | 極高 | 高 | 顯著上升 |
| 民怨高、美日臺明顯分裂 | 極高 | 極高 | 上升 |
| 接近金融危機 | 宣傳及控制極高 | 不確定 | 可能因無力承戰下降，也可能因誤判上升 |

## 十一、較可能的轉移民怨升級順序

在最壞但仍具可控性的情況下，較可能依序為：

1. 強化外國敵對與民族復興宣傳
2. 加強網路審查、出境與資本限制
3. 對臺經濟、外交、法律與認知壓力
4. 大型環臺軍演與海警執法
5. 短期航運檢查、海關式隔離或準封鎖
6. 網攻、海纜、金融、通信平台與內應同步測試
7. 有限外離島或精準軍事危機
8. 僅在認為能快速取勝且盟國不會有效介入時，考慮全面升級

這一路徑能取得民族主義與緊急動員效果，同時保留撤回及談判空間。

## 十二、真正危險的組合

經濟下行本身不是最強預警。較危險的是以下條件同步：

- 房地產、地方財政、就業及消費信心惡化
- 大規模抗議或公共服務下降
- 黨內權力、接班或合法性壓力
- 解放軍清洗完成並重新集中指揮
- 領導層相信可快速取勝
- 美國、日本、韓國、菲律賓、澳洲及臺灣明顯分裂
- 能源、糧食、金融與跨境支付進入反制裁準備
- 出境、外匯、VPN、國際網路與外企活動同步收緊
- 宣傳由和平統一轉向犧牲、長期戰爭與戰爭不可避免
- 民用運輸、醫療、通信、港口及工業正式轉入軍事優先
- 由中國控制或可影響的VPN、eSIM、雲端與通信平台進入定向監測或阻斷狀態

## 十三、新增第37至40項預警

### 第37項：戰略收購VPN、eSIM與跨境通信平台

追蹤：

- 最終受益人及併購資金來源
- 董事會、否決權與技術控制
- 上游電信商及核心網路
- SM-DP+、VPN控制面與資料中心所在地
- 更新簽章與軟體開發者
- 與中國國企、軍工、國安或高風險資料公司的關係
- 是否收購多個看似獨立品牌

### 第38項：異常低價通信服務滲透敏感族群

追蹤是否長期針對：

- 軍公教及其家屬
- 國防及政府承包商
- 大學生與研究生
- 記者、政治人物及助理
- 半導體、電信、能源及資安工程師
- 海外商務及外交人員

提供遠低於成本、長期免費或綁定身分驗證的VPN、eSIM與雲端服務。

### 第39項：VPN與eSIM流量關聯能力

高風險條件：

- 同一實際控制人
- 共用帳號或付款平台
- 共用裝置識別及分析SDK
- VPN及行動核心網路日誌可交叉
- 流量出口集中於相同資料中心或法域
- 可依職業、位置及政府網域分類使用者

### 第40項：經濟民怨與對外軍事敘事同步

追蹤：

- 經濟成長、消費、失業及房地產
- 地方財政與公共服務
- 抗議、群體事件及網路審查
- 戰爭與犧牲宣傳
- 出境、外匯及資本限制
- 民用交通、醫療及工業動員
- 對臺軍演、海警及封鎖演練
- VPN、eSIM及國際通信收緊

## 十四、第37至40項危機分級

| 指標 | 綠色 | 黃色 | 橙色 | 紅色 |
|---|---|---|---|---|
| 37 通信平台收購 | 一般商業投資 | 所有權不透明 | 控制權集中、路由及資料跨境 | 與國安、軍工或危機任務可驗證關聯 |
| 38 異常低價滲透 | 一般促銷 | 長期補貼且對象集中 | 針對敏感族群並要求高權限 | 危機時定向停用、更新或資料啟用 |
| 39 VPN＋eSIM關聯 | 不同公司無共享 | 共用帳號或SDK | 同一集團及日誌可交叉 | 與政府、軍事或內應任務同步使用 |
| 40 經濟民怨軍事化 | 經濟放緩 | 宣傳與管制升高 | 軍民動員及封鎖演練同步 | 不可逆動員、部隊不撤回及通信控制 |

## 十五、文件應用方式

### 15.1 每季供應鏈安全審查

- 新收購及股權變更
- VPN及eSIM熱門品牌
- 上游電信商與路由變化
- App權限及更新簽章
- 獨立稽核與資料保存政策
- 政府、軍方與關鍵產業使用比例

### 15.2 危機期間每日追蹤

- VPN及eSIM是否出現定向中斷
- 流量是否改道至異常國家
- App是否要求緊急更新或新增權限
- 政府及媒體網域是否被選擇性阻斷
- 中國是否同步限制國際網路、出境及資本
- 經濟民怨宣傳是否轉為戰爭動員

## 十六、最終判斷

### VPN與eSIM

> 若VPN或eSIM由不透明且受敵對國家實際控制的企業持有，最直接、最可信的風險是身分、位置、裝置、付款及流量中繼資料的集中與關聯；並可能在危機時形成選擇性阻斷、定向更新、使用者分類或通信降級能力。

這不等於所有中國資本持有的通信公司都從事間諜活動。政策應以控制權、技術證據、資料流向、權限及法域進行風險管理，而不是依國籍或價格進行推定。

### 經濟與民怨

> 經濟下行與民怨可能提升民族主義、軍演、灰色地帶、準封鎖及有限軍事危機的誘因，但全面侵臺同時可能引發制裁、傷亡及政權責任，因此不是自動或低成本的轉移工具。

當經濟壓力與黨軍指揮重整、反制裁準備、廣泛社會控制、盟國分裂、民用動員、間諜啟用及通信平台控制同步時，才應把「以外部戰爭壓制內部壓力」上調為高風險情境。
