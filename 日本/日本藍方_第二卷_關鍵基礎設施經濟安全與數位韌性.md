# 日本藍方｜第二卷：關鍵基礎設施、經濟安全與數位韌性

> **文件定位**
>
> 本卷把日本視為一個相互依賴的國家系統，而不是一組彼此獨立的設施。公開版只列功能、依賴、備援與復原原則；具體節點、弱點、位置與修復優先序應放入受限清冊。

## 0. 本卷目的

核心問題是：

> 海纜、能源、港口、金融、電信、雲端、交通或關鍵製造任何一項失效時，是否會透過相依關係造成跨領域連鎖崩潰？

日本2023年度能源自給率約15.3%，能源、原料、食品與工業供應高度依賴海外運輸；日本的經濟安全保障制度也已把重要物資、基幹基礎設施、重要技術及專利保護納入國家政策。[S10][S12]

---

## 1. 九項防護原則

1. **知道資產**：建立完整清冊。
2. **知道依賴**：畫出電力、通信、燃料、人員與供應商關係。
3. **知道時間**：設定最大可容忍中斷時間。
4. **知道最低功能**：定義降級服務。
5. **知道替代者**：準備備援節點與人員。
6. **知道如何修復**：備妥零件、工具與工程師。
7. **知道誰有權限**：管理內部與承包商。
8. **知道資料是否可信**：重建前先驗證。
9. **知道如何對民眾說明**：避免資訊真空。

## 2. 1：1受限資產清冊

| 欄位 | 說明 |
|---|---|
| 資產編號 | 使用內部編號，避免公開名稱成為唯一識別 |
| 國家功能 | 維持行政、軍事、金融、醫療或民生何種能力 |
| 主管與營運者 | 中央、地方、民間或合資 |
| 替代節點 | 主要節點失效時的接替方式 |
| 上游依賴 | 電力、通信、燃料、雲端、人員、原料 |
| 下游影響 | 哪些服務會因其失效而中斷 |
| MTPD | 最大可容忍中斷時間 |
| MBCO | 最低可接受運作能力 |
| RTO | 目標復原時間 |
| RPO | 可容忍資料損失 |
| 人工模式 | 數位失效時的程序 |
| 權限清冊 | 員工、供應商與遠端維護權限 |
| 備件與修復 | 零件、工程師、車輛與工具 |
| 外部支援 | 國內互援、國際原廠與友盟 |
| 最近演練 | 是否真正切換備援 |
| 缺口狀態 | 未處理、處理中、已驗證 |

## 3. 海底電纜與國際通信

### 3.1 功能盤點

- 國際網際網路
- 雲端服務
- 金融交易
- 外交與政府通信
- 企業跨境營運
- 新聞與資訊查證
- 島嶼通信
- 科研資料交換

### 3.2 藍方要求

- 多路由與多登陸區
- 即時異常監控
- 海纜維修協議
- 維修船與零件安排
- 衛星與微波備援
- 關鍵流量分級
- 國內核心服務本地化
- 與國際營運商共同演練

### 3.3 中斷時流量優先順序

**第一級**

- 國家指揮
- 自衛隊與警政
- 電力、電信、水務
- 醫療急救
- 外交安全通信

**第二級**

- 金融清算
- 港口機場
- 物流與能源
- 公共廣播
- 關鍵製造

**第三級**

- 一般影音
- 非必要更新
- 大型娛樂流量

### 3.4 海纜事件判斷

不得因單次事故立即歸責。應整合：

- 船舶動態
- 海象
- 錨泊與施工紀錄
- 纜線故障型態
- 網路攻擊時間
- 社群假訊息
- 相關公司與船舶控制權

## 4. 國內通信與離島連結

### 4.1 多層通信

- 固定光纖
- 行動網路
- 衛星
- 微波
- 防災行政無線
- 業餘與專業無線電
- 公務專網
- 可攜基地台

### 4.2 基地台持續運作

每個關鍵區域要盤點：

- 備用電力時間
- 燃料補給
- 回傳線路
- 備件
- 搶修人員
- 交通可達性
- 可攜設備
- 優先用戶與流量限制

### 4.3 地區與離島差異

- 北海道偏遠地區
- 日本海沿岸
- 沖繩與先島諸島
- 山區與災害易斷區
- 大都市高密度區

不得假設同一套備援可適用全部區域。

## 5. 政府數位信任

### 5.1 信任基礎

- 政府憑證
- 電子簽章
- 網域與DNS
- 時間同步
- 高階帳號
- 緊急警報
- 身分驗證
- 憑證撤銷

### 5.2 全國警報

J-ALERT透過衛星與地面線路將飛彈、地震、海嘯等緊急資訊傳送至地方與民眾。[S11]

藍方應演練：

- 假J-ALERT截圖
- 部分地方未收到警報
- 警報內容被冒用
- 手機警報與廣播內容不一致
- 真警報遭社群宣稱為假
- 地方設備故障

### 5.3 離線驗證

在網路不穩時，民眾仍應能透過：

- 公共廣播
- 地方防災無線
- 預先公布的官方頻率
- 實體公告點
- 統一驗證碼
- 地方政府與警消

確認訊息真偽。

## 6. 雲端、資料中心與備份

### 6.1 常見錯誤

- 主系統與備份使用同一帳號
- 備份長期連線
- 未驗證備份完整性
- 異地中心依賴同一電力或電信
- 境外雲端失聯時無本地替代
- 資料恢復後未確認是否遭污染

### 6.2 可信復原程序

1. 隔離受影響系統。
2. 建立乾淨管理環境。
3. 重發密鑰與高權限帳號。
4. 驗證映像與軟體來源。
5. 比對資料完整性。
6. 分階段恢復。
7. 監控潛伏行為。
8. 由第三方或跨單位覆核。

## 7. 重要基礎設施網路安全

日本2025年更新重要基礎設施資安行動計畫，強調風險管理、跨部門合作與事件應變。[S8][S9]

### 7.1 組織要求

- 董事會與高階主管負責
- IT與OT共同治理
- 法務、營運、公關與資安聯動
- 供應商風險管理
- 事件通報
- 國內外情資共享
- 定期壓力測試

### 7.2 工控安全

- 行政網與工控網隔離
- 遠端維護預設關閉
- 多人批准
- 操作白名單
- 實體安全
- 備用控制站
- 人工操作手冊
- 工程變更紀錄

## 8. 能源供應鏈

### 8.1 完整鏈條

> 海上進口 → 港口卸載 → 儲存 → 發電與煉製 → 輸電輸氣 → 配送 → 維修

### 8.2 日本能源風險

日本能源自給率低，且能源需求受資料中心與半導體工廠等新需求推升。[S10]

### 8.3 藍方措施

- 來源多元化
- 石油與LNG儲備
- 戰略性餘裕LNG
- 替代卸載港
- 優先配給
- 省能與需求管理
- 區域互援
- 分散式電源
- 重要設備備件
- 燃料運輸保護

### 8.4 優先用電

1. 國家指揮及通信
2. 醫療與救援
3. 水務與污水
4. 金融清算
5. 港口、機場及物流
6. 關鍵製造
7. 民生基本用電
8. 非必要商業與娛樂

## 9. 核能與大型能源設施

藍方不只要防止事故，也要避免假事故訊息造成恐慌。

應準備：

- 安全停機
- 備用冷卻與電源
- 環境監測
- 多機關共同發布
- 輻射數據公開
- 假疏散命令查證
- 地方政府與營運者同步
- 醫療與避難規劃

## 10. 水資源與污水

### 10.1 防護項目

- 取水
- 淨水
- 泵站
- 配水
- 污水
- 化學藥劑
- 水質監測
- 電力及通信
- 搶修

### 10.2 假污染消息

水質謠言可能造成：

- 瓶裝水搶購
- 道路與零售壅塞
- 醫療壓力
- 對政府不信任

藍方需以多點檢測、公開數據與地方廣播快速處置。

## 11. 港口、機場與公共基礎設施

日本依國家安全保障戰略推動自衛隊與海上保安廳可平時訓練、災害應變及有事運用的公共港口與機場整備。[S4][S5]

### 11.1 藍方治理

- 軍民流量排序
- 地方政府參與
- 承包商資安
- 人工作業能力
- 替代節點
- 危險物管理
- 搶修資源
- 對居民透明說明

### 11.2 港口降級模式

- 只處理能源、醫療、食品與國防物資
- 紙本或離線報關
- 人工貨櫃定位
- 簡化檢疫
- 小型分散卸載
- 替代道路與鐵路

## 12. 鐵路、道路與國內物流

### 12.1 重要功能

- 居民避難
- 軍事運輸
- 醫療後送
- 能源配送
- 食品與藥物
- 工程搶修
- 跨地方互援

### 12.2 物流韌性

- 區域分散倉儲
- 多家運輸業者
- 郵政與超商協作
- 司機與燃料保障
- 道路清障
- 不依賴單一排程系統
- 低科技備援

## 13. 金融與支付

### 13.1 最低功能

- 核心清算
- 政府支付
- 醫療與能源交易
- ATM
- 現金調度
- 商戶離線或低頻寬支付
- 國際金融通信

### 13.2 信心危機應變

情境：

- 假銀行倒閉
- 假資本管制
- 假存款凍結
- ATM排隊
- 行動銀行延遲
- 官方帳號遭冒用

應由央行、金融監管、主要銀行與警察建立共同事實頁面與定時簡報。

## 14. 經濟安全與重要物資

日本經濟安全保障政策涵蓋供應鏈、基幹基礎設施、重要技術及專利等支柱。[S12]

### 14.1 重要物資盤點

- 半導體
- 電池
- 永久磁石
- 關鍵礦物
- 抗菌藥物
- 肥料
- 船舶與航空零件
- 雲端與通信設備
- 能源設備
- 工業氣體

### 14.2 每項物資應記錄

- 國內庫存
- 進口來源
- 運輸時間
- 替代供應商
- 可替代規格
- 使用優先順序
- 擴產時間
- 相關人才與設備

## 17. 跨領域相依性地圖

應至少繪製：

- 電力 → 電信 → 金融
- 電力 → 水務 → 醫療
- 港口 → 能源 → 電力
- 雲端 → 政府 → 地方
- 交通 → 物流 → 糧食
- 衛星 → 導航 → 海空運輸
- 資料中心 → 清算 → 商業
- 人員 → 維修 → 復原
