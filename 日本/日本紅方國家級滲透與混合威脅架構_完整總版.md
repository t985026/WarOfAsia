## 一、戰略目的

紅方在日本的平時目標，通常不是要求所有日本人支持特定外國，而是降低日本在危機中的政策一致性、保密能力、同盟互信與社會動員速度。

- 增加內閣、國會、地方政府與產業之間的決策摩擦。
- 讓日美同盟議題被轉化為純粹的國內政黨與地方衝突。
- 使日本企業因市場、供應鏈與觀光利益而反對部分安全政策。
- 削弱日本對外國虛假資訊、科技外流與境外代理關係的辨識能力。
- 在危機前建立可被迅速放大的爭議、人物關係、媒體節點與社群敘事。

> 紅方的最佳結果不是公開控制日本政治，而是讓日本在最需要快速決策時自行延遲。


## 二、國家級紅方生態系

日本紅方不應被想像成單一情報機關，而可能是一個由國家、企業、研究、媒體、犯罪與第三國服務交疊構成的分散式生態系。

| 層級 | 可能功能 | 藍方觀察重點 |
|---|---|---|
| 戰略指揮 | 決定政策、軍事、科技、經濟及認知需求 | 需求是否跨領域同步 |
| 資金與掩護 | 透過公司、協會、研究、活動或顧問關係提供合法外觀 | 最終受益人與出資者是否透明 |
| 接觸網絡 | 建立政界、地方、產業、學術與媒體接觸面 | 接觸是否逐步超出正常活動範圍 |
| 數位基礎 | 帳號、設備、雲端、社群與資料分析能力 | 同一組基礎設施是否跨案件重複出現 |
| 任務執行 | 情報蒐集、影響、經濟脅迫、技術取得或危機回報 | 報酬是否與工作內容不相稱 |
| 切割復原 | 節點遭查後迅速更換公司、帳號或中介者 | 替代節點是否立即接手 |


## 三、政治與中央行政影響面

日本中央政府的安全決策涉及首相官邸、內閣官房、外務、防衛、經產、總務、國交、警察與地方政府。紅方可能尋找的不是單一『親外人士』，而是能延遲跨部會整合的程序性弱點。

- 政策草案、會議時程、內部爭議與利益相關者立場。
- 政治人物秘書、政策顧問、前官員與外部研究機構。
- 國會質詢、委員會安排、地方陳情與產業遊說的交叉點。
- 危機時各部會對資訊揭露、風險承擔與美軍支援的不同偏好。
- 政府採購、委外調查、翻譯、系統維護與活動承辦等非核心入口。


## 四、地方自治、沖繩與基地政治

日本47個都道府縣及大量市町村擁有高度行政與地方政治影響力。沖繩及西南諸島又同時承擔居民生活、觀光、地方自治、基地負擔與國家安全壓力。

| 風險面 | 紅方可能追求的效果 | 防禦界線 |
|---|---|---|
| 基地負擔 | 放大中央與地方的不信任 | 合法抗議與外國秘密操控必須區分 |
| 港口機場使用 | 使地方反對任何安全用途 | 應透明說明災防與安全雙重用途 |
| 居民疏散 | 放大成本、恐慌與不公平感 | 規劃需納入居民、弱勢與觀光客 |
| 地方交流 | 建立長期人脈及政策接觸面 | 交流本身不等於滲透 |
| 地方財政 | 利用觀光、投資與補助依賴影響政策 | 需揭露實際控制人與條件 |


## 五、社團、商會、文化與友好交流

地方友好城市、商會、文化協會、學校交流、觀光推廣與研究活動大多屬正常國際交流，但也可能被外國行為者用作人物盤點、關係養成或議題輸送的合法外觀。

- 活動資金是否由多層第三方代付。
- 受邀者是否被要求提供非公開人員、政策或產業資訊。
- 交流是否逐步轉為個別化、高報酬或保密接觸。
- 主辦單位是否拒絕揭露最終出資者與合作機構。
- 同一批中介者是否同時接觸政治、軍事與科技人員。


## 六、媒體、出版、廣告與內容供應鏈

影響作戰不只依靠假帳號，也可能透過內容採購、節目置入、評論供稿、翻譯、第三國媒體與廣告投放建立可信外觀。

- 以真實社會問題為基礎，刪除背景並加入誇大因果。
- 讓日本社會相信所有安全政策都只是美國要求。
- 同時向美國受眾宣稱日本缺乏承擔風險的意願。
- 利用災害、物價、基地事故或外交摩擦快速切換敘事。
- 把對虛假資訊的查核描述為壓制言論，以阻礙平台處置。


## 七、社群平台、AI與受眾分析

現代認知作戰的核心是受眾分群、協同行為與議題時機，而不只是大量貼文。

| 能力 | 可能用途 | 藍方觀察 |
|---|---|---|
| 受眾分群 | 依地區、年齡、政治傾向與議題焦慮投放不同敘事 | 同一事件是否出現互相矛盾但同源內容 |
| AI生成 | 快速產生日文、地方用語、圖像與影音 | 內容是否有重複模板或異常發布節奏 |
| 帳號養成 | 先經營娛樂、災害或生活內容，再轉向政治 | 帳號控制權與內容主題是否突然改變 |
| 深偽 | 冒充首相、地方首長、企業或美軍人員 | 建立官方快速驗證與多管道確認 |
| 第三國洗稿 | 讓敘事看似來自非中國來源 | 追蹤原始訊息與資金鏈 |


## 八、經濟關係與企業政策壓力

紅方可利用市場、投資、觀光、供應鏈與在外資產，使企業將國家安全政策視為商業損失來源。

- 對特定企業採取選擇性行政、通關、消費抵制或市場限制。
- 透過地方投資與就業形成政策依賴。
- 讓產業公協會在危機中要求政府降低同盟或臺海承諾。
- 以併購、合資、共同研究或人才延攬取得關鍵資訊。
- 利用第三國公司降低真正委託者的可見度。


## 九、學術、研究與關鍵人才

日本在材料、精密機械、半導體、機器人、量子、AI、航太與海事等領域具有高價值能力。風險常出現在未揭露關係與資料存取，而不是國籍本身。

- 未申報境外資金、雙重聘任或實際研究合作方。
- 研究資料大量下載、非必要樣本取得與實驗設備接觸。
- 透過研討會、人才計畫、獵才或顧問案接觸核心工程師。
- 以正常合作取得研發失敗紀錄、良率問題與供應商資訊。
- 離職、退休與海外派駐人員的資料權限未及時撤除。


## 十、犯罪、詐騙與地下服務

國家級行為者可能利用既有犯罪市場提供身分、金流、假公司、設備、勒索與代理人服務，但公開證據通常不足以證明所有犯罪均受國家直接指揮。

- 地下匯兌、虛擬資產與人頭帳戶提供隱蔽支付。
- 詐騙或資料外洩產生可用於勒索與人物分析的資料。
- 私家調查、跟監、恐嚇或債務服務被用於施壓。
- 假招聘、假投資與假商務接觸建立人物入口。
- 犯罪外觀可降低國家歸責速度。


## 十一、平時滲透成熟度

藍方可用成熟度模型判斷零散活動是否逐漸形成國家級網絡。

| 級別 | 狀態 | 主要指標 |
|---|---|---|
| L1 | 公開交流 | 活動及資金透明 |
| L2 | 人物盤點 | 持續收集人脈、政策與產業資訊 |
| L3 | 隱蔽資助 | 第三方付款、未揭露委託或高額報酬 |
| L4 | 多域連結 | 政治、媒體、產業與學術節點開始重疊 |
| L5 | 任務化 | 出現保密要求、指定情報需求或危機回報 |
| L6 | 危機可啟用 | 具資金、帳號、人員與替代節點，可同步行動 |


## 十二、藍方防禦提示

防禦重點是透明、權限、金流與行為，而不是思想與族群。

- 建立外國資金與實際委託者揭露制度。
- 對敏感職位、研究與供應商採取風險分級。
- 提供被脅迫者主動通報及減責機制。
- 讓媒體與平台能查核資金、帳號控制與協同行為。
- 避免政治化執法與對華人社群的集體懷疑。

## 一、軍事終局

日本紅方的現實軍事終局，可能不是全面占領日本列島，而是讓日本無法或不願有效支援日美聯合作戰與臺海周邊行動。

- 提高使用駐日美軍與自衛隊設施的政治成本。
- 使西南諸島的通信、運輸與居民保護承受長期壓力。
- 讓日本政府在『避免戰爭』與『維持同盟』之間延遲決策。
- 使商業航運、航空與保險市場自行降低日本前沿地區運力。
- 透過多方向牽制分散自衛隊、海上保安廳與美軍注意力。


## 二、東海灰色地帶層次

紅方可能以軍隊、海警、公務船、民用船、無人系統、法律敘事與資訊作戰構成多層壓力，使每一事件都低於全面戰爭門檻。

| 層次 | 功能 | 可能效果 |
|---|---|---|
| 法律與行政敘事 | 把爭議海域描述成正常執法範圍 | 降低外界對軍事脅迫的敏感度 |
| 海警與公務船 | 持續存在、追蹤、廣播與接近 | 消耗海上保安廳資源 |
| 海空軍力 | 提供後方威懾與快速升級能力 | 迫使日本保持高戒備 |
| 無人系統 | 增加監視、辨識與應變負擔 | 提高誤判與疲勞 |
| 認知作戰 | 把日本反應描述為挑釁 | 分化國內與國際輿論 |


## 三、西南諸島鏈式隔離

沖繩及西南諸島不是單一基地問題，而是居民、地方政府、港口機場、通信、醫療、觀光、能源與軍事後勤的複合系統。

- 島際交通與補給受限時，民生與軍事需求可能互相競爭。
- 通信降級可能讓各島看到不同版本的情勢。
- 疏散計畫若不透明，可能被敘事操作成放棄居民。
- 地方政府與中央對設施使用、風險揭露與居民保護可能有不同優先順序。
- 商業航運或航空公司可能因保險與安全考量先行縮減運能。


## 四、特定利用空港與港灣

日本已建立讓自衛隊與海上保安廳平時訓練、災害應變及有事展開更順暢的公共基礎設施框架。紅方因此會把地方協調、承包商、運輸與公共輿論納入情報模型。

- 民用設施的軍民雙重用途會增加政治爭議與資訊價值。
- 設施本身之外，還要關注油料、裝卸、交通聯外、資訊系統及維修。
- 地方反對不等於滲透，但未揭露的外國資助與協同操控需要調查。
- 紅方可能利用公共資訊推估運量、擴建進度及管理分工。
- 藍方應以功能韌性而非單一設施防護為核心。


## 五、日美同盟分離模型

紅方不必打敗日美聯軍，只要使日本與美國在危機的時間、基地使用、情報共享、風險承擔與對外訊息上產生落差。

| 裂縫 | 紅方敘事 | 可能後果 |
|---|---|---|
| 介入時機 | 美國會先行升高衝突，日本將被迫捲入 | 日本延遲批准支援 |
| 基地使用 | 日本承擔風險，美國保留決策自由 | 地方與中央政治衝突 |
| 情報共享 | 日本系統不安全或美國隱瞞風險 | 降低共同情勢圖可信度 |
| 平民傷亡 | 美軍活動使日本民眾成為目標 | 社會要求限制同盟活動 |
| 經濟代價 | 支援臺海將犧牲日本企業與能源安全 | 產業向政府施壓 |


## 六、基地與戰力保存的功能型分析

公開紅隊研究只能列出功能類型，不應逐一列出特定基地弱點、位置或優先序。

- 指揮與通信功能。
- 航空、海上與地面兵力的分散與再生。
- 油料、彈藥、備件與維修。
- 跑道、港勤、交通與醫療後送。
- 防空、防無人機、電磁與網路防護。
- 自衛隊、美軍、海上保安廳與民間承包商協同。


## 七、海底電纜、衛星與定位授時

日本作為島國，國際通信、金融與雲端高度依賴海底電纜，同時離島、船舶、航空與軍事活動依賴衛星與精確授時。

- 單點故障不等於國家隔離，真正風險是多層通信同時降級。
- 海纜異常與網路攻擊疊加，可能放大資訊真空。
- 定位與授時受干擾時，航運、航空、電網、金融與軍事可能同步承壓。
- 離島的替代通信容量通常低於平時需求。
- 歸責模糊可能使政府在事故、犯罪與國家行動之間延遲判斷。


## 八、海空交通線與商業自我封鎖

紅方未必需要正式宣布封鎖，只要提高航運、航空與保險業者的風險預期，就可能造成部分自我避險。

- 大規模演訓、警告區域與航路調整提高營運成本。
- 保險費、船員安全與港口排程可能先於政府命令改變。
- 觀光、貨運、能源與離島補給承受不同程度影響。
- 企業可能要求日本政府限制軍事支援以恢復正常商業。
- 此類效果可在未實際攔截所有船舶前形成。


## 九、多方向牽制

日本不能只面對西南方向。最壞情境會同時出現東海、日本海、北海道、網路、飛彈與海上安全壓力。

| 方向 | 可能壓力 | 戰略效果 |
|---|---|---|
| 西南 | 東海、離島與臺海外溢 | 牽制海空與快速部署能力 |
| 日本海 | 北韓飛彈、海空活動與網路威脅 | 增加預警與民防負擔 |
| 北海道 | 俄羅斯軍事活動與北方警戒 | 分散資源與政治注意力 |
| 本土網路 | 政府、金融、交通與媒體異常 | 削弱共同情勢圖 |
| 太空電磁 | 衛星、定位與通信不穩 | 提高跨域協同難度 |

> 多方向同時承壓不代表存在統一指揮；需用通聯、時間、技術與情報證據驗證。


## 十、模型化作戰與任務預演

成熟紅方會把地理、設施功能、道路、通信、兵力反應與地方治理轉化成可重複測試的問題。

- 實體訓練場與相似城市、島嶼、港口或機場環境。
- 數位地形、兵棋、模擬器與專業假想敵。
- 通信受干擾、錯誤情報與補給中斷條件。
- 跨軍種、海警、網路、電子與信息行動協同。
- 演練後以時間、損耗、錯誤與指揮延遲更新模型。

> 公開資料不足以證明紅方已建立日本所有設施的完整數位孿生；文件僅將其列為B至C級風險。


## 十一、災害與軍事壓力疊加

日本的大型自然災害可能自然造成通信、交通、能源與地方治理中斷。紅方最危險的選擇是利用災後資訊真空，而非必然製造災害。

- 災後加入假消息、網攻或外交軍事壓力。
- 利用真假故障混合，使政府難以歸責。
- 讓救援與軍事運輸爭奪港口、道路與燃料。
- 冒充官方發布錯誤避難、海嘯或交通訊息。
- 宣稱中央政府偏袒特定地區，破壞地方信任。


## 十二、軍事複合效果六層模型

軍事壓迫可被分解成六個高階效果層。

| 效果層 | 目的 | 防禦問題 |
|---|---|---|
| 感知剝奪 | 降低雷達、通信與共同情勢圖可信度 | 是否有多來源交叉驗證 |
| 前沿隔離 | 使西南諸島與本土聯繫下降 | 島際通信與補給能維持多久 |
| 同盟分離 | 延遲日美共同決策 | 命令、情報與政治溝通是否有備援 |
| 後勤摩擦 | 讓港口、機場、油料與維修效率下降 | 替代節點是否實際演練 |
| 社會恐慌 | 放大傷亡、缺貨與基地風險 | 可信資訊能否快速到達居民 |
| 政治迫降 | 迫使日本限制支援或接受條件 | 是否有跨黨派危機共識 |

# 日本紅方｜第三卷：關鍵基礎設施、經濟安全與系統性失能

    **從能源、通信、金融、交通、產業與修復鏈分析日本可能遭受的跨域失能風險**

    > **使用界線**  
> 本文件是防禦導向的高階紅隊研究，用來盤點日本可能面臨的國家級滲透、灰色地帶、軍事壓迫、經濟安全與系統性失能風險。內容不提供特定設施弱點、位置、破壞方法、招募流程、規避查緝、網路入侵步驟、封鎖參數或攻擊優先序。

    ## 證據分級

| 等級 | 定義 | 文件使用方式 |
|---|---|---|
| A級 | 日本或盟國官方已公開確認的制度、案件、演訓或威脅活動 | 可作為現況基礎 |
| B級 | 官方威脅評估、白皮書或多項公開資料支持 | 可作為合理風險判讀 |

## 一、系統性失能的核心

最黑暗情境不是所有設施同時被摧毀，而是多個系統以不同程度降級，造成操作人員、政府與民眾無法建立共同認知。

- 設施存在但資訊不可信。
- 物資存在但交通、報關或配送失序。
- 備援存在但與主系統共享相同電力、帳號或供應商。
- 地方仍可運作但與中央通信不穩。
- 金融帳面正常但民眾不相信支付與提款能力。


## 二、日本關鍵基礎設施相依性

日本的能源、通信、交通、金融、醫療、政府、製造與災防高度互相依賴。紅方會關注的是跨系統依賴，而不只是單一資產。

| 系統 | 主要上游依賴 | 失效後下游影響 |
|---|---|---|
| 電力 | 燃料、電網控制、通信、維修人員 | 通信、水務、醫療、交通、金融 |
| 電信 | 電力、骨幹網路、海纜、資料中心 | 政府、金融、物流、公共警報 |
| 港口 | 航運、油料、報關、資訊系統、道路 | 能源、製造、食品、外援 |
| 金融 | 通信、身分驗證、電力、雲端 | 商業、民生、企業信心 |
| 醫療 | 電力、藥品、氧氣、資料、交通 | 傷患、慢性病、社會穩定 |
| 製造 | 能源、材料、物流、軟體、人才 | 出口、國防、就業、供應鏈 |


## 三、能源進口與供應鏈

日本能源自給率低，化石燃料仍高度依賴海外。風險鏈條是海運、卸載、儲存、發電、輸配電、控制與維修。

- 原油與LNG航線受地緣政治與保險成本影響。
- 港口或接收站資訊異常可能延遲排程。
- 不同地區電力系統與互聯容量影響跨區支援。
- 備用燃料、發電設備與特殊零件需要長期規劃。
- 能源價格與短缺敘事可能被用來反對安全政策。


## 四、核能、電網與公共信任

核能與能源政策在日本具有高度社會敏感性。紅方可能利用事故、謠言或網路異常放大對政府與電力公司的不信任。

- 偽造輻射、停機或疏散訊息。
- 利用正常設備故障宣稱全面核安危機。
- 放大中央、地方與營運商資訊差異。
- 以假文件或深偽專家影像製造恐慌。
- 使電網調度與居民避難同時承受壓力。


## 五、海底電纜與國際通信

日本的國際金融、雲端、企業營運及對外政府通信高度依賴海底電纜。

- 多條線路或登陸站同時異常比單一故障更具戰略效果。
- 海纜降級與DDoS、DNS或雲端異常疊加，可形成資訊真空。
- 維修能力、船舶、零件、海象與安全情勢決定中斷時間。
- 離島與偏遠地區的替代通信容量可能不足。
- 事件可被包裝成海事事故，增加歸責難度。


## 六、數位身分、憑證與命令可信度

最嚴重的數位危機不是無法連線，而是無法確認身分、命令、資料與交易是否真實。

- 政府電子簽章與高階帳號。
- DNS、網域、時間同步與憑證撤銷。
- 金融、醫療、交通與地方政府身分系統。
- 官方社群與公共警報的多管道驗證。
- 憑證遭竊後能否迅速切換至乾淨信任根。


## 七、網路預置與資料污染

國家級網路行動可能在平時建立存取，危機時才啟用。目標不一定是關機，而可能是污染資料與延誤修復。

- 利用供應鏈、遠端維護、舊設備或帳號取得長期存取。
- 改變監控資料、派工資訊或庫存狀態。
- 同時製造真假警報，耗盡應變人員。
- 破壞備份、日誌或乾淨映像，使重建失去可信基準。
- 以勒索軟體或一般犯罪外觀掩飾國家目的。


## 八、金融、支付與市場信心

日本大型金融市場與高密度電子支付系統，使金融信任成為關鍵基礎設施。

| 情境 | 紅方效果 | 次生風險 |
|---|---|---|
| 假銀行倒閉消息 | 大量客服、提款與轉帳需求 | 正常延遲被視為崩潰 |
| 假政府資本管制公告 | 企業與民眾搶先換匯 | 市場波動與謠言互相放大 |
| 支付服務降級 | 商戶轉向現金或停止交易 | 物流與民生不便 |
| 高層深偽發言 | 質疑央行與金融監理可信度 | 外資與匯率壓力 |
| 跨境支付延遲 | 企業進口與能源付款受阻 | 供應鏈信心下降 |


## 九、港口、機場、鐵路與道路

日本交通體系高度準時與數位化，局部資訊失序可能迅速擴散到旅客、貨運、製造與救災。

- 港口貨櫃、報關、倉儲與聯外道路。
- 機場航班、地勤、油料、空管與旅客資訊。
- 新幹線、都市鐵路、地方鐵路與維修調度。
- 橋梁、隧道、高速公路與災後替代路線。
- 大型活動、觀光旺季或災害時的超載效應。


## 十、半導體、材料與精密製造

日本的價值不只在成品，也在材料、設備、製程、檢測、失敗經驗、供應商與人才。

- 半導體材料、設備與零件。
- 精密機械、光學、感測器與工業機器人。
- 汽車、電池、航太、造船與防衛供應鏈。
- 專利尚未揭露的技術路線與良率問題。
- 小型供應商、軟體商與海外子公司。


## 十一、食品、藥品、醫療與冷鏈

紅方不必直接破壞醫療或食品，只要製造真假混合的短缺與污染訊息，就可能造成真實壓力。

- 假藥品短缺或醫院停診消息。
- 冷鏈與配送資料失真。
- 高齡人口、透析、長照與偏鄉醫療的脆弱性。
- 災害與軍事危機同時發生時的床位、氧氣與人力競爭。
- 食品、飲水與污染謠言造成搶購及交通壅塞。


## 十二、災防、公共警報與地方治理

日本高度依賴地震、海嘯、氣象、交通與避難警報。敵對行為者可利用災害資訊真空，而不必製造災害本身。

- 冒充地方政府或氣象機關發布錯誤避難訊息。
- 對不同地區投放互相矛盾的道路、港口與醫療資訊。
- 讓民眾質疑真正的J-Alert或地方防災廣播。
- 以假救援或募款網站蒐集個資與金流。
- 放大中央與地方資源分配爭議。


## 十三、修復與復原產業鏈

很多韌性計畫只重視備援，卻忽略修復所需的人員、零件、船舶、工程車、住宿、交通與安全。

| 修復領域 | 關鍵依賴 | 紅方可能追求的效果 |
|---|---|---|
| 海纜 | 維修船、零件、許可、海象 | 延長對外通信降級 |
| 電力 | 變壓器、工程師、燃料、道路 | 使區域停電反覆出現 |
| 電信 | 設備、基地台電力、軟體與現場人員 | 讓備援容量逐步耗盡 |
| 交通 | 工程設備、材料、警戒與替代路線 | 延誤救災與軍事運輸 |
| 工控 | 原廠、乾淨軟體、設定與測試 | 使恢復後仍不可信 |


## 十四、內應與承包商風險

內部人員不一定進行直接破壞，可能只需提供真實損害、備援狀態與修復進度，或延誤派工和錯置資源。

- 承包商與遠端維護權限超出必要範圍。
- 離職人員帳號、憑證與設備未撤銷。
- 人員遭債務、家屬、職涯或犯罪把柄脅迫。
- 危機中回報哪些備援已啟動、哪些訊息最具效果。
- 利用正常官僚程序拖延修復而不留下明顯破壞證據。


## 十五、系統性失能成熟度

可用成熟度模型評估紅方是否已從單點蒐情進入跨域危機預置。

| 級別 | 能力狀態 | 指標 |
|---|---|---|
| S1 | 公開資訊建模 | 收集制度、供應鏈與設施功能 |
| S2 | 人物與供應商圖譜 | 掌握維護者、承包商與關鍵人才 |
| S3 | 數位或人員存取 | 取得有限帳號、資料或內部回報 |
| S4 | 跨系統相依性分析 | 可判斷電力、通信、物流與金融連鎖 |
| S5 | 危機預置 | 具替代帳號、代理人、假資訊與持續存取 |
| S6 | 同步啟用 | 能在軍事、災害或政治危機中形成複合效果 |

# 第4卷｜危機啟用、災害疊加與最壞情境推演

# 日本紅方｜第四卷：危機啟用、災害疊加與最壞情境推演

    **將平時滲透、軍事壓力、經濟安全與基礎設施風險組合成國家級推演情境**

    > **使用界線**  
> 本文件是防禦導向的高階紅隊研究，用來盤點日本可能面臨的國家級滲透、灰色地帶、軍事壓迫、經濟安全與系統性失能風險。內容不提供特定設施弱點、位置、破壞方法、招募流程、規避查緝、網路入侵步驟、封鎖參數或攻擊優先序。

    ## 證據分級

| 等級 | 定義 | 文件使用方式 |
|---|---|---|
| A級 | 日本或盟國官方已公開確認的制度、案件、演訓或威脅活動 | 可作為現況基礎 |
| B級 | 官方威脅評估、白皮書或多項公開資料支持 | 可作為合理風險判讀 |
| C級 | 依已知能力組合出的最壞情境推演 | 僅供演練，不視為既成事實 |
| D級 | 來源不足、無法驗證或過度推測 | 不納入主要結論 |

本文件特別避免把合法政治反對、反基地、反核、和平運動、地方自治、學術交流、在日華人或一般對中商務直接視為滲透。判斷基礎應是隱瞞委託、異常金流、未授權存取、秘密指示、協同行為與可驗證證據。

## 一、四階段危機模型

日本紅方可被分為平時塑形、壓力測試、複合壓迫與危機啟用四個階段。

| 階段 | 紅方主要活動 | 藍方應觀察 |
|---|---|---|
| 第一階段：塑形 | 建立人脈、資金、敘事、技術與供應鏈圖譜 | 未揭露關係與跨域節點重疊 |
| 第二階段：測試 | 以軍演、海警、網攻、經濟措施或假資訊測試反應 | 政府、企業、地方與民眾反應時間 |
| 第三階段：複壓 | 多方向軍事、經濟與資訊壓力同步增加 | 是否出現共同基礎設施與敘事來源 |
| 第四階段：啟用 | 內部回報、通信降級、金融恐慌與政治條件同時出現 | 是否形成政治迫降與同盟分離效果 |


## 二、最壞情境一：臺海危機外溢

臺海軍事危機可能使日本面臨基地使用、居民疏散、海空航線、能源、金融與外交決策的同步壓力。

- 西南諸島進入高警戒，商業交通先行縮減。
- 日美對支援範圍、時間與公開訊息出現差異。
- 社群散播日本被美國拖入戰爭的敘事。
- 企業要求限制支援，以維持市場與能源供應。
- 紅方提出降低壓力的政治交換條件。


## 三、最壞情境二：西南諸島通信與補給隔離

離島不必完全失聯，只要通信、航空、海運、醫療與物資同時降級，就可能產生被孤立感。

- 海纜或骨幹通信異常，衛星容量不足以支撐全部需求。
- 航班、船班與物流因風險及保險縮減。
- 地方政府收到延遲或矛盾命令。
- 假消息宣稱中央已放棄部分島嶼。
- 居民疏散與自衛隊運輸需求互相競爭。


## 四、最壞情境三：大型災害疊加敵對行動

最危險的情境是自然災害先造成真實損害，紅方再利用資訊真空與資源超載。

- 地震或海嘯造成通信、道路、港口與電力自然中斷。
- 敵對帳號散播錯誤避難、輻射、醫療與物資訊息。
- 網攻針對災防、地方政府或媒體平台增加混亂。
- 軍事活動在周邊升高，迫使政府分散注意力。
- 社會開始懷疑哪些故障是自然、哪些是敵對行動。

> 這是C級情境；不應在缺乏鑑識時把災害或事故直接歸責為敵對行動。


## 五、最壞情境四：深偽首相與內閣命令

高階深偽、遭竊帳號與通信降級可能共同造成國家指揮信任危機。

- 假首相影像宣布停戰、撤離或限制美軍。
- 地方政府收到偽造的避難或設施管制命令。
- 真正命令因社群大量質疑而延遲執行。
- 不同平台上的官方帳號發布不一致內容。
- 外國媒體無法快速確認日本合法政府狀態。


## 六、最壞情境五：金融與能源信心危機

能源價格、航運延遲、匯率波動與支付異常可被組合成『日本即將失控』的敘事。

- 假資本管制、銀行倒閉與燃料短缺公告。
- 正常延遲因大量提款、客服與交易需求而惡化。
- 企業停止部分投資與進口，造成真正供應鏈壓力。
- 社群宣稱政府為支援美國犧牲民生。
- 產業團體要求政策退讓換取市場正常化。


## 七、最壞情境六：多方向軍事牽制

西南、日本海與北海道方向同時出現軍事活動，並伴隨網路與飛彈威脅。

- 自衛隊與海上保安廳需在多方向維持警戒。
- 美日情報共享承受大量訊息與假情報污染。
- 地方政府同時要求防護、疏散與經濟補償。
- 媒體難以分辨哪些行動是演訓、示威或真正危機。
- 紅方利用不確定性迫使日本限制前沿活動。


## 八、最壞情境七：港口、機場與公共設施政治危機

軍民兩用公共基礎設施若在危機中被大量使用，可能同時面臨營運、地方政治、居民安全與認知戰壓力。

- 假消息宣稱公共設施已成為必然攻擊目標。
- 地方反對與中央命令衝突。
- 承包商、工會或營運商因安全疑慮降低服務。
- 旅客與居民自發撤離造成交通壅塞。
- 紅方提出停止設施支援即可恢復正常交通的敘事。


## 九、最壞情境八：城市與離島資訊分裂

不同地區可能因通信、媒體使用與地方政治而收到完全不同的危機敘事。

- 大城市相信危機可控，離島相信已被放棄。
- 部分地方收到假疏散命令，其他地區收到假留守命令。
- 地方首長與中央官員遭深偽冒充。
- 官方澄清因頻寬、語言或平台限制無法同步到達。
- 社會開始依政治傾向選擇相信不同版本。


## 十、最壞情境九：局部控制與戰後治理敘事

極端C級情境需要評估紅方對局部島嶼、港口或設施的政治控制宣傳，但不提供任何實際控制程序。

- 假地方投降或自治聲明。
- 冒充地方政府發布秩序與物資規則。
- 利用居民名冊、醫療與避難資料辨識人員。
- 將人道援助與政治服從綁定。
- 對外宣稱日本中央已失去有效管轄。


## 十一、最壞情境十：日美同盟政治迫降

紅方可能在日本國內壓力達到高峰時提出『恢復和平與經濟正常化』的交換條件。

- 限制駐日美軍設施使用。
- 降低自衛隊對臺海或西南地區支援。
- 暫停部分情報、後勤或制裁合作。
- 接受對東海或離島活動的新限制。
- 以能源、市場、航運或軍事降溫作為交換。

> 政治條件是否存在須以官方訊息與外交證據確認；此處僅建立防禦演練模型。


## 十二、紅方七級能力成熟度

日本藍方可用以下模型判斷紅方是否從平時影響升級為危機可啟用能力。

| 級別 | 能力 | 判斷指標 |
|---|---|---|
| R1 | 公開情報與敘事 | 以公開資料和合法交流為主 |
| R2 | 人物與供應鏈建模 | 持續盤點政策、產業、基地與地方關係 |
| R3 | 隱蔽資金與接觸 | 第三方付款、假公司、未揭露委託 |
| R4 | 多域存取 | 政治、科技、媒體、網路與基礎設施節點重疊 |
| R5 | 模型化預演 | 具數位、兵棋、專業藍軍與危機情境測試 |
| R6 | 危機同步 | 軍事、網路、經濟、假資訊與內部回報同步 |
| R7 | 政治迫降 | 可將系統壓力轉化為具體政策讓步 |


## 十三、網絡切割與復原

成熟紅方會預設部分節點遭查，並透過替代公司、第三國中介、可更換帳號與分段知情維持網絡。

- 一個公司遭查後，由另一法人接手相同活動。
- 付款改由第三國、顧問費、研究費或虛擬資產完成。
- 不同執行者只知道局部任務，難以還原上層。
- 事件被描述成普通詐騙、商業糾紛或個人違法。
- 透過新議題、新平台或新地方節點重新建立接觸。


## 十四、日本藍方必答問題

完整紅隊推演必須轉化成藍方可驗證的問題。

- 首相官邸或主要中央機關無法使用時，合法指揮如何持續？
- 深偽首相、地方首長或美軍命令出現時，如何離線驗證？
- 西南諸島通信與運輸同時降級時，民生與軍事如何排序？
- 日美情報出現矛盾時，誰有權建立共同情勢圖？
- 多條海纜異常後，哪些國家功能可獲得衛星與有限頻寬？
- 能源、港口與金融恐慌同步出現時，誰統一發布資訊？
- 災害與敵對行動疊加時，如何避免錯誤歸責與延誤反應？
- 特定利用港口機場遭政治爭議時，地方與中央如何協調？
- 承包商、遠端維護與關鍵技術人員的權限如何撤銷？
- 國家如何保護遭脅迫者並鼓勵其主動通報？
- 修復所需的船舶、零件、工程師與乾淨資料是否有實際備援？
- 如何避免反滲透被政治化或轉化成族群獵巫？
