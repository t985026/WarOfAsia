## 🧮 模擬器分數計算演算法 (Calculation Engine)

在 [Web Dashboard](file:///i:/Project/WarOfAsia/dashboard/index.html) 中，計算引擎公式如下：

```javascript
// 總最大權重分母 = sum(metric.weight * 2)  [全紅燈時]
let totalMaxWeight = 118 * 2 = 236;

// 當前紅方得分 = sum(yellow ? weight*1 : red ? weight*2 : 0)
let redScore = sum(current_metric_scores);

// 紅方攻勢壓力百分比
let redPercent = Math.round((redScore / totalMaxWeight) * 100);

// 藍方國家韌性得分百分比
let blueResiliencePercent = Math.max(0, 100 - Math.round(redPercent * 0.85));

// 日本與韓國外溢風險衍生計算
let jpSpilloverRisk = Math.min(100, Math.round(redPercent * 1.1));
let krSpilloverRisk = Math.min(100, Math.round(redPercent * 0.95));
```

### 警戒燈號與 DEFCON 狀態對應表
- **redPercent < 35%** ➔ **DEFCON 4 (綠色常態)**：系統常態運作。
- **35% <= redPercent < 65%** ➔ **DEFCON 2 (黃色警戒)**：灰帶與動員預警中，觸發附件 A/B。
- **redPercent >= 65%** ➔ **DEFCON 1 (紅色危機)**：海空封鎖與臨戰狀態，觸發附件 C/D/E。
