# 執行摘要

|  | **核心判斷**<br>公開資料已足以確認：共軍曾在朱日和等訓練環境中使用類似臺灣總統府的建築模型，並將臺灣、澎湖地圖、通信樞紐與海底電纜等內容放入演訓想定。這表示對臺準備不只存在於武器數量，也存在於「把臺灣轉換為可反覆測試、修正與驗證的訓練問題」之能力。 |
| --- | --- |

本報告認為，實體模型只是可見的一層。較完整的模擬作戰體系，應包含實體環境複製、假想敵藍軍、跨軍種協同、複雜電磁與資訊環境、指揮流程、裁判評估、數據回饋，以及對外威懾展示。其目的不必限定於單一「斬首」劇本，也可能服務於城市封控、重要功能奪控、道路清障、資訊作戰、後續秩序管理及政治心理施壓。

然而，模型化訓練不等於實戰必然成功。臺灣真實地形、守軍反應、人口流動、通信變化、持續補給、國際介入與政治社會反應，都無法被靜態模型完整複製。藍方應避免因模型曝光而陷入單一劇本恐慌，真正防禦重點是讓國家功能具備分散、替代、降級運作與快速重建能力。

# 一、公開證據與時間軸

## 1. 「使命行動－2013B」：臺澎掛圖、通信樞紐與海纜想定

臺灣國防部刊載的研究指出，共軍第 42 集團軍在「使命行動－2013B」戰役指揮所中出現臺灣與澎湖地圖，想定內容包括摧毀通信樞紐（含海底電纜）、破壞體系，以及依臺灣、澎湖不同地形劃分作戰區塊，進行彈藥、毀傷與戰術需求研判。

|  | **防禦判讀**<br>這不代表共軍已掌握每一條海纜或每一處設施的完整弱點，但顯示「通信隔離與體系破壞」至少已被納入公開可見的作戰研究與演訓想定。 |
| --- | --- |

## 2. 「跨越－2015B」：類似總統府模型與立體攻防

同一份國防部研究記載，「跨越－2015B」演習在內蒙古朱日和訓練基地出現類似中華民國總統府的建築物，並進行立體攻防作戰。這是目前最具代表性的官方公開證據，顯示模型區域被用來強化對特定政府象徵與城市環境的熟悉度。

## 3. 朱日和城市戰訓練的長期化

國防部刊載的 2023 年研究整理指出，共軍自 2006 年起在朱日和建造城市戰訓練基地，2009 年正式啟動城市戰訓練場；2014 年「跨越－2014·朱日和」進行大規模紅藍對抗；2017 年後則以合成旅驗證陣地進攻、城市進攻與防禦等能力。相關研究也指出，共軍在類比建築群中演練多路攻擊、分割圍殲，並運用無人載具強化監控與態勢掌握。

## 4. 2025 年以後的衛星影像報導

2025 年媒體引述日本研究機構與衛星影像判讀，聲稱朱日和「模擬臺北」區域持續擴建，除總統府外，亦出現被判讀為其他政府建築與周邊道路的模型，並觀察到道路封鎖、清障及裝甲車輛推進活動。這些資訊有助於辨識趨勢，但未獲中國官方證實，建築辨識、用途及訓練內容仍可能存在誤差。

| **年份**  | **公開訊號**                               | **證據等級** | **主要意義**                       |
|-----------|--------------------------------------------|--------------|------------------------------------|
| 2006–2009 | 朱日和城市戰基地建設與正式啟用             | A/B          | 城市作戰訓練制度化                 |
| 2013      | 臺灣、澎湖掛圖；通信樞紐與海纜想定         | A            | 對臺體系破壞納入作戰研判           |
| 2014      | 跨軍區紅藍對抗，紅軍多次受挫               | A/B          | 以專業假想敵揭露訓練缺陷           |

| 2020–2025 | 衛星影像報導模型區擴建與道路演練           | C            | 可能從單棟模型擴展至街廓與流程預演 |
| 2025      | 美印太司令部稱相關活動不只是演習，而是預演 | B            | 周邊軍事行動被視為能力驗證與排練   |

# 二、模型區域為何具有軍事價值

軍事模型區域不是單純的宣傳佈景。它能把抽象的作戰計畫轉換成可測量的時間、距離、通信、火力、道路、協同與人員負荷問題，讓部隊反覆練習並收集數據。

| **功能**       | **模型區可測試的問題**                       | **對藍方的含意**                                               |
|----------------|----------------------------------------------|----------------------------------------------------------------|
| 降低陌生感     | 視距、街廓、障礙、建築入口與交通限制         | 不要依賴固定格局與單一路線                                     |
| 標準化流程     | 哪些單位先到、誰負責協同、何時切換任務       | 命令與代理機制須具彈性                                         |
| 驗證聯合作戰   | 地面、空中、無人系統、電子與情報能否共享態勢 | 藍方要破壞敵方「共同情勢圖」的可靠性，但防禦本身也須有多源驗證 |
| 衡量時間與損耗 | 清障、封控、搜索、控制與後續維持所需時間     | 防禦設計要迫使敵方反覆重算，而非只守單一點                     |
| 訓練假想敵反應 | 藍軍伏擊、錯誤情報、通信中斷與反擊           | 臺灣必須讓真實反應超出紅方模型假設                             |
| 心理與戰略傳訊 | 公開模型與演練畫面，製造威懾與必敗感         | 避免把敵方宣傳等同實際成功機率                                 |

|  | **關鍵區分**<br>模型訓練的價值在於「縮短學習曲線」，不是保證能複製真實戰場。藍方最有效的反制，不是只遮掩建築外觀，而是使指揮、通信、後勤與社會運作具備多種替代模式。 |
| --- | --- |

# 三、六層模擬作戰生態系

從國家級紅隊角度，真正成熟的對臺模擬體系應被視為一個閉環，而非一座孤立模型村。

| **層級**        | **組成**                                   | **主要作用**               | **公開證據狀態**               |
|-----------------|--------------------------------------------|----------------------------|--------------------------------|
| 1｜情報與資料層 | 地形、道路、建築、通信、軍事活動與公開資料 | 建立基準環境及假設         | 部分已知；完整程度不明         |
| 2｜實體環境層   | 城市街廓、政府區域、地形、障礙與設施類型   | 進行空間、機動及協同訓練   | 朱日和等案例已確認             |
| 3｜數位／合成層 | 模擬器、兵棋、指揮資訊與數位地圖           | 反覆比較不同方案與損耗     | 合理推定存在；對臺細節未公開   |
| 4｜假想敵層     | 專業藍軍、守備想定與不確定事件             | 避免紅軍只在固定劇本中獲勝 | 朱日和紅藍對抗已公開           |
| 5｜聯合任務層   | 地面、空中、火力、無人、電子、網路與支援   | 驗證跨軍種與跨域銜接       | 多份公開研究支持               |
| 6｜裁判與回饋層 | 數據記錄、損害判定、失敗復盤與模型更新     | 把演訓結果轉化為下一輪改進 | 一般軍演必備；對臺專屬機制不明 |

# 四、實體模型與功能場景

公開防禦文件不應把這些內容轉化成具體攻擊清單；較安全且有價值的做法，是按「國家功能場景」檢視共軍可能希望驗證的能力。

| **功能場景**   | **可能驗證的能力**             | **藍方應保護的核心功能**                 |
|----------------|--------------------------------|------------------------------------------|
| 國家決策區     | 指揮失能、封控、資訊與象徵效果 | 憲政延續、代理順位、可信命令與異地辦公   |
| 城市街廓       | 多路推進、道路封鎖、清障與辨識 | 交通分流、地方治理、警消醫療與民眾避難   |
| 軍事設施類型   | 戰力保存、恢復、後勤與基地防護 | 分散、替代、快速修復與持續產生戰力       |
| 通信與海纜場景 | 對外隔離、指揮降級與資訊真空   | 多路通信、衛星備援、優先流量與人工程序   |
| 港口與機場功能 | 物流、外援、能源與兵力物資流動 | 多節點接收、離線作業、快速恢復及安全查核 |
| 能源與城市維生 | 電力、供水、醫療與工業連鎖失能 | 孤島運轉、燃料與零件儲備、人工調度       |
| 地下與備援設施 | 搜索、封控、通信及持續指揮     | 不依賴單一位置，確保替代指揮鏈           |
| 離島與複合地形 | 隔離、持續補給、監控與政治壓力 | 地方自主運作、補給冗餘與可信公共訊息     |
| 戰後秩序場景   | 道路、公共安全、人口與行政控制 | 維持政府合法性、治安、司法及社會韌性     |

|  | **關於總統府模型的正確解讀**<br>它可能同時服務於戰術熟悉、指揮區域封控、重要建築奪控、道路與街廓演練、心理威懾及政治象徵操作。僅從建築外觀，無法證明共軍只有單一斬首劇本，也不能推定其已掌握真實備援指揮位置。 |

# 五、假想敵、聯合作戰與城鎮控制

## 1. 專業藍軍的作用

朱日和紅藍對抗的重要意義，在於讓參演部隊面對會反擊、會欺騙、會改變部署的假想敵。2014 年演訓中「紅軍七戰六敗」的公開紀錄，反映藍軍並非只為配合劇本，而是用來揭露指揮、偵察、協同與後勤缺陷。

- 測試部隊是否過度依賴既定路線與時間表。

- 逼迫指揮官處理錯誤情報、通信中斷與突發反擊。

- 比較不同合成部隊與指揮方式的表現。

- 把失敗案例轉化為訓練標準、裝備需求及後續演訓課目。

## 2. 從「進入城市」到「持續控制」

國防部公開研究顯示，共軍城鎮戰研究不只關注突破與奪控，也涵蓋戰場清理、道路與重要建築控制、傷患救援、公共安全及後續秩序。這代表模擬區可能用於驗證從軍事行動延伸至治安與行政控制的流程，但公開資料不足以確認其對臺後續治理計畫的完整程度。

## 3. 聯合與多域整合

| **域別**       | **在模型區的可能角色**         | **防禦判讀**                         |
|----------------|--------------------------------|--------------------------------------|
| 地面           | 進入、封控、清障、搜索及控制   | 不要只以固定防線思考城市防禦         |
| 空中與火力     | 偵察、支援、火力效果評估       | 確保指揮與民生系統可在受壓下持續運作 |
| 無人系統       | 監控、定位、通信中繼與效果確認 | 建立反無人機、遮蔽與異常通報機制     |
| 電子與電磁     | 干擾定位、通信與感測器         | 保留無衛星定位、低頻寬與人工替代流程 |
| 網路與資訊     | 資料竊取、系統降級、假訊息配合 | 優先保護數位身分、命令驗證與日誌     |
| 武警／治安力量 | 設施控制、秩序與人口管理       | 地方政府、警政與司法須能合法持續運作 |

# 六、資訊、電磁與數位環境

實體模型只能複製空間；現代聯合作戰還需要複製「看不見的環境」，包括通信負載、定位授時、感測器資料、網路權限、假訊息與決策壓力。

## 1. 指揮流程與共同情勢圖

紅方可能藉模擬驗證：不同軍種是否看到一致態勢、資料延遲會如何影響決策、通信失效後的任務式指揮是否有效，以及上級與前線如何確認戰果。藍方則必須避免單一資料源或單一指揮節點成為整體失效點。

## 2. 複雜電磁環境

朱日和相關公開研究多次提到複雜電磁環境。其軍事意義包括測試通信、定位、感測器、無人系統及火力協同在受干擾情況下能否運作。對臺灣而言，防禦重點不是只增加頻寬，而是建立低頻寬、間歇連線、人工核對與不同技術路徑的備援。

## 3. 數位孿生：可以推測，但不能過度宣稱

|  | **證據界線**<br>共軍具備使用數位地圖、兵棋、模擬器與指揮資訊系統的能力並不令人意外；但目前沒有足夠公開證據證明其已建成涵蓋臺灣所有政府、軍事與基礎設施的即時、完整「數位孿生」。報告應區分一般數位建模能力與特定對臺全域模型。 |
| --- | --- |

| **可能的數位功能**   | **可合理推定程度** | **主要限制**                                   |
|----------------------|--------------------|------------------------------------------------|
| 地形與城市三維建模   | 高                 | 公開與商業資料可取得，但精度與時效不一         |
| 兵力、時間與後勤模擬 | 高                 | 結果高度依賴假設與輸入品質                     |
| 通信與電磁環境模擬   | 中高               | 真實戰時干擾、設備故障與人員行為難完整重現     |
| 關鍵設施相依性模型   | 中                 | 可從公開資料推測，但內部備援與實際運轉未必可見 |
| 即時全臺數位孿生     | 低至中／未證實     | 需要大量持續更新、內部資料與可信感測來源       |

# 七、最黑暗視角下的訓練閉環

從最壞情境紅隊角度，模型區域的危險不在於「長得像某棟建築」，而在於它可能成為情報、聯合演訓、網路與認知作戰之間的接口。以下是防禦性推演，並不代表每一環節均已部署。

| **階段**    | **紅方可能追求的效果**                       | **藍方需防止的失效**                   |
|-------------|----------------------------------------------|----------------------------------------|
| 1｜長期建模 | 把公開與秘密情報轉為地形、人物、流程和依賴圖 | 敏感資料過度公開、內部權限與供應鏈失控 |
| 2｜任務預演 | 反覆測量進入、封控、通信、火力和後勤時間     | 固定部署與單一備援被模型化             |
| 3｜壓力測試 | 以軍演、網攻、海纜事件與資訊戰觀察臺灣反應   | 每次應變都暴露真實流程與容量           |
| 4｜模型更新 | 把臺灣的修正措施再納入下一輪演練             | 防禦調整缺乏機動與欺敵思維             |
| 5｜危機同步 | 模型訓練與海空壓力、網路降級、認知戰同時啟用 | 中央、軍方、地方與民間形成不同情勢圖   |
| 6｜政治利用 | 將局部失能包裝成政權崩潰與抵抗無效           | 官方命令無法被驗證，社會信任快速下降   |

|  | **最壞情境核心**<br>紅方真正希望從模型中取得的，可能不是一張「如何攻下一棟建築」的答案，而是一套能判斷：何時臺灣的指揮、通信、物流、金融與社會信任會同時跌破可持續門檻的模型。 |
| --- | --- |

## 模型與心理戰的雙重用途

模型區曝光本身也是資訊作戰。公開總統府、政府區域或軍事設施模型，可以放大「敵方已經完全掌握臺灣」的印象。然而，模型畫面通常無法證明情報的新鮮度、內部配置、真實備援、持續補給或戰時抵抗。藍方應同時重視其訓練價值，又避免被其宣傳價值綁架。

# 八、證據缺口與常見誤判

| **常見說法**                           | **較嚴謹的判斷**                                                                   |
|----------------------------------------|------------------------------------------------------------------------------------|
| 「有總統府模型，等於已有成功斬首方案」 | 模型顯示任務關注與訓練需求，但不能證明已掌握真實指揮與備援體系。                   |
| 「模型越像，實戰成功率越高」           | 相似度可降低陌生感，但實戰更取決於情報、制空制海、補給、通信、守軍反應及政治條件。 |
| 「模型區只用於攻擊」                   | 也可能用於防禦、反恐、治安、工程、通信與聯合指揮測試。                             |
| 「衛星影像看到的每棟建築都能準確辨識」 | 影像判讀可能受比例、陰影、施工階段與先入假設影響，應保留不確定性。                 |
| 「共軍已建立完整臺灣數位孿生」         | 具備數位建模能力不等於已完成即時、全域、精確且持續更新的對臺模型。                 |
| 「訓練失敗代表沒有威脅」               | 紅藍對抗中的失敗反而可能提高後續學習與修正速度。                                   |

## 模型難以完整重現的現實變數

- 臺灣守軍、政府與地方單位會主動改變部署、程序及通信方式。

- 真實人口、交通、火災、傷患、天候與設備故障具有高度不確定性。

- 跨海行動的持續補給、維修、傷患後送與海空控制難以由城市模型代替。

- 盟友介入、國際制裁、金融市場與外交反應無法在實體模型中精確預演。

- 城市戰的地下空間、建築內部、民間通信與地方知識會持續變化。

- 模型若過度固定，可能使參演部隊形成錯誤的熟悉感與劇本依賴。

# 九、臺灣藍方防禦意涵

藍方不應以「隱藏所有建築」作為主要答案。公開地圖、衛星影像與城市資料不可能完全消失；真正需要保護的是不可從外觀直接推導的決策、權限、備援、存量、修復能力與運作模式。

| **防禦軸線** | **優先措施**                                           | **目的**                               |
|--------------|--------------------------------------------------------|----------------------------------------|
| 指揮延續     | 建立多層代理順位、異地辦公、離線命令驗證與可信公告     | 使象徵或主要辦公地點失能不等於政權失能 |
| 功能分散     | 將通信、資料、後勤、醫療及維修能力分散至多個節點       | 讓敵方模型無法以少數節點推導整體崩潰   |
| 模式多樣化   | 定期改變演練、備援、路由與協調流程，不依賴單一標準劇本 | 降低敵方反覆預演的收益                 |
| 資料治理     | 限制不必要的敏感地理、供應商、存量與備援資訊公開       | 提高紅方建模成本及不確定性             |
| 紅隊演練     | 建立專業假想敵，模擬共軍模型中的臺灣，再反向測試其假設 | 做到「模型其模型」而非只回應表面威脅   |
| 低頻寬運作   | 演練海纜、衛星、行動網路與雲端同時降級時的最低功能     | 避免通信受壓即失去共同情勢圖           |
| 修復韌性     | 保護維修人員、零件、車輛、工具、原廠支援與替代供應     | 讓局部損害無法累積成長期失能           |
| 社會信任     | 預先建立多通道官方認證、深偽應對與地方訊息一致性       | 抵消模型曝光與危機事件的心理戰效果     |

## 藍方的反模型原則

1.  讓敵方看到的外觀，無法直接推導真正的指揮與備援功能。

2.  讓單一節點的失效，不足以推導整個國家系統的失效。

3.  讓固定時間表、固定路線與固定通信方式不再是唯一運作模式。

4.  讓每次演習不只驗證成功劇本，也驗證失聯、誤判、內應與多點中斷。

5.  讓民眾知道政府功能如何延續，避免象徵性場所受損被解讀為政權崩潰。

# 十、國家級自我審查清單

以下清單供政府、軍方、地方政府與關鍵基礎設施營運者進行防禦盤點。它不要求公開具體節點，而是確認每個功能是否具備替代與復原能力。

| **審查面向** | **必答問題**                                                     | **最低成果**                             |
|--------------|------------------------------------------------------------------|------------------------------------------|
| 模型情報     | 本單位有哪些公開資訊可被用來重建建築、流程、存量、供應商或備援？ | 資料盤點、公開審查與最小揭露             |
| 指揮權       | 主要場所或高階人員失聯時，誰能合法接手？如何驗證？               | 代理順位、雙重驗證、異地與離線程序       |
| 通信         | 海纜、行動網路、衛星與雲端同時降級時，最低服務是什麼？           | 優先級、低頻寬、替代路由與人工流程       |
| 資料可信     | 畫面與感測器數據遭污染時，如何建立可信基準？                     | 多源比對、離線基準、長期日誌與人工核對   |
| 人員         | 關鍵工程師、承包商及輪班人員無法到位時如何運作？                 | 交叉訓練、備援人力、住宿交通及家屬支援   |
| 零件燃料     | 外援中斷後可維持多久？哪些特殊零件無替代來源？                   | 安全存量、替代品、維修與跨區調度         |
| 地方治理     | 中央失聯時，地方可依法決定哪些事項？                             | 預先授權、跨縣市互援、統一訊息格式       |
| 公共訊息     | 主要官方帳號遭竊或深偽出現時，民眾如何確認真偽？                 | 多通道認證、緊急廣播、地方重播與媒體協定 |
| 演練設計     | 演習是否總使用同一場地、流程與成功條件？                         | 變動劇本、專業紅隊、裁判數據與失敗復盤   |
| 復原         | 設施恢復後，如何確認沒有殘留權限、後門或資料污染？               | 乾淨映像、憑證重發、分階段恢復與獨立驗證 |

## 演練成熟度五級

| **級別**     | **狀態**                               | **判斷標準**               |
|--------------|----------------------------------------|----------------------------|
| L1｜紙上存在 | 有計畫但未驗證                         | 依賴文件與個人經驗         |
| L2｜單點測試 | 能測試單一設施或單一系統中斷           | 跨機關相依性尚未驗證       |
| L3｜跨域演練 | 同時測試通信、電力、物流與公共訊息     | 可發現連鎖失效與權限衝突   |
| L4｜對抗演練 | 有專業紅隊、假情報、內部威脅與模型更新 | 防禦方不依賴固定劇本       |
| L5｜持續學習 | 演練數據回饋至採購、法規、訓練與建設   | 形成藍方自己的閉環學習系統 |

# 十一、研究結論

|  | **結論一**<br>中共對臺準備不能只用飛彈、軍艦與軍機數量衡量。實體模型、專業藍軍、城市戰訓練、聯合演訓與裁判回饋，代表其正在把臺灣問題轉換為可反覆演練與修正的組織學習問題。 |
| --- | --- |

|  | **結論二**<br>類似總統府的模型具有戰術、指揮、城市封控、政治象徵與心理威懾等多重用途，但不能直接證明其已掌握臺灣實際指揮備援，也不能等同於跨海作戰成功。 |
| --- | --- |

|  | **結論三**<br>臺灣最重要的反制，是讓國家功能不與單一地點、單一帳號、單一供應商、單一通信路徑或固定劇本綁定，並建立自己的專業紅隊與持續學習閉環。 |
| --- | --- |

因此，藍方的核心問題不應只是「共軍仿造了哪些建築」，而應是：共軍正在試圖把哪些臺灣功能變成可預測、可測量、可重複的問題；臺灣又如何透過分散、替代、降級運作、修復與可信公共溝通，使這些模型在危機中失去準確性。
