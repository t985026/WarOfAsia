# 中國紅方 Markdown 文件索引

## 文件定位

本系列以防禦型紅隊方法，分析假想外部敵對行為者可能如何對中國的黨國指揮、軍事體系、經濟、基礎設施與社會治理形成壓力。所有內容以中國藍方的風險識別、備援、驗證、修復與危機降級為用途。

## 建議閱讀順序

- 國家安全與政策研究：第一卷 → 第四卷 → 第二卷 → 第三卷
- 軍事與戰略研究：第二卷 → 第四卷 → 第三卷
- 經濟與基礎設施：第三卷 → 第四卷 → 第一卷
- 紅藍對抗與完整盤點：完整總版

## 核心原則

> 中國紅方研究的目的，不是建立攻擊中國的目標手冊，而是識別哪些功能在多重壓力下可能失效，讓中國藍方能建立獨立驗證、最低運作、跨區替代與可信復原能力。
