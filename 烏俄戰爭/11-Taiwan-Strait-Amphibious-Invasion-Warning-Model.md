# 1. 為什麼全面兩棲登陸比封鎖更容易留下大型公開訊號？

全面登陸必須把大量：

```text
人員
+
車輛
+
裝甲
+
火砲
+
工程裝備
+
彈藥
+
油料
+
醫療
+
防空
+
通信
+
維修
```

跨越台灣海峽。

因此真正困難的不是：

> 第一波導彈能否擊中台灣。

而是：

> **能否把足夠地面部隊送上岸，建立灘頭，持續補充，最後形成可向內陸推進的戰役力量。**

所以兩棲預警的核心應放在：

# Lift + Marshaling + Sustainment + Combat Posture

而不是單純看軍機架次。
