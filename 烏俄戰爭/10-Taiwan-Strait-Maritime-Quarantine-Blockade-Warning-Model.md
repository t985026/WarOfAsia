因此：

> **目前是「管轄權主張與執法能力塑造」明顯升高，而不是已形成實質封鎖。**

# 1. 為什麼台海封鎖不能直接套用俄烏模型？

俄羅斯 2022 年全面入侵主要是：

```text
大量地面部隊
→ 邊境集結
→ 後勤前移
→ Combat Formation
→ 跨境攻擊
```

台海則存在另一條可能路徑：

```text
海警巡邏
→ 行政主張
→ 商船廣播
→ 航行資訊要求
→ 強制申報
→ 停船要求
→ 登臨檢查
→ 扣留／驅離
→ 局部航道控制
→ 隔離／檢疫
→ 海軍支援
→ 封鎖
```

這條路徑最大的差異：

> **它不一定需要先出現幾十萬地面部隊集結。**

因此，如果只用俄烏的 Logistics surge、Medical surge、Camp → Combat Formation 作為紅色警報門檻，可能會低估「準執法型海上隔離」風險。

# 2. 三個必須分開的概念

## 2.1 Quarantine｜隔離／檢疫式管制

政治語言可能使用：安全檢查、海關、檢疫、危險品、航運安全、交通秩序、反走私、國家安全。

其核心是：

> 要求第三國船舶先接受中國行政程序。

## 2.2 Interdiction｜攔截／阻止

包括：要求停船、改變航向、登臨、搜查、扣押、驅離。

## 2.3 Blockade｜封鎖

目標是實質阻止船舶、貨物、能源、軍援進出台灣，可能包含海警、海軍、航空、導彈、水雷、Cyber 與港口封控。

# 3. 台海版 10 級海上升級階梯

## Stage M0｜背景海上存在
### NORMAL PRESSURE

特徵：PLAN 例行活動、海警一般巡邏，無直接要求赴台商船服從中國管理。

警戒：🟢 GREEN / 🟡 YELLOW

## Stage M1｜台灣周邊海警存在常態化
### PRESENCE NORMALIZATION

特徵：海警、公務船頻率提高；活動區域擴大；台灣東部／太平洋側出現海警；重複宣稱為「依法巡查」。

目前：# ✅ 已成立

2026/06/01，中國海警公開宣布在「台灣島以東海域」進行所謂執法巡查，並表示將加強相關海域管控。

2026/07/04，中國海警又宣布由秀山艦編隊接替岱山艦編隊，繼續東部海域的「常態化執法巡查」。

這不是一次性進入，而是 **Task Group Rotation｜編隊輪替常態化**。

## Stage M2｜行政／法律主張
### JURISDICTION CLAIM

特徵：「中國管轄海域」「依法執法」「航行秩序」「維護主權與海洋權益」。

目前：# ✅ 已成立

中國海警 7/4 官方聲明明確使用「中國管轄海域」描述其在台灣東部的行動。

這是重要的 **Lawfare Indicator**：重點不是船有幾艘，而是北京開始把實際海警存在與法律管轄主張綁在一起。

## Stage M3｜商船識別／資訊詢查
### INFORMATION COMPLIANCE TEST

可能包括船名、IMO number、出發港、目的港、貨物、船旗、所屬公司。

目前：# ✅ 已出現

2026/06/09 台灣陸委會表示中國公務船曾向在台灣東部 EEZ 航行的外籍商船進行廣播／騷擾。Reuters 後續報導，中國船隻曾要求商船提供 origin / destination 等資訊。

這個階段可理解為 **Compliance Probe｜服從度測試**。

## Stage M4｜要求停船／接受檢查
### BOARDING DEMAND

特徵：要求降低航速、停船、接受海警登臨或安全檢查。

截至目前：# 🟠 威脅／政策層面出現；# ❌ 尚無公開確認的大規模實際執行

2026/07/01，台灣海巡官員公開表示，台灣船舶如遇中國海警登臨／檢查要求，應拒絕並通報台灣海巡。

Reuters 當時指出，最近一次行動尚未確認中國海警實際登上一艘台灣船。

因此：

> **M4 是目前最關鍵的 ORANGE→RED 分界之一。**

## Stage M5｜實際登臨一艘正常商船
### FIRST PHYSICAL BOARDING

定義：中國海警在台灣周邊強迫正常商船停船、派員登船、查驗文件／貨物，且不具台灣同意。

目前：# ❌ 未公開確認

若首次發生，這是 **Jurisdiction Claim → Physical Enforcement** 的巨大門檻。

## Stage M6｜系統性檢查制度
### SYSTEMATIC INSPECTION REGIME

特徵：不是單一事件，而是多艘、多日、多區、公開催程序，例如：

```text
赴台船舶
↓
事前申報
↓
取得批准
↓
指定航線
↓
接受檢查
```

目前：# ❌ 未出現

台灣 2026/06/25 桌上兵推即模擬中國要求所有赴台船舶取得北京批准，並可能檢查或扣押。

## Stage M7｜選擇性扣押／驅離
### SELECTIVE SEIZURE

特徵：扣留船舶、押送中國港口、沒收貨物、驅離赴台船舶、以「違反中國法律」處理船長／船員。

目前：# ❌ 未出現

## Stage M8｜局部航道隔離
### PARTIAL QUARANTINE

可能針對台灣東部能源航線、高雄／台中港外海、巴士海峽或台灣北部主要航線。

目前：# ❌ 未出現

## Stage M9｜海警＋海軍聯合封控
### COAST GUARD–NAVY ENFORCEMENT

前線以海警執法，外圍由 PLAN、空軍、無人機等提供軍事後盾。

目前：# 🟠 能力存在；# ❌ 未作為實際封鎖制度啟動

## Stage M10｜軍事封鎖
### MILITARY BLOCKADE

特徵：禁止未批准船舶進出台灣，以武力阻止突破，海空軍直接控制，可能配合導彈／Cyber／水雷。

狀態：# ❌ 未發生

此階段已屬 # BLACK / WAR。

# 5. 為什麼「台灣東部」特別重要？

台灣東部與太平洋側可作為戰時外援與補給方向，因此中國海警在東部建立「常態化執法」存在，其戰略價值高於單純增加台海西側巡邏。

它也能測試第三國反應，包括：船長是否回答、航商是否服從、船旗國是否抗議、保險公司是否調高風險、台灣海巡多久抵達。

# 7. 海上模型警戒分級

## 🟢 GREEN
一般海警存在，無針對赴台商船行政要求。

## 🟡 YELLOW
東部海警活動增加、「中國管轄海域」敘事增加，但無實質干預航行。

## 🟠 ORANGE
至少出現 Q2 編隊輪替、Q3 jurisdiction claim、Q4 商船資訊詢查，但沒有系統性登臨、扣押或強制申報制度。

### 目前：# 🟠 ORANGE

## 🔴 RED
任一高價值組合：

- Route A：Q7 強制停船 + Q8 實際登臨
- Route B：Q11 赴台申報制度 + Q14 檢查區
- Route C：Q17 大型航商取消 + Q18 大量改道
- Route D：Q19 PLAN 掩護 + Q8/Q9 執法升級

## ⚫ BLACK
典型：Q21 武力對拒檢船、Q23 多港同步封控、Q24 Maritime Final Convergence，或 PLAN 直接以武力阻止第三國商船。

此時「法律執法」與「軍事封鎖」已難以實務區分。

# 8. ORANGE → RED 最重要的五個門檻

## Gate 1｜從「問」變成「命令」

目前主要是詢問／廣播；RED 門檻是命令停船。

## Gate 2｜從「命令」變成「登船」

目前台灣已預先要求拒絕中國登檢；若中國真的登上一艘正常商船，風險性質會明顯改變。

## Gate 3｜從單一事件變成制度

目前是巡查；RED 是北京發布正式赴台航運申報／批准規則。

## Gate 4｜從海警變成 PLAN Backstop

目前海警是主角；RED 是 PLAN 顯著負責外圍武力保護。

## Gate 5｜從法律壓力變成商業效果

目前商船多仍正常航行；RED 是大型航商／保險業開始停止服務。

這個 Gate 非常重要，因為封鎖效果不一定需要每一艘船都被攔。只要 Insurance + Shipping Decisions 讓船不敢來，就可能形成 **De Facto Blockade**。

# 9. 「封鎖」最危險的不是第一槍，而是服從度

假設中國廣播：「進入本區必須申報。」

如果 100 艘船中 0 艘服從，管轄主張效果有限。

如果 100 艘船中 70 艘開始申報，即使沒有開火，也可能逐步形成：

# Administrative Control

所以應建立：

# Maritime Compliance Rate

# 11. 封鎖成功不一定需要 100% 阻斷

如果能源與大型航商認為台海風險太高，可能自行停航、改道、提高保費或暫停靠港。

因此：

> 實質隔離可能在軍事上尚未做到 100% 攔截前，就已透過商業風險形成。

# 12. LNG / 能源是高價值監測點

台灣高度依賴海運能源，因此應特別監測：

- LNG carrier
- crude tanker
- refined fuel tanker
- coal carriers

如果中國海警未全面攔船，但特別針對能源船檢查，戰略效果可能非常大。

# 15. 但不能過度推論

目前仍不能寫：「中國正在封鎖台灣。」

原因：

- 商船仍航行；
- 無系統性登臨；
- 無系統性扣押；
- 無強制赴台許可證；
- 無大規模航商撤離；
- 無 PLAN 武力攔船。

所以正確表述是：

# 「封鎖前置管轄／執法能力正在被塑造」

而不是：

# 「封鎖已開始」。

# 16. 颱風交通管制事件怎麼看？

2026/08/08，中國在 Typhoon Dolphin 期間以航行安全為理由要求台灣海峽船舶避險並遵守中國海事要求，台灣拒絕其管轄權。

## 16.1 低風險解釋

颱風本來就需要船舶避風、港口關閉與航運安全管理，因此事件本身不能直接證明封鎖測試。

## 16.2 高風險解釋

它也可能讓北京觀察：國際船舶是否服從中國 VHF 指示、哪些船旗國反應、航運公司政策與台灣海巡如何回應。

因此具有 **compliance test 的可能性**，但信心只宜標示為：

# 🔎 中低～中等

不能定性為已證實的封鎖演練。

# 17. 台灣 6/25 桌上兵推的重要性

台灣模擬的情境不是 PLA 直接發射導彈，而是：

```text
中國宣布：
所有赴台船舶
需北京批准
      ↓
海警檢查
      ↓
拒絕者可能被扣留
```

這非常重要，因為台灣政府已把 **Administrative Quarantine** 視為需要跨部會準備的真實風險。

兵推中：

- Coast Guard 負責執法回應；
- military 維持戰備；
- 政府進行國際法律／資訊宣傳。

這就是：

# Law Enforcement First
# Military Support Second

的危機模型。

# 24. 最重要的分析原則

## 原則 A｜Presence ≠ Blockade

船很多不等於封鎖。

## 原則 B｜Claim ≠ Enforcement

說有管轄權不等於已有效執法。

## 原則 C｜Enforcement ≠ Total Blockade

登檢一艘船很嚴重，但仍與系統性阻斷所有海運不同。

## 原則 D｜Commercial Compliance is Strategic

真正封鎖效果可以由航商自己停止航行，而非完全靠武力產生。

## 原則 E｜First Physical Enforcement Matters

第一次真正停船／登臨／扣押具有不成比例的高預警價值。
